1 Claude Codeって何？

Claude Code（クロード コード）は、Anthropic（アンソロピック）という会社が作ったAIツールです。

普通のAIチャット（例：ChatGPTやClaude.aiのウェブ版）とのいちばんの違いは、あなたのパソコン上のファイルを直接読んだり書いたりできることです。

  • 文章の作成・修正・翻訳
  • ファイルの整理・一括変換
  • 表やデータの加工
  • プログラムの作成（知識不要）
  • 調べ物・まとめ・提案書の作成
チャットとの違いをひとことで言うと ウェブのAIチャット＝「話し相手」　Claude Code＝「実際に手を動かしてくれる同僚」

2 始める前に確認すること

以下の3つが揃っているか確認してください。

  • Claude.ai のアカウント（Proプラン以上）
    Claude Code を使うには有料プラン（月額約3,000円〜）が必要です。claude.ai でサインアップできます。
  • Windows 10/11 または Mac（OSX 10.15以上）のパソコン
    スマートフォンやタブレットでは動きません。
  • インターネット接続
    Claude Code はAIと通信しながら動くため、常時接続が必要です。

3 Node.js のインストール

Claude Code を動かすには「Node.js（ノードジェイエス）」というソフトが必要です。これはClaude Code の「土台」のようなものです。

Node.js って何ですか？入れて大丈夫なものですか？

Node.js は「ウェブサービスやアプリを作るための世界標準ツール」で、Google・Netflix・LinkedInなど世界の大企業も使っています。OpenJS Foundation という非営利団体が管理しており、世界2億台以上のパソコンにインストールされている、信頼性の高いソフトです。

ウイルスや悪意のあるソフトではありません。Claude Code がこのソフトの上で動く仕組みになっているため、必須のインストールです。

後で消せますか？
はい。Windowsなら「設定」→「アプリ」から普通のアプリと同じように削除できます。Macも「アプリケーション」フォルダから削除できます。

インストール中に何かが盗まれたりしない？
Node.js 自体はインターネットに何かを送ったりしません。ファイルをダウンロードしてパソコンにインストールするだけです。公式サイト（nodejs.org）からダウンロードすれば安全です。

すでに入っているか確認する

「ターミナル（黒い画面）」って何ですか？怖くないですか？

ターミナルとは、パソコンにキーボードで命令を文字で打ち込む画面のことです。昔はすべてのパソコン操作がこの形式でしたが、マウスで操作できるようになってから見る機会が減りました。

怖くありません。画面が黒いだけで、普通のアプリと同じです。文字を打って Enter を押して初めて命令が実行されます。Enter を押さない限り、何も起きません。

ミスしても大丈夫です。打ち間違えてもEnterを押さなければ影響ゼロ。押した後でも「元に戻す」コマンドで取り消せる操作がほとんどです。

開き方：
Windows：「Windowsキー」を押して「powershell」と検索 →「Windows PowerShell」をクリック
Mac：「アプリケーション」→「ユーティリティ」→「ターミナル」をダブルクリック

「ターミナル」（Windowsなら PowerShell、Macならターミナル）を開いて、以下を入力してEnterを押してください：

node --version

v18.0.0 以上の数字が表示されればOKです。次のセクションに進んでください。
「コマンドが見つかりません」などのエラーが出た場合は、以下でインストールします。

ターミナル（黒い画面）の開き方 Windows：キーボードの「Windows キー」を押して「powershell」と検索 → 「Windows PowerShell」をクリック
Mac：「アプリケーション」→「ユーティリティ」→「ターミナル」をダブルクリック

Node.js のインストール手順

1 nodejs.org/ja をブラウザで開く
2 「LTS」と書かれたボタン（推奨版）をクリックしてダウンロード
3 ダウンロードしたファイルを開き、「次へ」を押し続けてインストール完了
4 PCを一度再起動する
5 ターミナルを開いて node --version と打ち、数字が表示されれば成功
「LTS」って何ですか？どれを選べばいい？

LTS は「Long Term Support（長期サポート版）」の略です。安定していて、長期間セキュリティ対応がされるバージョンという意味です。

一般的な用途では必ずこちらを選んでください。もう一方の「最新版（Current）」は新機能が試せますが不安定なことがあるため初心者には向きません。

4 Claude Code のインストール

Node.js が入ったら、Claude Code をインストールします。ターミナルに以下をそのままコピー＆ペーストしてEnterを押してください：

「npm install」って何をしているの？怪しいコマンドじゃないですか？

npm（エヌピーエム）は「Node Package Manager」の略で、ソフトウェアを安全に配布・管理するための公式の仕組みです。スマートフォンの「App Store」や「Google Play」に近いイメージです。

npm install -g @anthropic-ai/claude-code は「Anthropic（Claudeの開発会社）が公開しているClaude Codeというソフトを、公式の配布場所からダウンロードしてインストールする」という命令です。

@anthropic-ai の部分が重要です。これはAnthropicの公式パッケージであることを示すIDです。まったく知らない会社のコマンドを実行するわけではありません。

-g は「このパソコン全体で使えるようにする」という意味のオプションです。

npm install -g @anthropic-ai/claude-code
インストール中に英語がたくさん流れてきた。エラーですか？

大丈夫です。npm install は「何をダウンロードしているか」をリアルタイムで表示するため、大量の英語が流れます。これは正常な動作です。

問題ない場合のサイン（最後にこういった表示が出る）：
「added ○○○ packages」「Successfully installed」など

問題がある場合のサイン：
「Error」「ERR!」などの赤い文字が大量に出る場合はエラーです。その画面をスクリーンショットして保存しておくと、後でAIに見せて解決策を聞けます。

黄色い「WARN」という文字は「警告」ですが、ほとんどの場合は無視して問題ありません。

最後に「Successfully installed」のような表示が出ればインストール完了です。

エラーが出た場合（Windowsのみ） PowerShell を「管理者として実行」してから同じコマンドを試してください。
スタートメニューで「powershell」を右クリック →「管理者として実行」を選択。
「管理者として実行」って何ですか？やって大丈夫ですか？

Windowsでは、パソコン全体に関わる変更（ソフトのインストールなど）には「管理者権限」が必要な場合があります。「管理者として実行」とは、その権限を持った状態でPowerShellを起動することです。

家で例えるなら「合鍵を使って家の中の大きな家具を動かせる状態」のようなイメージです。

このガイドで紹介しているコマンドはすべて安全です。Anthropicの公式ドキュメントに記載されたコマンドのみを使っています。

ただし一般的な注意として、知らない人から「このコマンドを管理者権限で実行して」と言われた場合は実行しないようにしてください。

インストールできたか確認する

claude --version

バージョン番号が表示されればOKです。

5 作業フォルダを準備する

Claude Code は「フォルダ」を単位として動きます。AIと一緒に仕事をするための専用フォルダを用意しましょう。

おすすめの保存場所

Dropbox や OneDrive などのクラウド同期フォルダの中に作ることをおすすめします。理由：

  • パソコンが壊れても自動でバックアップされている
  • 別のPCからも作業できる
  • 速度が安定している
1 Dropbox（または OneDrive / Googleドライブ）フォルダを開く
2 新しいフォルダを作る（例：「AI作業フォルダ」「マイAIワークスペース」など好きな名前でOK）
3 そのフォルダの「パス（場所）」をメモしておく
例（Windows）：C:\Users\あなたの名前\Dropbox\AI作業フォルダ
例（Mac）：/Users/あなたの名前/Dropbox/AI作業フォルダ
「パス」って何ですか？どうやって調べればいい？

パス（path）とは、パソコンの中でファイルやフォルダがどこにあるかを示す「住所」のことです。

C:\Users\田中\Dropbox\AI作業フォルダ は「Cドライブの中の、田中というユーザーフォルダの中の、Dropboxフォルダの中の、AI作業フォルダ」という意味です。

パスを調べる方法（Windows）：
エクスプローラーでフォルダを開く → 上部のアドレスバーをクリック → パスが全部表示される → 右クリックでコピー

パスを調べる方法（Mac）：
フォルダを右クリック → 「情報を見る」→「場所」の欄に表示される
または：フォルダを開いた状態で「command + option + P」を押すと下部にパスが表示される

スペースが含まれる場合：パスの中にスペース（空白）が含まれるときは、コマンドに使うときに前後を "（ダブルクォーテーション）で囲む必要があります。このガイドではそのようにしています。

6 データを守る仕組みを作る（Git）

「Git（ギット）」は、ファイルの変更履歴を自動的に記録してくれるツールです。ゲームの「セーブデータ」と同じ仕組みで、AIが誤ってファイルを変えてしまっても一瞬で元に戻せます。

Gitって本当に必要ですか？なんだか難しそうで不安です

正直に言うと、Gitがなくても Claude Code は動きます。ただし、AIが間違えたときに取り返しがつかなくなります。

AIは「よかれと思って」ファイルを大量に変更することがあります。1〜2ファイルなら手動で直せますが、10個・20個となると現実的ではありません。

Gitを使うコマンドは実際には3つだけです：

  • git add .（セーブの準備）
  • git commit -m "名前"（セーブ実行）
  • git restore .（元に戻す）

これだけ覚えれば十分です。AIに「Gitでセーブして」と頼めば代わりにやってもくれます。

なぜ必要か AIは一度に大量のファイルを変更できます。Gitがあれば「元に戻して」の一言で完全に復元できます。必ず設定しておきましょう。

① Git をインストールする

ターミナルで確認：

git --version

数字が表示されれば入っています。表示されなかった場合：

インストール方法 Windows：git-for-windows.github.io からダウンロードし、全て「Next」でインストール
Mac：ターミナルで xcode-select --install と打つと自動でインストールされます

② 名前とメールを登録する（最初の1回だけ）

以下を1行ずつ実行してください。名前とメールは自分のものに変えてください：

git config --global user.name "あなたの名前"
git config --global user.email "あなたのメール@example.com"
なぜ名前とメールが必要なの？どこかに送られる？

Gitは「誰がいつセーブしたか」を記録するために名前とメールを使います。これはあなたのパソコンの中だけに保存されるものであり、外部に送信されることはありません。

GitHub などのサービスと連携する場合は表示されることがありますが、このガイドの範囲ではパソコン内で完結します。架空の名前でも動作しますが、後で見たときに自分とわかる名前にしておくと管理しやすいです。

③ 作業フォルダをGit管理下に置く

「git init」で何が起きますか？パソコン全体に影響しない？

git init は「このフォルダをGitで管理し始める」という宣言です。フォルダの中に「.git」という小さな隠しフォルダが作られるだけで、それ以外は何も変わりません。

パソコン全体には一切影響しません。このフォルダの中だけの変更履歴を記録する準備が整うイメージです。

後でGit管理をやめたい場合は「.git」という隠しフォルダを削除するだけでOKです。

作業フォルダの中でターミナルを開き、以下を順番に実行します：

git init
「git add .」の「.（ドット）」って何ですか？

「.（ドット）」は「このフォルダの中にある全てのファイル」を意味するショートカット記号です。

つまり git add . は「フォルダ内の全ての変更ファイルを、次のセーブの対象にする」という意味です。

特定のファイルだけ対象にする方法もありますが、最初は全部まとめてセーブする git add . で問題ありません。

git add .
git commit -m "はじめてのセーブ"
「git commit -m "..."」の -m と「" "」って何ですか？

-m は「メッセージ（message）」の略で、「このセーブにメモを付ける」という意味のオプションです。

"はじめてのセーブ" の部分が実際のメモ内容です。あとで「いつ何をセーブしたか」を見返すときのための名前です。日本語でも英語でも好きな言葉でOKです。

例えば「提案書修正前」「会議資料完成版」など、内容がわかる名前にしておくと便利です。

フォルダの中でターミナルを開く方法（Windows） エクスプローラーで作業フォルダを開く → アドレスバーに powershell と入力 → Enter
何かおかしくなったときの復元コマンド（覚えておいてください） git restore . と打つと、最後にセーブした時点に全ファイルが戻ります。
「git restore .」で本当に元に戻りますか？戻しすぎることはない？

git restore . は「最後に git commit した時点」に戻ります。それより古いセーブには戻りません。

イメージとしては「直前のセーブポイントに戻る」だけです。その1つ前のセーブには影響しません。

注意：コミット後にセーブしていない変更は消えます。「やっぱり戻したくない」と思った場合でも、一度実行すると取り消せません。迷ったら実行前にAIに「どうなるか確認して」と聞いてから実行しましょう。

7 Claude Code を起動して確認する

ターミナルで作業フォルダに移動してから、Claude Code を起動します。

作業フォルダに移動する

「cd」コマンドって何をしているの？なぜ移動が必要？

cd は「Change Directory（ディレクトリを変える）」の略です。ターミナルが「今どのフォルダを作業対象にしているか」を切り替えるコマンドです。

エクスプローラーで「フォルダをダブルクリックして開く」のと同じ感覚です。

Claude Code は「今いるフォルダ」を基準に動くため、作業フォルダに移動してから起動する必要があります。移動せずに起動すると、別の場所（デスクトップなど）で作業してしまいます。

パスにスペースが含まれる場合：前後を " で囲んでください。囲まないとエラーになることがあります。

cd "C:\Users\あなたの名前\Dropbox\AI作業フォルダ"

（Macの場合は /Users/あなたの名前/Dropbox/AI作業フォルダ のように入力）

Claude Code を起動する

claude

初回起動時はログイン画面が表示されます。Claude.ai のアカウントでログインしてください。

ログイン画面が出た。アカウント情報は安全ですか？

Claude Code のログインはAnthropicの公式サーバーを通じて行われます。パスワードをターミナルに直接入力するわけではなく、ブラウザが自動的に開いてclaude.ai の通常のログイン画面が表示されます。

ログインが完了すると「認証トークン」という一時的な鍵がパソコンに保存され、次回からはこの鍵で自動的に認証されます。パスワード自体はパソコンに保存されません。

この仕組みはGoogleやMicrosoftのサービスと同様の「OAuth認証」という方式で、業界標準の安全な仕組みです。

起動成功のサイン 「>」のような入力欄が表示されれば成功です！ここにメッセージを入力するとAIが返答します。

試しに以下と入力してみましょう：

こんにちは！何ができるか教えてください。

セットアップ完了！

ここからが本番です。あなただけのAIパートナーを作りましょう。

8 あなただけのAIパートナーを作る

Claude Code は「設定ファイル」を用意することで、AIの話し方や行動ルールをカスタマイズできます。この設定ファイルのことを CLAUDE.md（クロード エムディー）と呼びます。

テキストファイルを置くだけで本当にAIの動きが変わるの？

はい、本当に変わります。Claude Code は起動するたびに、作業フォルダ内の「CLAUDE.md」というファイルを自動的に読み込みます。

このファイルに書かれた内容がそのままAIへの「事前指示」として機能するため、名前・話し方・行動ルールを書いておくと毎回同じ設定でAIが動きます。

設定が反映されているか確認したい場合：起動後に「あなたの名前は？」と聞いてみてください。設定した名前で答えてくれれば成功です。

CLAUDE.md って何？ 作業フォルダの中に置くテキストファイルです。Claude Code はこのファイルを毎回自動で読み込むため、「このAIは常にこう振る舞う」という設定が固定されます。いわばAIへの「お仕事の説明書」です。

パートナーの名前を決めましょう

AIパートナーにはどんな名前でも付けられます。仕事のパートナーらしい名前でも、親しみやすいニックネームでも構いません。

好きな名前を自由に決めてください

例：「ソラ」「ハナ」「アシスト」「Nova」「Sora」「Leo」など、なんでもOK

名前が決まったら、以下のどちらかの方法で設定します。

方法A（おすすめ）— Claude Code に作ってもらう

Claude Code を起動した状態で、以下のメッセージを送るだけでパートナー設定ファイルが自動で作られます。[　] の部分を自分の名前・パートナーの名前に変えてからコピーしてください。

今日から私のAIパートナーとして一緒に働いてもらいます。
まず、この作業フォルダに「CLAUDE.md」というファイルを作ってください。

設定内容：
- パートナーの名前：[パートナーの名前をここに入力]
- 私の名前：[あなたの名前をここに入力]
- 話し方：むずかしい専門用語は使わず、親しみやすくわかりやすく話す
- ルール①：ファイルの削除・大きな変更をする前は「〜してもよいですか？」と必ず確認する
- ルール②：指示の意味がわからないときは勝手に進めず質問する
- ルール③：作業が終わったら「〜が完了しました」と必ず報告する
- 会話の始め方：毎回「こんにちは、[あなたの名前]さん！[パートナーの名前]です。今日は何をお手伝いしますか？」と挨拶する

ファイルを作ったら内容を見せてください。

Claude Code がファイルを作成したら、ターミナルを一度閉じて再起動してください。次回から設定が有効になります。

方法B — 自分でファイルを作る（より細かくカスタマイズしたい方向け）

以下のテンプレートをコピーして、[　] 内を書き換えてから「CLAUDE.md」という名前で作業フォルダに保存します。

# AIパートナー設定

## 基本情報
- パートナーの名前：[パートナーの名前を入力]
- あなたの名前：[あなたの名前を入力]

---

## パートナーの役割

あなたは [あなたの名前] さんをサポートするAIパートナー「[パートナーの名前]」です。
文章の作成・修正、アイデア整理、調べ物など、どんな依頼にも前向きに取り組みます。

## 話し方のルール

- むずかしい専門用語は使わず、やさしい言葉で話す
- 正直に、親しみやすく接する
- わからないことは「わかりません」「確認が必要です」とはっきり伝える
- 返答は長くなりすぎず、大切なことを先に伝える

## 仕事の進め方

- ファイルの削除・大きな変更をする前は「〜してもよいですか？」と必ず確認する
- 指示の意味がわからないときは勝手に進めず質問する
- 作業が終わったら「〜が完了しました」と必ず報告する

## 会話の始め方

新しい会話が始まったら、必ずこのように挨拶してください：
「こんにちは、[あなたの名前]さん！[パートナーの名前]です。今日は何をお手伝いしますか？」
「CLAUDE.md」として保存する方法（Windows） メモ帳（Notepad）を開く → 内容を貼り付ける → 「名前を付けて保存」→ ファイル名を CLAUDE.md と入力 → 「ファイルの種類」を「すべてのファイル」に変更 → 保存
「すべてのファイル」に変更しないとどうなる？

メモ帳（Notepad）でそのまま保存すると、ファイル名が「CLAUDE.md.txt」になってしまいます（.txt という拡張子が自動でつく）。これでは Claude Code が認識できません。

「ファイルの種類」を「すべてのファイル」に変えることで、拡張子を自分で指定できるようになります。ファイル名を CLAUDE.md と入力すれば、.md で保存されます。

保存後、エクスプローラーでファイル名が CLAUDE.md（.md だけ）になっていることを確認してください。

はじめてのパートナーとの会話

CLAUDE.md を設定して Claude Code を再起動したら、以下のメッセージを送って関係をスタートさせましょう：

はじめまして！これから一緒に働きましょう。
まず自己紹介をしてください。
それから私のことをもっと知るために、次の2つを聞いてください：
1. 主にどんな仕事や作業でサポートを使いたいか
2. AIに特に得意になってほしいことは何か
パートナーがうまく機能しているサイン 毎回の会話が「こんにちは、〇〇さん！△△です。」という挨拶から始まるようになれば、設定が正しく読み込まれています。

パートナーへの上手な頼み方

  • 具体的に伝える：「文章を直して」より「この文章を小学生でも読めるくらいやさしくして」
  • 背景を伝える：「これはお客さんに送るメールです」のように用途を教えると精度が上がります
  • 「〇〇してから進めて」：大きな作業の前に「保存してから作業して」と一言添えると安全です
  • 迷ったら聞いてと言う：「やり方が複数ある場合は先に相談して」と伝えると勝手に進みません

9 毎日の使い方とコツ

毎日の起動手順

1 ターミナルを開く
2 作業フォルダに移動する：cd "作業フォルダのパス"
3 Claude Code を起動：claude
4 パートナーが挨拶してくれたら作業開始！

大きな作業の前のひと手間（習慣にしてください）

AIに大量のファイルを変更させる前に、必ずGitでセーブしておきましょう：

git add .
git commit -m "作業前バックアップ"

または、パートナーに「作業前にGitでセーブしてから進めて」と一言添えるだけでもOKです。

何かおかしくなったとき

git restore .

このコマンド1行で、最後にセーブした状態に全ファイルが戻ります。

10 よくある質問

Q. パートナーの名前は後から変更できますか？
はい。CLAUDE.md ファイルの名前の部分を書き換えるだけで変更できます。パートナーに「名前を〇〇に変更して」と頼むこともできます。
Q. Claude Code を閉じてもパートナーの設定は消えませんか？
CLAUDE.md ファイルとして保存されているので、次回起動時にも同じ設定で動きます。
Q. 無料で使えますか？
Claude Code の本体ソフトは無料でインストールできますが、使用にはClaude.ai の有料プラン（Proプラン）またはAPIキーが必要です。
Q. パートナーに言ってはいけないことはありますか？
パスワード、クレジットカード番号、個人情報などは入力しないようにしましょう。AIとの会話はAnthropicのサーバーを通じて処理されます。
Q. Gitのコマンドが怖くて使えません
パートナーに「Gitで今の状態を保存して」と日本語でお願いすれば、代わりにコマンドを実行してくれます。
Q. CLAUDE.md を作ったのに挨拶してくれません
Claude Code を一度完全に終了して、ターミナルも閉じてから再起動してみてください。再起動後に設定が読み込まれます。
Q. 途中でやめても大丈夫ですか？
はい。ターミナルをいつでも閉じて終了できます。次回、作業フォルダで claude を起動すれば続きから使えます。インストールしたものが消えることもありません。
