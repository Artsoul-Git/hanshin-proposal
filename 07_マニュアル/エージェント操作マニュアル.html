1このマニュアルで何ができるようになるか

このマニュアルを読むと、AS株式会社の11種類のAIエージェントを使って、新規クライアントの初回面談から6ヶ月後の自走化・Phase 3継続まで、一連のコンサルティング業務をひとりで回せるようになります。

現在、AS株式会社のコンサルティング業務には以下の11種類のエージェントが設計されています。

まる様案件のような実際の案件では、このフロー通りに進みます：
初回面談（無料）→ INTAKE が事前アンケートを送付 → DEAL が提案書作成 → 受注後に INTAKE（ヒアリングシート）→ MAPPER（訪問）→ ANALYST・PLANNER（フロー図）→ COACH（手順書）→ BLUEPRINT（スペシャル資料¥132,000）→ 解説会 → 伴走プラン選択

2準備するもの

  • Claude Code または Claude.ai へのアクセス（有料プラン推奨）
  • このプロジェクトフォルダ（D:\Google Antigravity\AS_AI導入支援事業_cc\）
  • 各エージェントのmdファイル（03_コンサル・実務支援\agents\ 内）
  • クライアントから収集した情報（面談メモ、書類スキャン等）
  • クライアント案件フォルダ（05_クライアント案件\YYYYMMDD_会社名\）

3用語の事前説明

エージェント
特定の役割・手順・出力形式が定義されたClaudeの「仮面」のこと。「MAPPER として動いて」と指示すると、mapper.md の定義通りに動く。
引き継ぎパッケージ
あるエージェントから次のエージェントへ渡す情報セット。たとえば MAPPER が ANALYST に渡す「訪問ヒアリングメモ＋預かり書類リスト」がそれ。
ロードマップ策定フェーズ
ACTモデルに入る前の「まず設計図だけ作りましょう」サービス（¥110,000〜）。MAPPER が担当。まる様案件で実際に行ったフロント商品。
ACTモデル（AI Core Transformation）
AS株式会社のメインサービス。Phase 1（月30万 × 3ヶ月）→ Phase 2（月15万 × 3ヶ月）→ Phase 3（月5万 顧問）の6ヶ月＋継続プログラム。
AIマネージャー
クライアント社内でAI活用を推進する担当者。研修で育成し、6ヶ月後には自走できる状態を目指す。
自走化（じそうか）
クライアントが「AS株式会社に頼らなくてもAI活用の月次改善を自分で回せる」状態。6ヶ月後のゴール。
クイックウィン
Month 2 に最初の成果を出すための「最も効果が高く・最も実現しやすい」改善施策。現場の信頼を得るために早期に成果を見せる。
B/A分析（Before/After分析）
AI導入前後の業務時間・コストを比較して「どれだけ良くなったか」を数字で示す分析。TRACKERが毎月生成する。
プロンプト v1→v2→v3
業務自動化に使うAIへの指示文（プロンプト）を、現場のフィードバックをもとに3回改善していくサイクル。COACHが管理する。
ライモBiz
AS株式会社が研修で使用するAI活用プラットフォーム。ミニアプリ開発・AIスタジオ・チャットボット作成などができる。

参照ファイル 02_営業・マーケティング\agents\deal.md

使うタイミング

  • SNS・紹介・無料診断フォームから問い合わせが来たとき（リードスコアリング）

17よくあるトラブルと対処

トラブル1：エージェントが「想定と違う出力」をする

原因：インプット情報が少なすぎる or エージェント名の宣言が抜けている

対処：「intake.md のロールで動いてください」の一行を必ず最初に入れる。情報が足りない場合はエージェントに「不明な点があれば質問してください」と追記する。

トラブル2：ROI試算の数字がおかしい

原因：スタッフ数・時給・業務頻度などの前提数値を与えていない

対処：「スタッフ時給：¥1,200、管理者時給：¥1,500、月稼働日数：20日」のように具体的な数値を必ず渡す。

トラブル3：引き継ぎパッケージが不完全

原因：引き継ぎを依頼しないまま次のエージェントを呼んだ

対処：「○○エージェントへの引き継ぎパッケージをまとめてください」と明示的に依頼してから次に進む。まとめたパッケージを次の指示の冒頭に貼り付ける。

トラブル4：クライアントの業務名が汎用的になってしまう

原因：業種・具体的な業務名を渡していない

対処：「日報作成（毎日17:00実施）」「出退勤簿の転記（月末に国保連システムへ入力）」のように、現場の言葉・タイミング・対象システムを具体的に渡す。

トラブル5：PIPELINEのアラートが正常に機能しない

原因：KPIデータが週次で揃っていない

対処：AIマネージャーへのKPIデータ提出リマインドをメール文案（email_templates.md）で準備しておく。

トラブル6：MAPPERとINTAKEで二重作業になった

原因：MAPPERフェーズでヒアリングシート作成済みなのに、ACTモデル開始時にINTAKEに同じ作業を依頼してしまった

対処：ACTモデル開始時にINTAKEへ「MAPPERフェーズで作成・回収済みのヒアリングシートがあります。引き継ぎ確認とANALYSTへの引き継ぎパッケージ作成のみ行ってください」と伝える。

18用語集（詳細版）

ACTモデル（AI Core Transformation）
AS株式会社のメインサービス。Phase 1（月30万 × 3ヶ月）→ Phase 2（月15万 × 3ヶ月）→ Phase 3（月5万 顧問継続）の6ヶ月プログラム。LTV は平均215万円。
AIマネージャー
クライアント社内でAI活用を推進する内部担当者。TRAINERが育成し、COACHが能力開発し、GROWERが自走化させる。
As-Is / To-Be
As-Is = 現状の姿（Before）。To-Be = あるべき姿・改善後の姿（After）。ANALYSTが現状マップ（As-Is）を作り、PLANNERがTo-Beを設計する。
B/A分析（Before/After分析）
AI導入前後の数値比較。TRACKERが毎月生成する。「月○時間削減・月○万円削減」の数字がこれで出る。
クイックウィン
Month 2 に最初の成果を出すための最優先施策。「最も効果が高く・最も実現しやすい」業務を選ぶ。現場のモチベーション維持のために必須。
ライモBiz
AS株式会社が研修・支援で使用するAIプラットフォーム。ミニアプリ開発・AIスタジオ・QAボット作成・AIパンフレットなどの機能を持つ。
ミニアプリ
ライモBizで作成する「現場専用のAI入力ツール」。たとえば「日報を音声入力→自動でフォーマット化して出力するアプリ」など。COACHが設計書を作り、巧（AI社員）が実装する。
SOP（Standard Operating Procedure）
標準操作手順書。プロンプト v3 が完成したタイミングで COACHが設計する。「誰でも・同じ品質で・5分以内に」業務を実行できるようにする文書。
自走化スコア
GROWERが評価する「AIマネージャーの自立度」。6項目 × 5段階評価で最大30点。26点以上でPhase 3 移行可と判定される。
引き継ぎパッケージ
あるエージェントから次のエージェントへ渡す構造化データ。たとえば「TRAINER → COACH 引き継ぎパッケージ」には「修了者情報・AIマネージャー候補評価・フォロー状況・COACHへの引き継ぎ事項」が含まれる。
スペシャル資料
BLUEPRINTが生成するロードマップ策定の最終成果物。GWS導入完全ガイド・ライモBizミニアプリ仕様書・6ヶ月超詳細ロードマップ・AI研修計画・アップセール提案書の6部構成。¥110,000〜¥132,000の料金内で提供される。
伴走プランS/A/B/C（アップセール）
BLUEPRINTのスペシャル資料内に含まれる4つのアップセールプラン。S=自走（¥0、DIYで実施）、A=¥5万/月（月次レポート+チャットサポート）、B=¥15万/月（隔週コーチング+KPIダッシュボード）、C=¥30万/月（週次コーチング+ミニアプリ開発+月次訪問）。
Phase移行判定
PIPELINEとGROWERが連携して行う「Phase 2 → Phase 3 に進んでいいか」のチェック。6項目のうち全達成でPhase 3 移行可となる。
ROI試算（Return on Investment）
投資回収の計算。「¥○○万円の投資に対して、○ヶ月で回収できる」を数字で示す。ANALYSTが3パターン（保守的・標準・楽観）で計算する。
