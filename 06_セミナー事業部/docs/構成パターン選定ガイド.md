# セミナー構成パターン選定ガイド

## 5つのパターン

| パターン | YAML | ゴール | 営業圧 |
| --- | --- | --- | --- |
| 情報提供型 | pattern-information | 理解と気づき | 低 |
| 製品紹介型 | pattern-product-launch | 認知・興味喚起・体験申込 | 中〜高 |
| 教育型 | pattern-educational | スキル習得 | なし |
| 営業型 | pattern-sales | リード獲得・受注 | 高 |
| ストーリー型 | pattern-story | 感情的共感・ブランド記憶 | 低 |

## 選定の判断軸

### 主催者の最終ゴール
- リード獲得・受注 → sales
- 新商品認知 → product_launch
- 業界知識共有 → information
- 受講者育成 → educational
- ブランディング・採用 → story

### 参加者の動機
- 学びたい → information / educational
- 買いたい → product_launch / sales
- 知りたい → information / story

### 構成の特徴

#### sales（営業型）
- オープニング → 共感 → 課題 → 解決策 → 事例 → 価値訴求 → 特典 → CTA → Q&A
- 個別相談誘導が最大目的

#### information（情報提供型）
- オープニング → アイスブレイク → 現状認識 → 課題分析 → 解決の方向性 → クロージング → Q&A
- 営業圧ゼロ、純粋な知識共有

#### story（ストーリー型）
- フック（引用） → 起承転結（4幕） → メッセージ → CTA → Q&A
- 感情ベースで記憶に残す
