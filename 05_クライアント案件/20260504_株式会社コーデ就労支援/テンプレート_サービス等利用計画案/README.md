# 書類1 サービス等利用計画案 テンプレート

## 保存物
- `create_service_plan_template.gs`（GAS）
- `書類1_サービス等利用計画案_未記入テンプレート.xlsx`（Excel）

## GASの使い方
1. Googleスプレッドシートを新規作成
2. 拡張機能 → Apps Script を開く
3. `create_service_plan_template.gs` の中身を貼り付けて保存
4. `createServicePlanTemplate()` を実行
5. 生成されたスプレッドシートURLをログから開く

## 再現方針
- PDFの2ページ構成を `書式本体_1of2` と `週間計画表_2of2` で再現
- 個人情報欄は空欄化
- 罫線・結合セルを使って書式を再現
- 入力軽減として以下を追加
  - 達成時期/評価時期: プルダウン
  - サービス選択: チェックボックス

## 注意
- 元PDFが画像ベースのため、GASの自動描画では印刷時のミリ単位一致までは保証できません。
- レイアウトは大枠を忠実に再現し、運用時の入力性を優先して微調整しています。
- 印刷帳票として完全一致が必要な場合は、Excel版をベースに最終微調整してください。
