## 2. カラーパレット

### メインカラー（グリーン系）

| ロール | 色名 | HEX | 用途 |
|--------|------|-----|------|
| プライマリ | オリーブグリーン | `#6F911D` | ヘッダーバー・強調テキスト・ボーダー |
| プライマリ（濃） | ディープグリーン | `#5E791A` | ボタン・番号ラベル影 |
| ライトグリーン1 | ミドルグリーン | `#A6BE54` | サブアクセント・バッジ |
| ライトグリーン2 | ソフトグリーン | `#C2D580` / `#C7D99B` | 背景パネル・カードアクセント |
| バックグラウンド | ペールグリーン | `#E8F1D8` | 薄い背景・ストライプ |

### アクセントカラー

| ロール | 色名 | HEX | 用途 |
|--------|------|-----|------|
| 強調 | ブライトイエロー | `#FABE00` / `#F9D30C` / `#FBDA03` | キーワードハイライト・セクションアクセント |
| ポイント | スカイブルー | `#38B6FF` | 特定キーワード強調（散発的使用） |

### ベースカラー

| ロール | 色名 | HEX | 用途 |
|--------|------|-----|------|
| 背景（ダーク） | チャコール | `#333333` | ダーク系スライド背景 |
| 背景（ミッドダーク） | ダークグレー | `#404040` / `#3F3F3F` | 問いかけスライド背景 |
| テキスト（ダーク） | ブラック | `#000000` / `#333333` | 白背景上の本文 |
| テキスト（ライト） | オフホワイト | `#EDEDED` / `#FFFFFF` | ダーク背景上のテキスト |
| 白 | ホワイト | `#FFFFFF` / `#FEFEFE` | 背景・反転テキスト |

### カラー使用ルール

- **緑背景 → 白テキスト**（コントラスト確保）
- **白背景 → グリーン（#6F911D）か ダークグレー（#333333）テキスト**
- **ダーク背景 → 白 or 明るいグリーン（#C7D99B）テキスト**
- **黄（#FABE00）はキーワード単語レベルの強調のみ**（文章全体への使用は避ける）

## 3. フォント

### 使用フォント一覧

| 優先度 | フォント名 | 用途 |
|--------|-----------|------|
| 第1 | **Noto Sans JP Bold** | 日本語メイン（見出し・本文） |
| 第2 | **Zen Maru Gothic Bold** | 柔らかい丸ゴシック（サブタイトル・吹き出し） |
| 第3 | **ZEN角ゴシックNEW Bold** | クリーンな角ゴシック（テクニカル文） |
| 第4 | **ヒカリ角ゴ Bold** | ヘッダー見出し（インパクト系） |
| 装飾 | **モトヤマルベリみやび** | タイトル装飾・ブランド名（使用頻度低） |
| 英数字 | **Calibri (MS) Bold** | 英数字・記号 |

### フォント運用

- **全スライドを通じてBold（太字）が原則**。細字（Regular）は使用しない。
- 日本語が主体のため、英数字も日本語フォントに揃える（混在しない）。
- フォールバック：Noto Sans JP → Meiryo → ヒラギノ角ゴ

## 4. フォントサイズ体系

単位はポイント（pt）。スライドの実測値から。

| 名称 | サイズ | 用途 |
|------|--------|------|
| 超特大（インパクト） | 108–144 pt | 問いかけの核心語・強烈なメッセージ |
| 特大 | 90–92 pt | タイトルスライドメインタイトル |
| 大見出しA | 72–75 pt | セクション区切り・コア文 |
| 大見出しB | 66 pt | スライドタイトル（各スライド共通） |
| 中見出し | 54–56 pt | サブ見出し・節タイトル |
| 小見出し | 48–50 pt | コンテンツブロック見出し |
| 本文大 | 42–45 pt | メイン本文テキスト |
| 本文小 | 36 pt | 補足説明・ステップ文 |
| 注釈 | 28–32 pt | キャプション・時間帯・補足 |
| 番号ラベル | 30 pt | ①②③番号バッジ内テキスト |

## 5. スライドタイプとレイアウトパターン

### タイプ A：タイトルスライド

```
[キャンバス 50.8 × 28.58 cm]
┌─────────────────────────────────────────┐
│ ████████████ 緑バナー(高さ約7cm) ████████ │ ← #6F911D
│                                          │
│         メインタイトル（92pt, 白）       │
│                                          │
│         サブタイトル（48-54pt）          │
│                                          │
│                        ブランド名（右下）│
└─────────────────────────────────────────┘
```

- 上部：緑（#6F911D）の横断バナー（高さ約7cm）
- バナー下：白背景
- メインタイトル：右寄り配置、92pt、白
- サブタイトル：同エリア、48-54pt、緑 or ダーク
- ブランドロゴ：右下角、緑テキスト

---

### タイプ B：セクション見出しスライド

```
┌─────────────────────────────────────────┐
│                                          │
│   ●●●●●  黄アクセントバー              │ ← #F9D30C
│                                          │
│      セクションタイトル（54pt, 白）      │
│                                          │
│         （チャコール背景 #333333）        │
└─────────────────────────────────────────┘
```

- 背景：チャコール（#333333）一色
- 黄色（#F9D30C）の横線 or バッジアクセント
- テキスト：54pt、白（#FFFFFF）
- シンプル・余白大きめ

---

### タイプ C：問いかけ・インパクトスライド

```
┌─────────────────────────────────────────┐
│ ██ 緑タグ（66pt）                        │
│                                          │
│   メインメッセージ（108pt, 白 or 緑）    │
│                                          │
│         ダークグレー背景 #404040         │
└─────────────────────────────────────────┘
```

- 背景：ダークグレー（#404040）
- 上部：緑（#6F911D）の小テキスト or バー（66pt）
- メイン：超大テキスト（108pt）、白 or 緑
- 余白を大胆に使い「問いかけ感」を演出

---

### タイプ D：コンテンツ（箇条書き）スライド

```
┌─────────────────────────────────────────┐
│ ████ スライドタイトル（66pt, 緑）         │ ← 緑テキスト or 緑バー
│─────────────────────────────────────────│
│                                          │
│  ■ 本文テキスト（42-45pt）               │
│  ■ 本文テキスト                          │
│  ■ 本文テキスト                          │
│                                          │
│         白背景 #FFFFFF                   │
└─────────────────────────────────────────┘
```

- 白背景
- タイトル：上部左寄せ、66pt、#6F911D
- 本文：42-45pt、#333333 or #404040
- 箇条書き or カードブロック構成

---

### タイプ E：ステップ/番号スライド

```
┌─────────────────────────────────────────┐
│ タイトル（66pt, 緑）                      │
│─────────────────────────────────────────│
│  [01]  ステップ1テキスト（36-50pt）       │
│  [02]  ステップ2テキスト                  │
│  [03]  ステップ3テキスト                  │
│  [04]  ステップ4テキスト                  │
└─────────────────────────────────────────┘
```

- 番号バッジ：#6F911D 背景 + 白テキスト（30pt）
- ステップ本文：36-50pt、#333333
- 番号は2桁ゼロ埋め（01, 02...）

## 6. 共通デザイン要素

### ヘッダーバー（各スライド共通）

- 緑（#6F911D）の横断バー or テキストヘッダー
- 高さの目安：キャンバス高の約7-10%（約2-3cm）
- スライドタイトルを内包

### テキストスタイル

| 要素 | 指定 |
|------|------|
| 基本ウェイト | Bold（全体） |
| 行間 | 広め（1.2-1.5倍） |
| 文字間隔 | 標準（カーニングなし） |
| アライメント | 左揃え基本（タイトルスライドは中央 or 右） |
| 句読点 | あり（日本語標準） |

### シェイプ・装飾

- **角丸矩形** を多用（カード・ボックス表現）
- 番号バッジ：緑（#6F911D）背景の角丸四角または円
- フリーフォーム（Freeform）でダイナミックな区切りを演出
- 影（シャドウ）は最小限 or なし → フラットデザイン傾向

### アイコン・画像

- SVG形式のアイコンを使用（多数）
- 写真は補助的（必要時のみ PNG）
- 人物・キャラクターイラスト系を多用

  --color-mid-bg:         #404040;
  --color-body-text:      #333333;

  /* フォントサイズ（スライド比率ベース） */

  --fs-title:    5.75rem;   /* 92pt相当 */

  --slide-ratio: 16 / 9;

## 8. スライド生成時の指示テンプレート

AI（Kai）がスライドを生成する際に参照する標準指示文。

```
このスライドは kei_model スタイルで作成してください。

【基本仕様】
- キャンバス: 16:9 ワイドスクリーン
- 背景: タイプに応じて（白 / チャコール#333333 / ダークグレー#404040）
- フォント: Noto Sans JP Bold（日本語）、Calibri Bold（英数字）
- 全テキストBold

【カラー】
- アクセント: グリーン #6F911D（メイン）/ イエロー #FABE00（強調）
- 白背景→緑テキスト、緑背景→白テキスト、暗背景→白テキスト

【スライドタイプ指定】
タイプA（タイトル）/ タイプB（セクション）/ タイプC（問いかけ）/ タイプD（コンテンツ）/ タイプE（ステップ）

【フォントサイズ】
スライドタイトル: 66pt / 本文: 42pt / 強調語: 108pt
```

## 9. デザイン哲学（kei_modelの特徴）

1. **インパクト優先** — 読む前に「雰囲気で伝わる」デザイン。大文字、大余白。
2. **グリーンで統一** — メインカラーの #6F911D が全スライドを貫く軸。ロゴカラーと一致。
3. **ダークとライトのメリハリ** — 問いかけスライドはダーク、解説スライドはホワイト。
4. **太字ゴシック一択** — 細字・明朝は使わない。力強く、視認性最優先。
5. **シンプルなレイアウト** — 1スライド1メッセージ。情報を詰め込まない。
6. **番号バッジ** — ステップ系は緑バッジ+白番号で視覚的序列を示す。
