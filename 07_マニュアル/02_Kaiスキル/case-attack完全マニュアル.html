SECTION 01 / PURPOSE

スキルの位置づけ — 何を攻略するスキルか

/case-attack は新規クライアント候補との商談を「武器」で攻略するためのデモ資料セット制作スキル。15ファイル全部入りで、商談を次のステップに進めるための実装。

SECTION 02 / MINDSET

⚔️ 攻略マインドセット5原則

単純なファイル生成スキルではない。難しい相手・状況・課題を「攻略」するための戦略書として運用すべき5原則。

攻略マニュアル＝難題突破の実務書

「整った文書」より「殴れる文書」を作る

本マニュアルはrules/kai-style-guide.md「完全マニュアル＝攻略マニュアル」ルールに基づき設計されている。手順書ではなく、現場で武器になる実務書。

原則1：型は守る、内容は壊す

越前刃心の「12章構成／五箇条／7施策／マンダラ81セル」は絶対に崩さない。崩していいのは「業種固有の数値・固有名詞・カラーテーマ」のみ。構造を崩すと再現性が消える。

原則2：実データ vs 架空の境界を絶対に守る

会社固有情報（社名・売上・代理店数）のみ架空。市場統計・参照ブランドは実データ＋URL出典。境界が曖昧だと「信用毀損」と「捏造」の両方に陥る。

原則3：3層構造を絶対に守る

クライアント共有可（公開層）／社内ストーリー設定（社内層）／社外秘営業ノウハウ（極秘層）の3層を物理的に分離。1ファイルでも層を間違えると流出事故。

原則4：難題は「フレーム」で攻略する

「いくら？」「AIで作ってるなら安いはず」等の反論は、その場で考えるな。事前に用意した切り返しフレームを出す。反論集（Section 10）を暗記レベルまで習得せよ。

原則5：商談10分以内、デモ閲覧3分以内

全7HTMLを商談で見せようとしない。ポータル＋提案①冒頭＋ラシンバン構造分解＋新販路マップの4ポイントに絞る。残り3HTMLは「持ち帰り用」。

PHASE 0

方針宣言（省略可）

編集系ノンストップモード下では省略。「15ファイル生成します。約1〜2営業日。事前確認したい点ありますか？」

PHASE 1 / 10〜30分

要件整理＋業種選定

5案を生成し、Keiに選択させる。「事業規模／本質課題／異業種転用候補／業界団体機会」を各案1行で提示。

PHASE 2 / 2〜3時間

5MD生成（社内専用）

00_基本情報／01_社長ペルソナ／02_財務／03_経営会議／04_現場ヒアリングの5本。実在企業との直接的関係はゼロ。

PHASE 3 / 30分〜1時間

実データ収集（WebSearch並列）

10件並列検索：国内市場／海外市場／業界統計／参照ブランド／業界団体／規制／隣接市場／EC構造／後継者問題／海外展開事例。

PHASE 4 / 4〜6時間

提案書HTML 4本生成

越前刃心の4本（proposal/global/association/knife_channels）をテンプレに、コピー＋差し替え。出典URL必修。

PHASE 5 / 3〜4時間

ラシンバン 3本生成

アプリ版テンプレ完全継承。DATA部分のみ書き換え。HTML/CSS/JSは触らない。localStorageキーは案件別に独立。

PHASE 6 / 1時間

ポータル index.html

7HTMLへの導線。パスワード記載・社内MD欄は絶対入れない（営業時URL共有用）。

PHASE 7 / 2〜3時間

社外秘攻略マニュアル2本

10章構成の.md＋.html。営業話法・カスタマイズ・AI指示文・反論切り返しを含む。.gitignore追加必修。

PHASE 8 / 1〜2時間

preview実機検証＋Inspect 4点

実装テスト（連鎖動作）／リンク切れ／版番号同期／SVG座標スケール整合性。コンソールエラー0件確認。

SECTION 05 / CASE STUDIES

⚔️ 難題ケーススタディ集

手順通りに進まない難題6パターン。それぞれの状況・打ち手・回避策を実戦シナリオで示す。

CASE 1初回ヒアリングで情報が3項目以下しか取れない

状況：商工会議所での名刺交換のみ、本格ヒアリング機会なし／クライアント側が警戒気味で情報を開示しない
攻略法

Mode C（リサーチ＋ポータル）で軽量版デモを作る。業種＋規模感のみで「同業他社の典型像」として越前刃心型を提示。「貴社の事情に合わせると違うはず」と前置きしながら、想像力を補う材料として見せる。情報を「もらう」ではなく「埋めて見せる」のが攻略の核。

注意

「貴社のはこうじゃないですか？」と決めつけ口調NG。「典型像を見ていただいて、貴社の場合はどこが違うか教えてください」と質問形式に変換。

CASE 2クライアントが「越前刃心と業種が遠すぎる」と懐疑的

状況：越前刃心デモを見せたが「うちはIT企業、刃物メーカーとは違う」と切り捨てモード／構造類似性を理解してもらえない
攻略法

業種ではなく「販路構造」「課題類型」で説明する。「卸ルート」を「販売代理店／パートナー企業」、「研ぎ直し」を「保守サポート」、「業界団体総会」を「業界カンファレンス」に瞬時に翻訳して話す。30秒以内に「貴社の業界ではこれが○○に当たります」と置換実演する瞬発力が攻略の要。

予防策

事前にクライアントの業種に2案件以内に近いカスタマイズ事例を持参する。3案件以上跨ぐと「業種似てない感」が出る。

CASE 3意思決定者が技術出身でAI懐疑派

状況：「AIなんてChatGPTでできる」「これも全部AIで作ってる」と懐疑的／ハルシネーション・誤情報を警戒
攻略法

その場でAIに「中国輸入包丁シェアは何%？」と質問して、AIが捏造数値を出すデモをする。「これを潰すのが我々の仕事」と明示。出典セクションを開き、全URLをスクロールしながら「これは厚労省、これはJETRO、これは農水省」と読み上げる。「AIの限界を知っている専門家」というポジショニングを獲得する。

補強

「設計と判断は私が全部やっています」を繰り返す。Kai標準レポート構成完全マニュアルの存在も補強材料。

CASE 4「予算が決まってからじゃないと動けない」と保留される

状況：興味は示すが「社内で予算化してから連絡します」と先延ばし／3ヶ月後にフォローしても進展なし
攻略法

その場で「ヒアリング自体は3万円（または無料）」と提示し、最小コミットメントを取る。デモ作成は無料で進め、提案書段階で正式見積もり。「予算化前に動く理由」を作るのが攻略。商工会議所・銀行紹介ルートの場合、紹介者を巻き込んで「予算化の社内根回し」を支援する形にする。

トラップ回避

「無料でデモまで」を3案件以上同時並行しない。受注確度の低い案件で時間を食われる。3ヶ月ルール（フォロー3回で進展なければ離脱）を厳守。

CASE 5クライアント側で「内製化したい」と言い出される

状況：デモを見せた後「貴社のフォーマットだけ教えてもらえれば、うちで作ります」と内製案を出される／受注機会を失う寸前
攻略法

素直に「テンプレートだけ買い切りで100万円、運用支援付きなら月20万円」など、内製化前提の価格表を即座に提示する。デモ実物は渡さず、テンプレート＋研修＋四半期レビュー支援のセット販売に切り替える。「ノウハウの切り売り」を許容範囲で受けるのが新しい受注パターン。

警告

15ファイル全部のテンプレを渡すと再依頼率が消える。提案書1本＋ラシンバン1本のテンプレに留める。攻略マニュアル本体は絶対に渡さない。

CASE 6納期が「来週まで」と短納期で要求される

状況：商談中に「来週の取締役会で見せたい」と短納期依頼／通常2営業日のフローを5営業日に圧縮要求
攻略法

Mode B（構造分解単体）またはMode C（リサーチ＋ポータル）で対応し、フル版は別納期で並行制作。「取締役会用は要約版、本番は2週間後に完全版」の2段階デリバリーを提案。納期に振り回されると品質が崩れるので、必ず2段階提案で交渉。

価格

短納期は1.5倍料金。「無料デモ作成」の場合は短納期対応しない（受注確度が読めないため）。

SECTION 06 / FAILURE PATTERNS

⚠️ 失敗パターン集（NG集）

「やったら詰む」NGパターン7選。それぞれの典型症状＋切り抜け方を明示。

NG-01社内専用5MDをクライアントに送る

最大の事故。社長ペルソナ・経営会議文字起こしを「資料一式」として共有してしまう。クライアントが「架空の設定資料」を読んで信頼を喪失。
送付前に必ず10_PUBLISHED/配下のみをZIP化するか、URLで該当HTMLのみ共有する。.gitignore＋ファイル名プレフィックス（00_／99_）で物理的に区別。

NG-02攻略マニュアルを社外に流出させる

「営業話法」「反論切り返し」が外に出ると、クライアントが「裏を読まれて操作されている」と感じる。最悪の信頼毀損。
ファイル名に「社外秘」を必ず含める。.gitignoreでGitHub追跡対象外。PDFエクスポート時の警告バー表示。社内研修以外で開かない。

NG-03架空数値を実データと混ぜる

「越前刃心は年商23億円（架空）、中国輸入包丁シェア27%」のように、架空と実数を1文に混ぜる。読み手が境界を見失い、全数値が疑わしくなる。
架空数値には必ず「（架空試算）」「（Demo仮置）」表記。実データは出典URLセット。境界は段落単位で分離。

NG-04ラシンバンのDATA以外を触る

テンプレのHTML/CSS/JSを書き換えてしまい、マンダラ→マトリクス→フロー連鎖が壊れる。再現性が消える。
書き換えは必ずconst DATA = {...}とconst SK = '...'のみ。テンプレ本体は越前刃心版から無加工コピー。preview検証でマンダラセル→マトリクス遷移を必ず確認。

NG-05ポータルに社内MDへのリンクを残す

index.htmlに「デモ資料セット（補足）」リンクを置き、クライアントがクリックして社内専用MDにアクセス。社外秘情報の流出。
ポータルは7HTML（提案書3＋構造分解3＋リサーチ1）への導線のみ。「社内資料」「補足」セクションは絶対に作らない。

NG-06パスワードを本文に書く

「パスワード：demo2026」とフッターに記載。URL共有時に意味が消える＋セキュリティゼロ。
パスワードはゲート機能のみ。本文・フッター・コメントに記載NG。営業時はURL＋パスワードを別送（メール本文＋SMS等）。

NG-07全7HTMLを商談10分以内で見せようとする

焦って全部スクロール表示。クライアント側で印象がぼやけ、何の会社か伝わらず。
商談用は4ポイント（ポータル＋提案①冒頭＋ラシンバン構造分解＋新販路マップ）に絞る。残り3HTMLは「持ち帰り用」として後送。
SECTION 07 / LEVELS

段階的習得ロードマップ（Lv1〜Lv5）

スキルを使いこなすための5段階。各レベルの到達目標と所要期間。

LEVEL 1 / 初学者

越前刃心デモを完全理解

15ファイル全部を読み込み、ファイル間の参照関係を把握。社外秘マニュアルを暗記レベルまで。
所要：3〜5日
LEVEL 2 / 実践者

近接業種で1案件完成

越前刃心と販路構造の近い業種（食品・建材・部品メーカー等）で1案件完成。Kaiに指示してフル15ファイル生成。
所要：1〜2週間（初案件）
LEVEL 3 / 中級者

業種跨ぎ案件で3案件横展開

アパレル・IT・医療など業種が大きく異なる3案件を横展開。難題ケース1〜3に1回以上遭遇し対応。
所要：1〜2ヶ月（3案件累計）
LEVEL 4 / 熟達者

反論切り返しを瞬発で出せる

商談中にQ1〜Q5の反論が来た瞬間、3秒以内に対応開始。難題ケース4〜6（内製化要求・短納期・予算保留）に成功実績。
所要：3〜6ヶ月（実案件10件以上）
LEVEL 5 / 攻略者

新パターンを発見・体系化

越前刃心では想定していない難題パターンを実戦で発見し、本マニュアルに追記して体系化。営業メンバー研修を実施可能。
所要：1年以上（営業メンバー育成も含む）

SECTION 10 / COUNTERS

⚔️ 反論切り返し集（最重要）

商談で必ず出る5つの反論への切り返しテンプレ。暗記レベルまで習得し、3秒以内に反応できるようにする。

「これ全部AIで作ってるんでしょ？うちもChatGPTでできるよ」
「AIは手を動かしてもらってますが、設計と判断は私が全部やっています。実は、出典の確認・数値の検証・5MDの矛盾チェックに一番時間がかかります。AIが嘘の数値を平気で出すので、それを潰す作業こそが我々の仕事です。」

→その場でAIに「中国輸入包丁シェアは何%？」と質問してAIが違う数字を出すデモ実演。出典セクションを開いて公開URL一覧を見せる。
「うちみたいな小さい会社にここまで必要？」
「ここまでの量がそのまま貴社に必要なわけではないです。逆に言うと、貴社が動かしたい施策3つに絞った構造分解だけお作りすることもできます。料金は出すドキュメントの数に比例します。」

→価格表3段階で持参（小規模40万／中規模120万／大規模300万）。
「うちの業界はAIなんて使えないよ」
「業界によってはAIが直接ユーザーと話す機会はゼロです。我々の提案も、AIがお客様と話す部分はほぼないんです。AIは"見えない裏方"として、ヒアリングデータの分析、提案書の下書き、施策アイデアの量産、ここで使います。フロントは全部、貴社の人と私です。」
「で、これ作るのいくら？」
1. まず「7本セットの場合、企画から納品まで2ヶ月で150〜300万円が多いです」と幅で伝える。
2. 「ただ、お客様によって必要なものは違うので、ヒアリングして見積もりさせてください。ヒアリング自体は3万円です（または無料）」
3. 絶対に値切られ前提の金額を最初に出さない。
「同業他社の事例はないの？」
「クライアント様には守秘義務をお約束しているので、社名は出せません。ただ、この越前刃心デモは『中小製造業×B2B卸×後継者問題』という構造で、実在のお客様の課題を抽象化して作っています。貴社の業界にも横展開できる原理原則が詰まっています。」
攻略マインド

反論は「攻撃」ではなく「興味の証」

反論が来たら、相手はすでに前のめりになっている。冷静に切り返せばクロージング率は跳ね上がる。逆に、反論が一切出ない商談は「興味なし」のサイン。早めに離脱判断。
