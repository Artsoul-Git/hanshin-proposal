# 初期セットアップガイド

## 前提条件
- Claude Code インストール済み
- Python 3.10 以上
- Windows / Mac / Linux

## セットアップ手順

### Step 1: スキルを Claude Code から呼び出せる場所に配置
このフォルダ全体（seminar-system）を、運用したいプロジェクトフォルダにコピー。

### Step 2: Python 依存関係インストール
```bash
cd seminar-system
pip install -r scripts/requirements.txt
```

### Step 3: Claude Code 起動
```bash
cd seminar-system
claude
```

CHIEF が自動起動。

### Step 4: 案件ブリーフ作成
`inputs/[案件ID]/brief.md` を作成（examples/PILOT-001-sample/brief.md を参考）。

### Step 5: 実行
Claude Code に：
```
inputs/[案件ID]/brief.md の案件を進めて
```

### 生成物
`outputs/[案件ID]/` 配下に：
- 01_persona.md 〜 08_review.md
- slide-spec.json
- seminar.pptx（メイン成果物）
- audit/ （GUARDIAN検査ログ）

## トラブルシューティング

### ビルド時に「cairosvg がない」
```bash
pip install cairosvg
```

### 日本語が文字化け（Linux環境のみ）
v4 の SVG分離アーキテクチャで解決済み。Windows/Mac では発生しない。

### CHIEF が冗長な応答をする
CLAUDE.md の「冗長禁止ルール」を再確認指示：
```
CLAUDE.md の禁止語句リストを確認して、結論ファーストで応答して
```
