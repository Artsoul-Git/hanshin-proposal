# 請求書テンプレート ＆ 発行フロー

Ver 1.0 ／ 2026年5月作成

---

## 1. 請求書発行フロー

```
【発行タイミング】
Phase 1（研修）  ：契約締結後 → 初回研修実施前に全額請求（前払い）
Phase 2（実装）  ：毎月1日に翌月分を請求（月次前払い）
Phase 3（顧問）  ：毎月1日に当月分を請求（月次前払い）
スポット対応     ：作業完了後3営業日以内に請求

【支払い期限】
原則：請求書発行日から14日以内

【発行方法】
1. 下記テンプレートをコピーして記入
2. PDF化してメール送付 or クラウド会計ソフトから送付
3. 送付後、client_status.md の「入金状況」欄を更新
4. 入金確認後、領収書を発行（希望があれば）
```

## 3. 請求書番号の採番ルール

```
INV - YYYYMM - 連番（3桁）

例：
  INV-202606-001  → 2026年6月 第1号
  INV-202606-002  → 2026年6月 第2号

管理：client_status.md の「請求番号」列で一元管理
```

## 4. フェーズ別 標準請求金額

| フェーズ | 内容 | 標準金額（税抜） | 請求タイミング |
|---------|------|----------------|--------------|
| Phase 1 | AI導入研修（13時間） | ¥200,000 | 契約締結後・研修前 |
| Phase 2 | 月次実装支援 | ¥150,000〜¥300,000/月 | 毎月1日 |
| Phase 3 | 顧問契約 | ¥50,000/月 | 毎月1日 |
| スポット | 単発コンサル・開発 | 要見積もり | 作業完了後3営業日 |
| AI社員派遣 | カスタムAI社員開発 | ¥150,000〜（初期） + ¥30,000/月 | 開発完了後 + 月次 |

> 上記は目安。contract_template_detailed.md の契約金額が優先。

## 5. 遅延・未払い時の対応手順

```
Step 1：支払期限の翌営業日にリマインドメール送付
Step 2：さらに5営業日後に電話フォロー（フー担当）
Step 3：さらに10日後に内容証明の送付を検討（律に相談）
Step 4：それでも未払いの場合、支払督促・法的手続き検討

【リマインドメール文例】
Subject：【AS株式会社】ご請求書のお支払いについて（INV-XXXXXX-XXX）

○○株式会社　○○様
```

## 7. 経理記録の手順（月次）

```
【月次経理チェック（毎月末）】
□ 当月発行の請求書を一覧化（client_status.md 確認）
□ 入金確認（通帳・振込通知と照合）
□ 未入金があればリマインド実施
□ 翌月分の請求書を作成・送付（月次顧問分）
□ 売上・経費を会計ソフトへ記帳
□ profit_simulation_y1.md の実績欄を更新
```
