# クライアント・オンボーディングチェックリスト

Ver 1.0 ／ 2026年5月作成

> 契約締結からPhase 1研修完了までの全手順。担当：ケイ（意思決定）・フー（事務連絡）・改（現場支援）。

---

## STAGE 0：契約締結前（商談クロージング〜契約直前）

```
□ 初回面談スコアを確認（detailed_hearing_sheets.md の記録確認）
□ 顧客の課題・ゴールを言語化し、提案書を最終確認（栄）
□ 契約書（contract_template_detailed.md）に顧客情報を記入（律がチェック）
□ 価格・フェーズ構成を口頭で最終合意
□ 契約書を2部印刷または電子署名ツールで送付
□ 支払い方法（銀行振込）と口座情報を顧客に連絡
□ 請求書発行（invoice_template.md 参照）・送付
□ client_status.md に顧客情報を新規登録

完了目安：商談から3営業日以内
```

## STAGE 1：契約締結後〜研修Day1まで（〜7日）

### 1-A. 社内準備（AS側）

```
□ 【フー】契約書の署名・入金を確認し、ケイに報告
□ 【連】担当AI社員（主：改、副：結）へ顧客情報・課題を共有
□ 【改】業界別テンプレート（industry_templates/）から該当業種を選定・カスタマイズ
□ 【守】研修資料・配布物の最終QAチェック完了
□ 【巧】オンライン会議URLの発行（Zoom/Meet等）
□ 【ケイ】研修スケジュール（全13時間）の日程を顧客と合意
□ client_status.md の進捗ログを更新
```

### 1-B. 顧客への事前送付物

```
□ ウェルカムレター（下記テンプレート参照）を送付
□ 研修スケジュール表（日程・所要時間・場所/URL）を送付
□ 事前アンケート（業務の詳細把握用）を送付・回収
□ 研修当日の持ち物・準備物リストを送付
□ client_ai_management_manual.md（顧客配布用）を送付

送付担当：フー（メール）、作成担当：改・舞
```

## STAGE 2：研修Day1〜研修完了（Phase 1）

参照：`training_curriculum_13h.md`

```
【Day1前日】
□ 研修資料・演習問題の最終確認（守）
□ デモ環境（ChatGPT等）の動作確認（巧）
□ 参加者リストの確認（人数・役職）

【Day1当日：基礎編（2時間）】
□ アイスブレーク・自己紹介（5分）
□ AIとは何か・できること/できないこと（30分）
□ 実際に触ってみる（ハンズオン）（60分）
□ Q&A・宿題説明（25分）
□ 終了後：参加者の反応・課題をメモ（client_status.md に記録）

【ツール活用編（7時間）】
□ 主要ツール（ChatGPT/Gemini等）の使い方
□ 業務別プロンプトの設計と実演
□ 業界固有の活用シーン演習
□ 受講者によるプロンプト作成ワーク

【実務ワークショップ（4時間）】
□ 実際の自社業務にAIを適用する演習
□ 「AI活用マップ」の作成（各自の業務とAIの接点を可視化）
□ 社内展開計画の策定

【研修完了時】
□ 修了証の発行（training_certificate_template.md）
□ 研修アンケート（満足度・活用意向）の回収
□ Phase 2 への移行提案（operation_manual.md 参照）
□ quantitative_report_template.md で研修前後の工数変化を初期計測
□ client_status.md を「Phase 2 検討中」に更新
```

## STAGE 3：Phase 1完了後のフォローアップ（研修後1週間）

```
□ 研修3日後：「研修後いかがでしょうか？」確認メール送付（フー）
□ 研修1週間後：フォローアップ面談の日程調整（連）
□ フォローアップ面談実施（ケイ）
  ├ 研修内容の定着確認
  ├ 実際に使えているか？困っていることは？
  └ Phase 2 への移行タイミングの合意
□ Phase 2 移行の場合：新契約書・請求書の発行
□ Phase 2 移行しない場合：理由をclient_status.md に記録し継続フォロー計画策定
```

## よくある落とし穴と対処法

| 落とし穴 | 対処法 |
|---------|--------|
| 事前アンケートが返ってこない | 3日後にフーからリマインド電話。返答なしで研修当日に持参してもらう |
| 研修当日に参加者が少ない | 事前に「全員参加推奨」と伝える。録画・フォロー研修で対応 |
| 研修後に活用が止まる | 3日フォロー・1週間面談を必ず実施。「使い続ける理由」を作る |
| Phase 2 移行を渋る | 研修効果の数値化（改）＋具体的なROI提示（phase2_meeting_agenda.md 参照） |
| キーパーソンが変わる | client_status.md の担当者情報を即更新。新担当者への関係構築を優先 |
