# Kai Visualize　操作マニュアル

## 概要

マンダラチャートからタスクをクリックするだけで、4象限マトリクス・フロー図・ガントチャートをAIが自動生成するローカルWebアプリ。

- **ポート：** localhost:3458
- **APIキー不要モード：** キューにリクエストが貯まるので、Kaiのチャットに貼り付けて手動生成も可能
- **AI自動生成モード：** GEMINI_API_KEY を設定するとクリックで即時生成

---

## 初回セットアップ（Gemini APIキーの登録）

### 1. APIキーの取得
1. `aistudio.google.com` にアクセス（Googleアカウントでログイン）
2. 右上「Get API key」→「Create API key」
3. 表示された `AIzaSy...` の文字列をコピー

### 2. Windowsの環境変数に登録（GUIで行う）
キーはチャットやターミナルに貼り付けず、必ずGUI経由で登録する。

1. Windowsキー → 「環境変数」で検索 → **「システム環境変数の編集」** を開く
2. 「**環境変数**」ボタンをクリック
3. 上段「ユーザー環境変数」の「**新規**」をクリック
4. 変数名：`GEMINI_API_KEY`　値：コピーしたキーを貼り付け → OK → OK

> **注意：** GCPコンソールで発行したキーはクォータが0の場合あり。必ずAI Studioのキーを使うこと。

## 起動方法

### 方法A：ダブルクリックで起動（通常利用）

`起動してブラウザを開く.vbs` をダブルクリック。

> ただし環境変数が読み込まれない場合、手動モードで起動することがある（→ 方法Bを使う）

### 方法B：PowerShellから起動（確実）

別ウィンドウのPowerShellで1行ずつ実行：

```powershell
$env:GEMINI_API_KEY = [System.Environment]::GetEnvironmentVariable('GEMINI_API_KEY','User')
```
```powershell
cd "D:\Google Antigravity\AS_AI導入支援事業_cc\08_アプリ開発事業部\outputs\kai-visualize"
```
```powershell
py -3 server.py
```

ブラウザで `http://localhost:3458` を開く。

> 複数行を一度に貼り付けると警告が出る。1行ずつ実行すること。

## 画面の見方・操作フロー

```
マンダラ（9×9グリッド）
  ├─ 色付きの大きいセル（テーマセル）をクリック
  │    → そのテーマの8タスク優先順位（テーマ4象限）を生成
  │
  └─ 小さいセル（タスクセル）をクリック  ← メインの使い方
       → そのタスク専用の詳細4象限を生成
            → Q1（今すぐ着手）の「▶ フロー図あり」をクリック
                 → フロー図を生成
                      → 「ガントチャートへ →」ボタン
                           → ガントチャートを生成
```

- AI自動生成モードでは「AIが生成中...」と表示され、10〜20秒で切り替わる
- キー未設定の場合は「生成する」ボタンが表示され、クリックでキューに追加される

## サーバー接続状態の確認

ブラウザ右上のバッジで確認：

| 表示 | 状態 |
|------|------|
| ● サーバー接続中 (AI自動) | 正常・自動生成モード |
| ● サーバー接続中 | 正常・手動モード（APIキーなし） |
| 再接続中... | SSE切断（自動復帰） |
| ✗ エラー | サーバー未起動 |

---

## APIキーの更新方法

1. `aistudio.google.com` で新しいキーを発行
2. Windowsキー → 「環境変数」→ ユーザー環境変数の `GEMINI_API_KEY` を選択 → 「編集」→ 値を更新 → OK
3. PowerShellでサーバーを再起動（方法B参照）

---

## 生成データのリセット

ブラウザで `http://localhost:3458` を開いた状態でサーバーを停止し、`state.json` を削除して再起動。または：

```powershell
Invoke-RestMethod -Uri http://localhost:3458/reset -Method POST
```

| ファイル | 役割 |
|----------|------|
| `server.py` | ローカルHTTPサーバー（ポート3458）＋Gemini API呼び出し |
| `index.html` | ブラウザUI（マンダラ・4象限・フロー・ガント） |
| `state.json` | 生成済みコンテンツとキューの保存ファイル |
| `kai-visualize-cli.py` | ターミナルからの手動生成用CLIツール |
| `起動してブラウザを開く.vbs` | ダブルクリック起動スクリプト |
