# 初心者向けガイド作成スキル — 使い方

このフォルダの中身は、PC操作が苦手な完全初心者向けのHTMLガイドブックを、Claudeに毎回同じクオリティで作らせるための仕組みです。

「Antigravity並列運用ガイド.html」と同じレベルの読みやすいマニュアルを、別のテーマで何個でも量産できます。

---

## このフォルダに入っているもの

```
beginner-guide-skill/
├── README.md          ← 今これを読んでます。最初にここから
├── SKILL.md           ← 本格スキル定義書（Claude Codeなどに登録する用）
└── プロンプト版.md      ← コピペ用の短縮プロンプト（一発依頼用）
```

---

## まず結論：どっちを使えばいい？

| 状況 | 使うファイル |
|------|------------|
| 今すぐ1個だけガイドを作りたい | **プロンプト版.md** |
| 今後ずっとガイドを量産したい | **SKILL.md** |
| Claude CodeやAntigravityに常駐させたい | **SKILL.md** |
| ChatGPTやGeminiでも使いたい | **プロンプト版.md** |
| 両方ピンと来ない | まず **プロンプト版.md** で1回試す |

迷ったら **プロンプト版.md** を試してください。SKILL.mdの方は、運用が回りだしてから登録すれば十分です。

---

## 使い方A：プロンプト版.md（一番簡単）

### 手順

1. **プロンプト版.md を開く**
   - エクスプローラーでこのフォルダを開いてダブルクリック、またはVS Code/Antigravityで開く

2. **「短縮プロンプト（基本）」セクションをコピー**
   - 三重バッククォート（` ``` `）で囲まれてる部分をまるごと選択してコピー

3. **【】の中身を埋める**
   - メモ帳でもVS Codeでも、コピーしたプロンプトを貼り付けて、`【テーマ】`、`【読者像】`、`【最終ゴール】` の3箇所を自分の状況に書き換える

4. **Claudeに貼り付けて送信**
   - Cowork、Claude Code、Claude.ai のいずれでも可
   - 章構成案が返ってくる
   - 内容OKなら「進めて」、修正したい点があれば「○○の章を追加して」など指示

5. **HTMLファイルが生成される**
   - computer:// リンクをクリックしてブラウザで確認
   - イマイチな箇所があれば「ここを直して」と追加指示

### こんな依頼ができる

プロンプト版.md の最後の方に「サンプル使用例」が2つあります（Slack新人マニュアル / freee経費精算マニュアル）。これを真似すれば応用効きます。

例：
- 「Notionの新人向け使い方ガイド」
- 「経費精算システムの操作マニュアル」
- 「Zoom会議の参加方法」
- 「年末調整の入力ガイド」
- 「タイムカードシステムの使い方」

業界・読者を変えるだけで何でも作れます。

## 使い方B：SKILL.md（本格運用）

### こういう人向け

- Claude Codeで「スキル」として登録して、自然な依頼で発動させたい
- AntigravityのSKILLフォルダに置いて常駐させたい
- 複数案件で何度も使う前提

### 登録手順（Claude Code / Antigravityの場合）

1. **このフォルダ（beginner-guide-skill）を、スキル保管場所にコピー**

   コピー先の例：
   ```
   D:\Claude code_Cowork\AIエージェント設計\skills\beginner-guide-skill\
   ```
   または
   ```
   D:\Google Antigravity\AS_AI導入支援事業_cc\skills\beginner-guide-skill\
   ```

2. **Claude Codeを再起動**
   - ターミナルで `/exit` → もう一度 `claude` で起動

3. **動作確認**
   - 「○○の初心者向けガイドを作って」と依頼
   - Claudeが自動でこのスキルを発動して、SKILL.mdの仕様通りに作り始める

### 登録不要で使う方法（手動発動）

スキル登録が面倒なら、Claudeに以下のように指示するだけ：

```
このSKILL.mdの仕様に沿ってガイドを作って：
（SKILL.mdの中身を全部貼り付け、または以下のリンクを参照）
{SKILL.mdへのパス}

【テーマ】：○○
【読者像】：○○
【最終ゴール】：○○
```

これで毎回同じクオリティのガイドが出ます。

### Cowork/デスクトップアプリで使う場合

Coworkモードのプロジェクト指示文（CLAUDE.mdやプロジェクト設定）に、SKILL.mdの中身をコピペして登録しておくと、そのプロジェクト内では常にこのスキルが効いた状態になります。

## できあがるガイドの特徴

このスキル（プロンプト）で作るガイドには、以下の要素が必ず入ります：

- **表紙ページ**：タイトル・サブタイトル・対象読者の明示
- **目次**：全章リンク付き
- **第1章「ゴール提示」**：何ができるようになるか
- **第2章「必要なもの」**：チェックリスト形式
- **第3章「用語の事前説明」**：超ざっくり版
- **第4章「全体フロー図」**：SVGで作成
- **本編章**：ステップ番号付きカード、色分け枠（tip/warn/ok）
- **トラブルシューティング章**：8〜10件の困りごと対応
- **詳細用語集**：再掲・拡張版
- **付録**：効率化Tips、ショートカット集、応用設定

カラー：ネイビー（#1A365D）＋オレンジ（#ED8936）＋アクセント（緑・赤・黄）
フォント：Yu Gothic UI（Windows標準で日本語表示OK）

```

## カスタマイズしたい時

### カラーを変えたい

SKILL.md の「カラーパレット」セクションを参照。業界別の推奨配色も書いてあります。

- 製造・建設 → ネイビー＋オレンジ＋グリーン（デフォルト）
- 医療・教育 → ベージュ＋ピンク＋ブラウン
- 金融・コンサル → ネイビー＋ゴールド＋シルバー
- IT・テック → ダークグレー＋ティール＋イエロー

### 章構成を変えたい

SKILL.md の「章構成の設計」セクションが基本テンプレ。これを土台に、業務内容に応じて章を足し引きしてOK。

### トーンを変えたい

SKILL.md の「文体・トーン」セクション参照。「やる」「やらない」リストに従えば、初心者向けの丁寧トーンが安定して出ます。

カジュアルにしたい場合は、プロンプト時に「カジュアル寄りで」と指定すれば調整されます。

## トラブルシューティング

### Q1：Claudeが章構成を提示してくれない、いきなりHTML生成し始める

A：プロンプトの最後に **「章構成案だけ先に箇条書きで見せて、OKもらってから本文生成に入って」** を必ず入れてください。プロンプト版.mdのテンプレには既に入ってます。

### Q2：HTMLが文字化けする

A：保存時のエンコーディングがUTF-8になっているか確認。`<meta charset="UTF-8">` が `<head>` に入っているか確認。

### Q3：日本語フォントが豆腐（□）になる

A：CSS の `font-family` を `"Yu Gothic UI", "Hiragino Sans", "Meiryo", sans-serif` で指定すれば、Windows / Mac どちらでも日本語が表示されます。テンプレ通りなら問題ないはず。

### Q4：SVGのフロー図が表示されない

A：SVGがHTML内に直接書かれているか確認。外部ファイル参照になっていると単独で開いた時に動きません。SKILL.md のテンプレ通りに `<svg viewBox="...">` を直接埋め込む形が正解。

### Q5：思った通りのトーンにならない

A：プロンプトに `【トーン】` 指定を明示。さらに「『簡単です』『すぐできます』を使わない」「業界用語は全て初出時に定義」など、SKILL.mdの「やらない」リストから2〜3個ピックアップして強調すると効果的。

## まとめ

3行でいうと：

1. **すぐ作りたい** → プロンプト版.md をコピペして【】を埋めて、Claudeに貼る
2. **何度も作りたい** → SKILL.md をスキルフォルダに置いて、自然に依頼するだけ
3. **既存を直したい** → プロンプト版.md の「修正プロンプト」を使う

これだけ覚えておけば、初心者向けガイドが量産できます。
