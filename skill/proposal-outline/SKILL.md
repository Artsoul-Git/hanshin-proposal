# 提案骨子 自動生成スキル

ヒアリング結果から1〜2ページの提案骨子をWord形式で生成するスキル。商談後の提案準備時間を大幅に短縮する。

## トリガーワード

- 「提案骨子を作成して」
- 「提案のたたきを作って」
- 「このヒアリングから提案を作って」
- 「提案アウトラインを生成して」

---

## 入力ソース（優先度順）

1. **hearing-sheet（.xlsx）** — `/hearing-sheet` で生成したExcelファイル（最優先）
2. **文字起こしテキスト（.txt）** — 音声録音の文字起こし
3. **手書きメモ（直接貼り付け）** — 会社名・業種・主要課題が最低限必要

---

## hearing-sheetからの自動抽出

| 抽出項目 | 抽出元 |
|---------|--------|
| クライアント名 | 企業プロファイルシート |
| 業種・従業員数 | 企業プロファイルシート |
| 課題の優先順位 | 優先課題と投資意向シート |
| 理想の状態 | 優先課題と投資意向シート |
| 予算感 | 優先課題と投資意向シート |
| 困っていること | 領域別シート（チェック済み項目） |
| 具体的なエピソード | 領域別シート |

---

## 提案タイプの自動判定

| 検出キーワード | 提案タイプ |
|--------------|-----------|
| AI・生成AI・LLM・ChatGPT・自動化・DX・デジタル変革 | **AI/DX推進型** |
| システム・ツール・クラウド・SaaS・紙からの脱却 | **ITツール導入型** |
| 販促・集客・SNS・LP・マーケティング | **マーケティング型** |
| 複数混在・分類困難 | **複合提案型** |

---

## 出力フォーマット（A4縦1〜2ページ）

```
┌─────────────────────────────────────┐
│  ご提案概要                          │
│  {クライアント名} 御中              │
│  {日付}    {提案者名}              │
├─────────────────────────────────────┤
│  ▶ 課題の構造                        │
│    ◇ {最重要課題}                    │
│      → {背景・業務への影響}          │
│    ◇ {第2課題}  ◇ {第3課題}        │
├─────────────────────────────────────┤
│  ▶ アプローチ                         │
│    {解決策の方向性}                  │
│    ・{理由／根拠1}                   │
│    ・{理由／根拠2}                   │
├─────────────────────────────────────┤
│  ▶ 導入効果（想定）                   │
│    作業工数      約XX%削減           │
│    コスト        年間XX万円削減      │
│    {定性効果}                        │
├─────────────────────────────────────┤
│  ▶ ご提案フロー                       │
│    ① 現状診断・詳細ヒアリング        │
│    ② 解決策のご提示・見積提出        │
│    ③ トライアル導入（概念実証）      │
│    ④ 本格展開・定着支援              │
└─────────────────────────────────────┘
```

---

## 文字起こしからの課題抽出ロジック

| 発話パターン | 抽出分類 |
|-------------|---------|
| 「困っている」「課題」「問題になっている」 | 課題 |
| 「したい」「欲しい」「改善したい」「必要」 | 要望 |
| 数値表現（○時間・○人・○件・○円） | 定量データ |
| 「以前に〜した」「昔は〜だった」 | 背景・経緯 |

---

## 他スキルとの連携

```
/hearing-sheet  → ヒアリングシートに課題を整理
    ↓
/proposal-outline → 課題から提案骨子を生成
    ↓
/billing-docs → 提案内容をもとに見積書を作成
    ↓
/nda → 機密保持契約書の締結
    ↓
/biz-contract → 業務委託契約書の締結
    ↓
/wbs-gantt → プロジェクトスケジュール作成
```

---

## このスキルの役割範囲

### やること
- ヒアリング結果からの課題構造化
- 顧客目線の価値訴求文の生成
- AI/DX・IT・マーケティング提案の3タイプに対応
- 1〜2ページのシンプルなアウトライン出力

### 他スキルに任せること
- 詳細な実装スケジュール（→ /wbs-gantt）
- 見積金額の算出（→ /billing-docs）
- 5ページ以上の詳細提案書（→ /sme-ai-proposal）
- 競合比較・市場分析（→ /research）

## 出力ファイル名

`提案骨子_{クライアント名}_{YYYYMMDD}.docx`
