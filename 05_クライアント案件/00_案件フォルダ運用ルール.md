# 案件フォルダ 運用ルール

Ver 1.0 ／ 2026年5月作成

> 本フォルダはクライアントごとの実務ドキュメントを管理する場所。
> `03_コンサル・実務支援/` は「型（テンプレート）」、こちらは「各クライアントの実データ」。

---

## ■ フォルダ命名ルール

```
YYYYMMDD_クライアント名_ステータス/

例：
  20260504_さくら就労支援センター_デモ/    ← デモ・参考用
  20260601_〇〇建設株式会社_Phase1/        ← 進行中
  20261201_△△法律事務所_Phase3顧問/       ← 顧問契約中
  20260901_□□製造_完了/                   ← 終了済み

ステータス一覧：
  デモ    = デモ・参考事例
  商談中  = ヒアリング〜提案段階
  Phase1  = 研修・基礎構築中
  Phase2  = 実装・定着支援中
  Phase3顧問 = 顧問契約中
  完了    = 支援終了
```

---

## ■ 各案件フォルダの標準構成

```
YYYYMMDD_クライアント名_ステータス/
├── 00_クライアント基本情報.md    ← 会社概要・担当者・契約情報
├── 01_ヒアリング記録.md          ← 全ヒアリングの記録
├── 02_分析レポート.md            ← As-Is分析・課題構造化・優先度
├── 03_提案書.md                  ← クライアントへの提案書（完成形）
├── 04_6ヶ月計画.md               ← カスタマイズ済み支援計画
├── 05_ロードマップ.md            ← ガントチャート・週次タスク
├── 06_制度設計書.md              ← SOP・KPI・ガバナンス設計
├── 07_議事録/                    ← 面談・MTGの議事録
│   ├── 20260501_初回面談.md
│   └── 20260515_研修Day1.md
├── 08_成果レポート/              ← 月次・四半期レポート
│   └── 202606_月次レポート.md
└── 09_共有ドキュメント/          ← クライアントに渡した資料
    └── 研修資料_Day1.pdf
```

## ■ 更新ルール

```
□ 面談・訪問の翌営業日中に議事録を作成・保存
□ client_status.md（CRM台帳）の進捗ログと同期させる
□ 提案書・計画書を更新した場合はバージョン番号を上げる（v1.0→v1.1）
□ 完了案件は「完了」にリネームし、アーカイブフォルダへ移動
□ デモ・サンプルは「デモ」フラグを付け、実案件と明確に区別する
```
