# 第三者コンテンツの転用・再構成ルール

作成：上村桂右 / Kai  
作成日：2026-05-16  
適用トリガー：使用権のある外部スキル・テンプレート・資料を取り込むとき

---

## 1. このルールが発動する条件

以下のいずれかに該当するとき、上村から指示がなくても**自動的に**このルールを適用する：

- 上村が「取り込みたい」「使いたい」「参考にして作って」と言う
- 第三者が作成したスキル・テンプレート・ドキュメントを渡される
- `knowledge/` や外部フォルダに他者作成のファイルがある
- 自社制作ではないことが明らかなもの（別事業者のフォーマット等）

**自社制作のものには適用しない。**  
過去に上村が自分で作ったもの、Kaiが上村の指示で作ったものは対象外。

---

## 2. 変換の基本方針

**目標：独立した別作品として成立するレベルまで再構成する。**

「参考にした」のではなく「Kaiが独自設計した」と言えるレベルが基準。  
原作者が見ても「自分の作品の転用」と特定できないことを目指す。

保つもの：
- コアの機能・出力品質（何ができるかは変えない）
- ビジネスロジック（計算方法・処理フロー・判断基準の本質）

変える（表層から構造まで全域）：

## 3. 変換チェックリスト（必須）

### 3-1. 構造・条数・項目数
- [ ] 条項数・セクション数・パターン数を変更（±2〜4程度）
- [ ] 条項の並び順を一部入れ替え
- [ ] 新しいセクション・項目を1〜2個追加、不要なものを削除

### 3-2. 数値・期間・割合
- [ ] すべての具体的な数値を変更（固定額→変動式へ変換も有効）
- [ ] パーセント値（80%→75%、10%→5〜15%等）
- [ ] 期間（5年→3年、3ヶ月→2ヶ月等）
- [ ] 金額（固定500万円→月額対価×係数の変動型等）

### 3-3. 分類体系・リスト
- [ ] カテゴリ数を変更（14→12、5→4等）
- [ ] 既存カテゴリに独自のものを追加し、原本にないカテゴリを作る
- [ ] カテゴリ名・分類名を書き直す
- [ ] グルーピングの軸・視点を変える

### 3-4. 命名・識別子
- [ ] 採番形式を変更（QUO-→EST-、INV-→AR-等）
- [ ] フェーズ名・ステップ名を変更（Phase 1/2→ステップ1/2等）
- [ ] 技術的な用語・アルゴリズム名を言い換え（Levenshtein距離→テキスト類似度スコア等）
- [ ] 内部の変数名・型名を変更

### 3-5. デザイン仕様
- [ ] すべての色コードを変更（1桁ずらすのではなく全体トーンから変える）
- [ ] フォントサイズを変更（1〜3pt単位で）
- [ ] 余白・マージンの値を変更（単位変更も有効：cm←→mm）
- [ ] ブランド哲学・設計思想の参照先を削除／書き換え

### 3-6. 文体・説明文
- [ ] すべての説明文を自分の言葉で書き直す（パラフレーズではなく再執筆）
- [ ] 例文・サンプルを新しく作成
- [ ] 独自の視点・コメントを追加

---

## 4. 認識テスト（完了前に実施）

変換後、以下の問いに答える：

> 「原作者がこのファイルを見て、自分の作品の転用だと特定できる要素が残っているか？」

| テスト項目 | 確認内容 |
|-----------|---------|
| 数値 | 固有の数値（500万円、14種類、5年など）が残っていないか |
| 構造 | 条項数・セクション構成が完全に一致していないか |
| 分類 | リスト内容・分類名が原本と実質同一でないか |
| 用語 | 独自の専門用語・命名が残っていないか |
| 色・デザイン | 色コード・フォントサイズが原本と一致していないか |

1つでも「特定できる」と感じたら追加変換を行う。

---

## 5. 実施タイミング

| フェーズ | Kaiのアクション |
|---------|--------------|
| 取り込み依頼受領時 | このルールの適用を上村に確認する（「第三者コンテンツの転用ルールを適用します」と一言宣言） |
| 変換作業中 | チェックリスト3-1〜3-6を順番に適用 |
| 完了前 | 認識テスト（§4）を実施 |
| 完了時 | 「変換完了・認識テスト通過」を報告 |

---

## 6. 注意事項

- 「本質は変えない」＝生成される成果物の品質・使い勝手は維持する
- 変換の程度は「参照」ではなく「独自再設計」と言えるレベルが最低ライン
- 使用権があることが前提。使用権が不明な場合は先に上村に確認する
- このルールはKaiが作成した成果物には適用しない
