スキル一覧と概要

コンサルティング案件の営業フェーズ → 契約フェーズ → 実行フェーズをカバーする9スキル。「ヒアリングシートを作って」など自然な言葉で呼び出せる。
/hearing-sheet
ヒアリングシート生成
業種×部門に合わせた質問項目を自動生成。文字起こし自動記入にも対応。
/proposal-outline
提案骨子生成
ヒアリング結果から1〜2ページの提案アウトラインをWord形式で生成。
/billing-docs
見積書・請求書生成
見積書・請求書をExcelで自動生成。消費税自動計算・インボイス番号採番。
/nda
NDA生成
損害賠償上限・秘密保持期間明示のバランス型NDA。現代的条項含む。
/biz-contract
業務委託契約書生成
コンサル・AI支援に特化した15条構成の業務委託契約書。受託者帰属＋包括ライセンス型標準。
/wbs-gantt
WBS・ガントチャート生成
日付変更でバーが自動伸縮する動的関数版ガントチャート。3シート構成。
/daily-report
音声入力日報
自然文を6列Excelに自動変換（工数列追加）。月次レポートのデータ源として蓄積。
/monthly-report
月次活動レポート
日報から月次レポートを自動生成。A4縦2ページのコンパクト設計。
/doc-compare
新旧対比表生成
2つのWord/PDFを比較し、変更箇所を色分けした新旧対比表を生成。

/hearing-sheet
ヒアリングシート生成
業種×部門に合わせた質問項目をExcelで動的生成
初回商談・現状把握に使うヒアリングシートを自動生成。業種（14種）と部門（5種）を指定すると、業種特有の質問項目が自動追加される。

呼び出し方

# 基本
ヒアリングシートを作成して

# 詳細指定
〇〇株式会社（製造業）の経理と営業部門のヒアリングシートを作って

# 文字起こし自動記入
このヒアリングメモからシートに自動記入して
[文字起こしを貼り付け]

業種選択肢（14種）

製造業 / 小売業 / 卸売業 / 建設業 / 福祉・介護 / 医療 / 金融・保険 / 不動産 / 運輸・物流 / 飲食・宿泊 / 情報通信・IT / その他サービス業 / 農林水産業 / 公共・団体（農協・商工会等）

部門選択肢（5種）

経理 / 人事・総務 / 営業 / 現場・製造 / 情報システム

シート構成

シート内容生成条件
基本情報会社概要・担当者・従業員数常時
IT環境使用システム・インフラ常時
【部門名】部門別質問項目選択部門ごと
優先度・ゴール整理課題優先順位・予算感・意思決定常時

自動記入機能（確信度による色分け）

確信度セル背景表示
高白（標準）そのまま記入
中薄黄推測根拠をコメントに記載
低薄オレンジ複数候補をコメントに記載
不明薄グレー「該当発言なし」
注意自動記入結果は必ず人間がレビューすること。黄色・オレンジのセルを優先確認。

出力ファイル名：ヒアリングシート_{企業名}_{日付}.xlsx

/proposal-outline
提案骨子生成
ヒアリング結果から1〜2ページの提案アウトラインを自動生成
hearing-sheetのExcel・文字起こし・手書きメモのいずれかから課題を抽出し、AI/DX提案または汎用IT導入提案の骨子をWord形式で生成する。

呼び出し方

# hearing-sheetから
このヒアリングシートから提案骨子を作って
[Excelをアップロード]

# 文字起こしから
「うちは社員5人で経理が1人で請求書を毎月100枚手入力してます…」
この内容で提案のたたきを作って

提案タイプの自動判定

検出キーワード提案タイプ
AI・生成AI・自動化・DX・デジタル化AI/DX支援提案
システム導入・ツール導入・Excel脱却IT導入提案
両方混在・不明両方を含む提案

出力フォーマット（1〜2ページ）

  1. 現状課題の整理（3課題・具体的な数値・影響付き）
  2. ご提案の方向性（アプローチ・なぜこのアプローチか）
  3. 期待効果（工数削減・コスト・品質向上）
  4. 次のステップ（詳細ヒアリング・見積・PoC）

出力ファイル名：提案骨子_{クライアント名}_{日付}.docx

/billing-docs
見積書・請求書生成
Excel形式で見積書・請求書を自動生成
「見積書を作成して」「請求書が必要」など自然な言葉でトリガー。消費税10%自動計算・インボイス番号自動採番。月額顧問型・時間単価型・プロジェクト型に対応。

呼び出し方

# 見積書
〇〇株式会社向けにAIアドバイザリー月額30万円の見積書を作成して

# 請求書
〇〇株式会社への5月分の請求書を作って（AIコンサル業務・税抜20万円）

見積タイプ別の設定

タイプ備考のデフォルト
月額顧問型月末締め翌月末払い・契約期間1年（自動更新）
時間単価型稼働時間は実績に応じて精算
プロジェクト型着手金30%・中間金40%・完了時30%

共通仕様

  • 消費税：10%（端数切り捨て）
  • 支払期限：請求月末
  • 有効期限：発行日から30日後（デフォルト）
  • 番号形式：見積書 EST-YYYYMM-NNN / 請求書 AR-YYYYMM-NNN
PDF送付の場合Excelで開いて「ファイル → 印刷 → PDF保存」で変換してください。

出力ファイル名：御見積書_EST-YYYYMM-NNN.xlsx / 請求書_AR-YYYYMM-NNN.xlsx

/nda
機密保持契約書（NDA）生成
損害賠償上限・秘密保持期間を明示したバランス型NDA
片方向・双方向どちらにも対応。損害賠償上限は取引規模に連動する変動型（月額対価の3〜6ヶ月相当・最低50万円）。秘密保持期間は原則3年（情報の性質で延長可）。生成AI利用条項など現代的な条項を含む。

呼び出し方

NDAを作成して。開示者は自社（有限会社アートソウル）、受領者は〇〇株式会社。
目的はAI導入支援コンサルティング。

標準構成（11条）

条項内容特徴
第2条機密情報の定義書面・口頭・電磁的方法すべて対象
第5条デジタルツールの利用クラウド・生成AI利用条項（現代的）
第8条有効期間と存続義務2年・自動更新・秘密保持は終了後3年
第9条損害賠償と責任制限月額対価の3〜6ヶ月相当（最低50万円）

カスタマイズ

項目選択肢
損害賠償上限変動型（月額×3〜6ヶ月・最低50万円）／プロジェクト型は総額の20〜30%
秘密保持期間1〜2年 / 3年（標準） / 5年（個人情報）/ 7年（特許前技術）
情報の流れ片方向 / 双方向
重要本スキルが生成するNDAは標準ひな形です。実際の締結前に専門家（弁護士等）に確認してください。

出力ファイル名：機密保持契約書_{相手先企業名}_{日付}.docx

/biz-contract
業務委託契約書生成
コンサル・AI支援に特化した17条構成の業務委託契約書
月額顧問型を標準とし、知的財産権は「受託者帰属＋委託者への包括ライセンス」のプロ型を採用。個人情報取扱（第9条）・不可抗力（第14条）を標準装備。損害賠償は月額対価の最大6ヶ月・間接損害除外。AI支援・DX推進・コンサルティング業務全般に対応。

呼び出し方

業務委託契約書を作成して。
委託者：〇〇株式会社、受託者：有限会社アートソウル
業務：AI導入支援コンサルティング、月額30万円（税抜）、契約期間1年

標準17条構成のポイント

条項内容設定
第7条 知的財産権成果物の著作権帰属受託者帰属＋委託者包括ライセンス（デフォルト）
第9条 個人情報の取扱いAPPI対応の管理義務目的外禁止・漏洩速報・廃棄義務を明示
第10条 再委託外注の可否事前書面承諾で可（デフォルト）
第13条 損害賠償と責任制限上限・範囲月額の最大6ヶ月・間接損害除外
第14条 不可抗力免責事由と手続き天災・感染症・クラウド停止等。2ヶ月継続で終了可

知的財産権の帰属パターン

タイプ内容向いているケース
受託者帰属＋包括ライセンス（標準）著作権は受託者。委託者は委託目的内で無制限に利用可コンサル・教育・ノウハウ提供
共有型双方が共同著作者として共有共同開発・双方のリソースを投じる場合
委託者帰属型著作権は委託者に帰属、受託者は実績公表権のみシステム開発・委託者専用ツール制作
重要本スキルが生成する契約書は標準ひな形です。実際の締結前に専門家（弁護士等）に確認してください。

出力ファイル名：業務委託契約書_{クライアント名}_{日付}.docx

/contract-check
契約書レビュー
受領した契約書を立場指定でレビュー。Excel比較表＋Wordレポートで出力
受け取った契約書・覚書・規約を「甲有利／乙有利／公平」の立場で分析。リスク条項・曖昧条項・欠落条項を特定し、改善提案をExcel比較表（7列）とWordレポートで出力。作成ではなく受領・確認フェーズに特化したスキル。

呼び出し方

# 立場を指定してレビュー
この契約書をチェックして。
立場：乙（受託者）側の有利な条件で確認してください。
[契約書ファイルをアップロードまたはテキストを貼り付け]

# 特定条項を重点確認
受け取った業務委託契約書の知財条項と損害賠償条項が乙側に不利でないか確認して

Excel比較表の出力列

列内容
A 条文番号第○条、前文、附則 等
B 元の条文（要約）問題となる箇所を抜粋
C 問題点・懸念事項何が問題か・なぜリスクか
D リスクレベル高🔴 / 中🟡 / 低🟢（オートフィルタ付き）
E 改善提案修正案または代替表現
F 立場への影響甲-不利 / 乙-不利 / 双方 / 中立
G 対応優先度要対応 / 検討 / 参考

立場設定の使い分け

立場いつ使う？
甲-有利発注側として受け取った契約書の確認（甲＝発注側・委託者）
乙-有利受注側・コンサルタントとして受け取った契約書の確認（乙＝受注側・受託者）
公平社内確認・第三者チェック・雛形の精査

他スキルとの連携フロー

相手先から契約書ドラフト受領
→ /contract-check：問題点・改善提案をExcel比較表で可視化
→ 交渉・修正
→ /doc-compare：修正前後の新旧対比表を生成
→ /biz-contract または /nda：合意内容をもとに最終版を新規生成
重要本スキルのレビューは実務的なリスク把握が目的です。高額・高リスクな取引は弁護士等の専門家に確認してください。

出力ファイル名：契約書チェック_{相手先}_{日付}.xlsx / 契約書レビューレポート_{相手先}_{日付}.docx

/daily-report
音声入力日報
自然文を6列Excelに自動変換
話した内容をそのまま貼り付けるだけで、日付・報告者・作業内容・工数・課題・翌日計画の6列Excelに自動変換。月次レポートのデータ源として蓄積していく。

呼び出し方

今日の日報を記録して。
「今日はA社向けのAI導入支援提案書を4時間かけて作成しました。
要件定義の認識ずれが課題です。
明日はB社との定例ミーティングと議事録作成の予定です。」

自動抽出する6項目

列内容取得方法
日付本日の日付自動取得
報告者担当者名不明時はヒアリング
作業内容顧客名・業務の概要発話から自動抽出
工数（h）作業にかけた時間発話から自動抽出
課題発生した問題・懸念事項発話から自動抽出
翌日計画翌日以降の予定発話から自動抽出
/monthly-report との連携日報を蓄積することで、月末に月次レポートを自動集計できます。「毎日記録 → 月末にまとめる」の習慣が定着すると最も効果的です。

出力ファイル名：日報_YYYY-MM-DD.xlsx

/monthly-report
月次活動レポート生成
日報から月次レポートをA4縦2ページで自動生成
日報データをもとに、クライアントへ送付する月次活動レポートを自動生成。A4縦2ページに収まる「読まれる」設計。数値で成果を証明し、継続契約の判断材料に。

呼び出し方

〇〇株式会社への5月分の月次レポートを作って。
稼働：18日・稼働時間：144時間
主要活動：AI戦略策定・社員研修実施・業務自動化提案
成果：研修参加率95%・月40時間削減見込み
課題：一部部署の活用遅延 → 次月に追加説明会実施予定

A4縦2ページの構成

ページセクション内容
1ページ目ヘッダータイトル・対象月・クライアント名
稼働実績稼働日数・稼働時間
活動内訳業務別日数リスト＋円グラフ（2カラム）
2ページ目成果達成事項と定量数値（✓マーク付き）
課題と対応課題と対応策をセットで記載
次月の計画3〜5項目のアクションリスト
フッター自社名（小さく）
設計哲学「間延びせず、詰め込みすぎず」——1ページ版は要点のみで物足りなく、5〜7ページ版は読まれない。2ページが「見てもらえる適切な分量」です。

出力ファイル名：月次レポート_{クライアント名}_{YYYYMM}.docx

/doc-compare
新旧対比表生成
2文書の変更箇所を色分け表示したWord形式の対比表を生成
就業規則・契約書・社内規程の改訂前後をWord形式で比較。13種類の見出しパターンを自動認識し、階層構造を解析して正確に対応付ける。

呼び出し方

# ファイルをアップロードして指示
[変更前.docx と 変更後.docx をアップロード]
新旧対比表を作成して

# 列順序を指定する場合
旧→新の順で対比表を作って（デフォルトは新→旧）

変更の表示ルール

種別表示方法
変更後テキスト赤字・太字・下線
変更前テキスト黒字・太字・下線
新規追加青字・太字、左セルに「(新規追加)」
削除赤字・取り消し線、右セルに「(削除)」
変更なし表示しない（変更箇所のみ抽出）

対応する見出しパターン（13種）

第○条 / 第○章 / 附則 / 番号付き見出し / 階層番号（1.1.2等） / ハイフン番号（3-2等） / 括弧番号（(1)等） / 角括弧（【1】等） / 英語（Article等） / 枝番条文（第3条の2等） / 記号（§等） 他

条文番号ずれへの対応章の挿入・削除で条文番号がずれた場合でも、見出し名のテキスト類似度スコアでマッチングするため正確に対応付けられます。

出力ファイル名：新旧対比表_{文書名}_{日付}.docx
