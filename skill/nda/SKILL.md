# 機密保持契約書（NDA）自動生成スキル

企業間取引における機密情報保護のためのNDAをWord形式で生成するスキル。双方の実務負荷を最小化しつつ、実効性のある保護水準を確保する11条構成。

## トリガーワード

- 「NDAを作成して」
- 「機密保持契約書を作って」
- 「秘密保持契約が必要」
- 「情報開示前に秘密保持の書類を準備して」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 内容 |
|------|------|
| 甲（情報開示側） | 企業名・代表者名・所在地 |
| 乙（情報受領側） | 企業名・代表者名・所在地 |
| **立場設定** | **甲（開示側）-有利 / 乙（受領側）-有利 / 公平（省略→公平）** |
| 契約の背景・目的 | 例：AI導入支援の検討協議、業務委託の準備 等 |
| 開示の方向 | 一方向（甲→乙）or 相互開示（双方向） |
| 特に保護したい情報の種類 | 顧客情報・技術資料・財務データ・経営戦略 等 |
| 損害賠償の上限 | 省略→立場設定に応じて自動選択 |
| 秘密保持の存続 | 省略→立場設定に応じて自動選択 |

---

## 立場設定による条項の自動調整

| 条項 | 甲（開示側）-有利 | 公平（デフォルト） | 乙（受領側）-有利 |
|------|-----------------|-----------------|-----------------|
| 秘密情報の定義 | 広く（口頭・黙示も含む） | 書面・電磁的方法＋口頭の確認あり | 狭く（書面指定のみ） |
| 開示例外の範囲 | 狭く（例外を限定） | **標準（4類型）** | 広く（独自開発・公知化の立証負担軽減） |
| 損害賠償上限 | 高め（月額×6ヶ月） | **月額×3〜6ヶ月（最低50万円）** | 低め（月額×3ヶ月・最低30万円） |
| 秘密保持の存続 | 長め（5年） | **3年（標準）** | 短め（1〜2年） |
| 違反時の措置 | 差止請求・損害賠償の両方を明記 | 損害賠償のみ（差止は協議） | 損害額の立証義務あり |

---

## 標準構成（11条）

| 条項 | タイトル | 内容・ポイント |
|------|---------|--------------|
| 第1条 | 目的と適用範囲 | 本契約の目的と対象取引の明示 |
| 第2条 | 秘密情報の定義 | 書面・口頭・電磁的方法で開示された情報を広く対象に |
| 第3条 | 保護義務と利用制限 | 目的外使用・第三者提供の禁止、善管注意義務 |
| 第4条 | 開示の例外 | 公知情報・独自開発・法的開示義務 等 |
| 第5条 | デジタルツールの利用 | 業務用クラウドサービスの利用許可・生成AIへの入力制限 |
| 第6条 | 情報の返却・廃棄 | 契約終了・要請時の処理方法 |
| 第7条 | 権利の非譲渡 | 契約上の地位・権利義務の譲渡禁止 |
| 第8条 | 有効期間と存続義務 | 有効期間2年・自動更新、**秘密保持義務は終了後3年存続** |
| 第9条 | 損害賠償と責任制限 | **上限：月額対価の3〜6ヶ月相当（最低50万円）**、故意・重大な過失は除外の対象外 |
| 第10条 | 協議・解釈 | 未定事項・解釈の齟齬が生じた場合の協議義務 |
| 第11条 | 準拠法と合意管轄 | 日本法準拠・専属管轄裁判所の指定 |

## 損害賠償の算出方式

固定額ではなく、取引規模に連動する変動型を採用：

```
上限額 = MAX(月額対価 × 係数, 下限額)

標準設定：
  係数 = 3〜6ヶ月（案件リスクに応じてKaiが提案）
  下限額 = 50万円（月額対価が低額な場合のフロア）

例：月額30万円の顧問契約
  → 30万 × 4ヶ月 = 120万円が上限
```

プロジェクト型（一括契約）の場合は契約総額の20〜30%を目安に設定。

## 秘密保持の存続期間

| 情報の性質 | 推奨存続期間 |
|-----------|------------|
| 一般的な業務情報 | 終了後1〜2年 |
| 標準（デフォルト） | **終了後3年** |
| 個人情報・顧客リスト | 終了後5年 |
| 特許出願前の技術情報 | 終了後7年 |

---

## 第5条：デジタルツール条項について

現代の業務環境を前提とした条項：

- **クラウドサービスの利用**：セキュリティ基準を満たす企業向けサービス（Google Workspace・Microsoft 365等）での情報取り扱いを明示的に許可
- **生成AIへの入力制限**：受領した秘密情報を生成AIのプロンプトに直接入力することを禁止（要約・抽象化した利用は別途協議）
- **端末・ネットワーク管理**：業務端末・社内ネットワーク経由での利用を原則とする

---

## 相互開示型（双方向NDA）への変換

「双方向NDA」を指定すると：
- 甲・乙どちらも開示者かつ受領者となる構成に変更
- 各条項の主語を「両当事者は」に統一
- 第2条の定義を双方向の開示を前提とした表現に修正

---

## 追加オプション条項

| 条項 | 追加するケース |
|------|--------------|
| 競業避止条項 | 競合会社へのコンテンツ・ノウハウ転用を防ぎたい場合 |
| 従業員への周知義務 | 受領側に開示先の管理を厳格化したい場合 |
| 損害額の立証不要条項 | 違反時の証明負担を軽減したい場合 |

## 技術仕様

- ライブラリ：docx.js（Node.js）
- フォント：MS Mincho（日本語契約書標準）
- 出力形式：.docx（A4・余白上下25mm・左右30mm）

## 出力ファイル名

`機密保持契約書_{相手先企業名}_{日付}.docx`

---

## 注意事項

本スキルが生成する契約書は実務的な標準ひな形です。業種・案件特性・相手方の要求によって調整が必要な場合があります。締結前には弁護士等の専門家への確認を推奨します。KaiはNDA内容の法的妥当性を保証するものではありません。
