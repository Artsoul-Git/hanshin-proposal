# 課題積み上げ体感実演型

**作成日:** 2026-05-18
**素材形式:** オンラインウェビナー・90分・中小企業/個人事業主/AIビジネスに関心があるフリーランス向け
**用途:** ツール選定・業務改善・AI導入など「なぜこれを選ぶか」という意思決定を促したいセミナーに最適。思想の理解なしには実演が活きないテーマで特に効果的。

---

## パターン概要

表面的なコスト・不便さへの共感から始め、本質的な問題（構造的な課題）を段階的に積み上げて危機感を醸成する。その危機感が「だからこそこのアプローチが正解」という納得に自然につながるよう設計し、後半の実務実演で「今日から使える」という高揚感で締める。

**最も刺さる条件:**
- ターゲット: 複数のツール・方法論を試してきた経験者、なんとなく現状に不満がある実務担当者・経営者
- テーマ: ツール選定・プラットフォーム統合・業務フロー改善・AI導入戦略
- 場: オンラインウェビナー・60〜90分・チャット機能あり

---

## DNA定義

### ① オープニングDNA

- **フックの種類:** チャット参加型数値質問（「〇〇に毎月いくらかけていますか？」等、参加者が自分の数値をチャットに書き込む形式）
- **設計構造:** 冒頭フック（数値入力で場を温める）→ 自己紹介（実績列挙 + 失敗/転換の体験談）→ 本日のKPI設定（3つのゴールを明示）→ アジェンダ提示
- **目安時間:** 4〜6分
- **ポイント:** 自己紹介で「自分もできていなかった失敗」を先に晒すことで、聴衆との心理的距離を縮める。KPI設定で「何が起きれば今日は成功か」を先に共有する。

### ② 構造DNA

- **セクション数:** 6セクション
- **各セクションと役割:**
  1. 問題提起（表面課題）— 聴衆が日常で感じている不満・コストを可視化 [約10%]
  2. 原因の深掘り（本質課題）— 表面課題の背後にある構造的な問題を露わにする [約15%]
  3. 新しい視点の提示（思想転換）— 「だからこそ〇〇という選択肢がある」という意思決定軸を提供 [約15%]
  4. 思想の補強（エコシステム/哲学）— なぜその選択肢が長期的に正解かを論理と体験で補強 [約20%]
  5. 実務実演（チップス3〜5選）— 今日から再現できる具体的な使い方を実際に操作して見せる [約35%]
  6. CTA（段階的行動喚起）— ユーザーレベル→ビジネス活用→パートナー/顧客になる、の3段階で提示 [約5%]

- **論理フロー:** 問題（共感）→ 原因（気づき）→ 解決思想（納得）→ 補強（確信）→ 実演（高揚）→ 行動（決断）
- **転換点の設計:** 前半/後半の境界は「では実務に入ります」等のブリッジ台詞で明示。各セクションの転換も「さて、ここまでで〜」と区切りを言語化する。

### ③ エンゲージメントDNA

- **参加仕掛けの種類:**
  - チャット数値入力（冒頭）
  - 質問コメントへの実況回答（進行中・断続的）
  - スクリーンシェア実演（後半）
- **配置パターン:** 冒頭に集中して参加を作り、中盤は質問対話で維持、後半は実演で視覚的に引きつける
- **処理パターン:** コメントを読む → 肯定する → 内容に活用してフロウを進める（コメントをセミナーコンテンツの一部として使う）

### ④ 感情カーブDNA

**設計フロー:**
1. 共感・一体感（「あるある」の数値で笑いと共感）
2. 表面的な不安（「コストが積み上がっている」）
3. 本質的な危機感（構造的な問題があると気づく）
4. 揺れ（「でも他にも良い選択肢があるのでは」という疑問）
5. 確信（反論を先取りして封じ、哲学的に正解を証明）
6. 高揚感（実演で「今日から使える」という感覚）
7. 決断（CTA + プレッシャー除去で踏み出しやすくする）

**ピーク位置:** 実務実演の「これ一つで解決した」体験場面 と CTA直前
**感情のテンポ:** 前半はゆっくり積み上げ、後半は実演テンポで加速

### ⑤ コンテンツ比率DNA

- **配分:** 理論3：体験談2：問いかけ2：具体事例3
- **前半:** 理論と体験談が中心。「なぜか」を論理と自身の失敗経験で補強
- **後半:** 実演と具体事例が中心。操作しながら解説するリアルタイム形式
- **事例の出し方:** 先出し（問題提起で事例を見せて共感を取る）→ 解決策提示 → 実演でさらに補強
- **専門性の見せ方:** 体験談重視（「自分もかつて失敗した」から入る）+ 実演重視（操作を見せることで再現性を示す）

### ⑥ クロージングDNA

- **CTAへの導き方:** 3段階段階型
  1. 「ツールを活用できる」ユーザーレベル
  2. 「他者に提案・提供できる」ビジネスレベル
  3. 「一緒に市場を作る」パートナーレベル
- **「今動く理由」の設計:** 限定性（このタイミング・この価格）の提示 + プレッシャー除去（「押し売りしない」「気軽に相談だけでもOK」）をセット
- **余韻:** CTA後も「困ったら連絡して」という開かれた姿勢で終わることで、参加者の心理的負荷を下げる

### ⑦ 話法構造DNA

- **口調パターン:** 語りかけ型（「〜ですよね」「〜じゃないですか」）と断定型（「〜が正解」「〜が大事」）の交互使用
- **話法の構造:**
  - 反論先取り構造：「〜と思う方もいると思います。それはそれでおっしゃる通りです。ただ—」
  - 逆説転換：「ただ」「しかし」「だがしかし」を繰り返し使って思想転換を演出
  - 説明展開パターン：「〜どういうことかと言いますと」で展開し「つまり〜」で締める
- **テンポ設計:** 全体的に速め・熱量高め。前半は論理的なテンポ、後半は実演に合わせてコマンドを打ちながら話す（操作音・画面と連動）
- **間の使い方:** セクション間のブリッジ台詞で「間」を作る。Q&Aで意図的にペースを落として参加者に追いつかせる

## このパターンのツボ（再現のコツ）

- **課題は2層で積む:** 「表面の課題（コスト・不便さ）」で共感を取ってから「本質的な課題（構造問題）」を示す。1層だけでは浅く、2層目で初めて「だから〇〇が必要」という論理が成立する
- **思想を浸透させてから実演に入る:** 「なぜか」が腑に落ちていない聴衆に実演を見せても技術デモで終わる。思想が先に入っているから実演が「答え合わせ」になる
- **自分の失敗を先に晒す:** 登壇者自身が「完璧ではない・かつて間違えた」と先に言うことで聴衆の防衛心が下がり、正論が通りやすくなる
- **反論は必ず先取りする:** 「〜という疑問を持つ方もいると思います」と自分から言ってしまうことで、聴衆が心の中でする反論を解消してから次に進む
- **実演は3〜5選に絞る:** 「全部できること」を示そうとすると脳内渋滞を起こす。最も再現性が高く体感差が大きいものに絞る
- **CTAは3段階で逃げ道をふさがず、入口を広げる:** 「すぐ買う」以外の「まず相談」「興味があれば」という選択肢を用意することで踏み出しのハードルを下げる

## このパターンの落とし穴

- 思想説明が長すぎると前半で聴衆が離れる（座学は全体の45%以内に収める）
- 実演で技術的トラブルが起きた場合の対処台詞を準備していないと雰囲気が崩れる（「これ気分によっちゃいますよね」等のユーモアで回収する準備を持つ）
- 反論先取りをしすぎると「言い訳っぽい」印象になる（1セクションに1回まで）
- 3段階CTAで「一番上位のプラン」から話すと圧迫感が出る（ユーザーレベルから始めて段階的に上げる順序を守る）
