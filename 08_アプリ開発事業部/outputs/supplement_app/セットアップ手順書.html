STEP 1 — 約5分

Google スプレッドシートを作成する

📊
ℹ️ スプレッドシートがNoliaのデータベースになります。顧客の記録・レポートがすべてここに蓄積されます。
  • 1
    Google Drive を開く
    drive.google.com にアクセスします（GWSアカウントでログイン済みのこと）
  • 2
    新規スプレッドシートを作成
    左上「＋ 新規」→「Google スプレッドシート」をクリック
  • 3
    ファイル名を変更
    左上の「無題のスプレッドシート」をクリックして Nolia-DB に変更
  • !
    スプレッドシートIDをメモする（重要）
    URLの中から長い文字列をコピーしてメモ帳に保存してください
https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit#gid=0
URLの
/d/ と /edit の間の文字列
がIDです
例: 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms ← これをコピー
✅ このIDは STEP 3 で「スクリプトプロパティ」に登録します。今はメモ帳に保存しておくだけでOK。

STEP 3 — 約5分

APIキーとパスワードをスクリプトプロパティに設定する

🔑
🔒 APIキーはコードに直接書かず、必ずスクリプトプロパティに保存してください。コードにキーを書くと、GitHubに公開した際に外部に漏れる危険があります。
操作手順
  • 1
    GASエディタで左のナビ「プロジェクトの設定」⚙️ をクリック
  • 2
    「スクリプトのプロパティ」セクションまでスクロール
    「プロパティを追加」ボタンが見えます
  • 3
    以下の4つを1つずつ追加する
プロパティ名（左の欄）値（右の欄）取得場所
SPREADSHEET_ID STEP 1 でメモしたID 済 メモ帳に保存済み
GEMINI_API_KEY Gemini APIキー（長い文字列） 要取得 aistudio.google.com
LINE_TOKEN Channel Access Token 要取得 LINE Developers
ADMIN_TOKEN 自分で決めた管理者パスワード
例: nolia-admin-2026		 自由 自分で決める
Gemini APIキーの取得方法
  • 1
    aistudio.google.com を開く
    Googleアカウントでログイン（GWSアカウントでOK）
  • 2
    左メニュー「Get API key」→「Create API key」
    「Create API key in new project」を選択
  • 3
    生成されたキーをコピー → スクリプトプロパティに貼り付け
    キーは AIzaSy... から始まる長い文字列です
LINE Channel Access Token の取得方法
  • 1
    developers.line.biz を開く
    LINE Business IDでログイン（公式アカウントで使っているアカウント）
  • 2
    プロバイダー → 公式アカウントのチャネルを選択
  • 3
    「Messaging API設定」タブ →「Channel access token」→「Issue」
    生成されたトークンをコピー → スクリプトプロパティに貼り付け

config.js を書き換えて GitHub Pages に公開する

5-1. config.js にGASのURLを貼り付ける

ファイルの場所: D:\Google Antigravity\_publish-staging\nolia-app\js\config.js

// 変更前（このまま残っている状態）

const lineUrl = 'https://line.me/R/ti/p/YOUR_LINE_ID';

  const config = getConfig();
  const result = Admin.createUser(config.ADMIN_TOKEN, {

トラブルシューティング
症状原因対処法
「リンクが見つかりません」と出る config.jsのURLが間違い or トークンが無効 config.jsのAPI_BASEを確認。GASを「デプロイを管理」から再デプロイ
記録を保存しても何も起きない GASのCORSエラー or アクセス権限エラー デプロイ設定「アクセスできるユーザー：全員」になっているか確認。ブラウザのF12→Consoleでエラー確認
Sheetsにデータが入らない SPREADSHEET_IDが間違い スクリプトプロパティのSPREADSHEET_IDを再確認。GASログも確認
招待メールが届かない GmailApp送信エラー or 迷惑メール GASのログを確認。受信側の迷惑メールフォルダも確認
GASエラー「承認が必要」 初回実行時の認証 「権限を確認」→「詳細」→「安全でないページへ移動」→「許可」
グラフが表示されない 記録データが2件未満 or Chart.jsの読み込みエラー まず数日間記録してから確認。またはネット接続を確認（CDNが読めない可能性）
GitHub PagesのURLにアクセスしても真っ白 Pages設定が完了していない or ビルド待ち 設定後2〜5分待つ。GitHubのActionsタブでデプロイ状況を確認
GASを修正したのに反映されない 新バージョンでデプロイしていない 「デプロイ」→「デプロイを管理」→鉛筆アイコン→「バージョン：新バージョン」→「デプロイ」
ℹ️ 解決しない場合は、GASエディタ左下の「実行数」でログを確認するか、Claude Codeに「エラー内容」と「どのSTEPで止まったか」を教えてください。
