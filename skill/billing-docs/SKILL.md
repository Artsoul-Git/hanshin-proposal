# 見積書・請求書 自動生成スキル

請求書と見積書をワンコマンドで生成する統合スキル。

## トリガー判定

| キーワード | 生成物 |
|-----------|--------|
| 請求書・インボイス・請求・invoice | **請求書** |
| 見積書・見積もり・見積・御見積・quotation | **見積書** |

---

## 請求書の生成

### 必要情報（Kaiがヒアリング）

| 項目 | デフォルト |
|------|----------|
| 請求先企業名 | — |
| 業務内容 | — |
| 金額（税抜） | — |
| 請求日 | 今日 |
| 請求書番号 | 自動採番：AR-YYYYMM-NNN |

### 請求書の構成（10要素）

1. タイトル「請求書」
2. 請求書番号（AR-YYYYMM-NNN）
3. 発行日
4. 請求先（御中）
5. 請求金額合計（税込・最大フォントで強調）
6. 明細表（品名・数量・単価・小計）
7. 小計・消費税（10%）・合計
8. 支払期限（請求月末）
9. 発行者情報（社名・住所・電話・メール）
10. 振込先情報

### 計算ルール

- 消費税：10%（端数は切り捨て）
- 支払期限：請求月の末日
- 採番形式：AR-YYYYMM-001 から連番

## 見積書の生成

### 必要情報（Kaiがヒアリング）

| 項目 | デフォルト |
|------|----------|
| 見積先企業名 | — |
| 業務内容 | — |
| 金額（税抜）または明細 | — |
| 見積日 | 今日 |
| 見積書番号 | 自動採番：EST-YYYYMM-NNN |
| 有効期限 | 発行日から30日後 |

### 見積タイプ別の備考欄デフォルト

#### 月額顧問型
```
備考：
・お支払条件：月末締め翌月末払い
・契約期間：1年間（双方合意のうえ更新可）
・振込手数料はご負担ください
```

#### 時間単価型
```
備考：
・稼働時間は前月実績に基づき翌月請求
・月次稼働報告書を請求書に添付
```

#### プロジェクト型
```
備考：
・着手時：総額の30%
・中間確認完了時：総額の40%
・納品・検収完了時：残額30%
```

### 見積書の構成（10要素）

1. タイトル「御見積書」
2. 見積書番号（EST-YYYYMM-NNN）
3. 発行日
4. 見積先
5. 見積金額合計（税込・最大フォントで強調）
6. 有効期限
7. 明細表
8. 小計・消費税（10%）・合計
9. 備考（支払条件・契約期間等）
10. 発行者情報

## Kaiビジュアル標準（見積書・請求書共通）

### 設計思想
情報の優先度をフォントサイズと濃淡だけで表現する。装飾ゼロ・余白最大化。

### カラーパレット

| 用途 | カラーコード |
|------|------------|
| タイトル・最重要金額 | #1A1A1A |
| 本文テキスト | #2C2C2C |
| セクション見出し | #595959 |
| 補足・日付 | #8A8A8A |
| 区切り線 | #D8D8D8 |
| 背景 | #FFFFFF |

### フォント構成

| 要素 | サイズ | スタイル |
|------|--------|---------|
| ドキュメントタイトル | 26pt | Bold |
| 金額（最大強調） | 32pt | Bold |
| 合計金額 | 14pt | Bold |
| セクション見出し | 11pt | Bold |
| 本文・明細 | 10pt | Regular |
| 補足情報 | 9pt | Regular |

フォント：メイリオ統一

### レイアウト
- 余白：左右均等・広め
- 罫線：最小限（細い下線のみ）
- グリッド線：非表示
- 金額列：右揃え

## 見積→請求の連携フロー

```
見積書発行（EST-YYYYMM-NNN）
  ↓ クライアント承認
契約締結（/nda → /biz-contract）
  ↓
請求書発行（AR-YYYYMM-NNN）
  ※同一デザイン・同一金額で一貫性を保つ
```

## 自社情報の設定

初回実行時にKaiが確認する：
- 会社名・住所・電話番号・メールアドレス
- 振込先口座（銀行名・支店・種別・番号・名義）
- 適格請求書発行事業者登録番号（インボイス対応）

## 出力ファイル名

- 見積書：`御見積書_EST-YYYYMM-NNN.xlsx`
- 請求書：`請求書_AR-YYYYMM-NNN.xlsx`

PDF送付の場合はExcelで開いて「印刷 → PDFとして保存」。
