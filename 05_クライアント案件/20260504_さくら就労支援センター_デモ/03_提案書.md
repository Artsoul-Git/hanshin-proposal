# 【第1章】現状と課題：何が起きているのか

## 「書類が支援を妨げている」構造

ヒアリングと現場観察を通じて、貴事業所の課題の本質が明確になりました。

```
【悪循環の構造】

  利用者支援の質を上げたい
         ↓
  でも書類仕事に時間がなくなる
         ↓
  残業・疲弊→余裕がなくなる
         ↓
  ITを学ぶ時間がない
         ↓
  ずっと手書き・紙のまま
         ↓（繰り返し）
```

### 月間183時間の内訳

| 業務 | 月間工数 | 月間コスト | 最大の問題点 |
|------|--------|-----------|------------|
| 実績記録票（日次手書き） | 110時間 | 275,000円 | 支援員全員の終礼後1時間が消える |
| 国保連 請求業務 | 24時間 | 60,000円 | 転記ミス→返戻→資金繰り悪化 |
| 個別支援計画・モニタリング | 17時間 | 42,500円 | 山本さんが年140時間を手書き |
| 工賃計算 | 6時間 | 15,000円 | 集計ミスが工賃支払いミスに直結 |
| その他 | 26時間 | 65,000円 | 情報が紙に散在、探せない |
| **合計** | **183時間** | **457,500円** | |

### 「このまま5年続けたら」リスク

```
コスト：457,500円/月 × 60ヶ月（5年）= 約2,745万円が書類作業に消える

人材リスク：
  山本さんへの依存度 = 100%
  万が一、山本さんが退職・長期休職した場合 →
  個別支援計画・請求・モニタリング全てが止まる。
  事業継続不能になるリスクあり。

品質リスク：
  書類作業の疲労から支援員のモチベーションが低下
  → 利用者への支援品質が低下
  → 指定取消・減算リスク

資金リスク：
  返戻が年3回 → 最大で3ヶ月分の請求が滞留
  → 月200万円規模の売上が不安定化
```

# 【第2章】解決策：何をどうするのか

## 3つの改革の柱

```
╔═══════════════════════════════════════════════════╗
║  柱①「記録のデジタル化」                            ║
║  紙への手書き → スマホ/タブレット入力に変える        ║
╠═══════════════════════════════════════════════════╣
║  柱②「集計・転記の自動化」                          ║
║  入力したデータが自動で集計・請求データに変換される  ║
╠═══════════════════════════════════════════════════╣
║  柱③「文書作成のAI補助」                            ║
║  個別支援計画・モニタリング記録をAIが下書き作成      ║
╚═══════════════════════════════════════════════════╝
```

## 柱①：実績記録票のデジタル化（Month 1〜2）

**使用ツール**：Google フォーム ＋ Google スプレッドシート（無料）

```
【変革前】
  支援員が紙に手書き（1時間/日/人）
  → ファイルに綴じる
  → 月末にサビ管が1枚ずつ集計（8時間）

【変革後】
  支援員がスマホで入力（10分/日/人）
  → スプレッドシートに自動記録
  → 月末に自動集計済み（確認30分）

ポイント：
  ・操作はLINEと同じ感覚（選択肢を選ぶだけ）
  ・スマホ1台あれば使える（新しい機器の購入不要）
  ・利用者名・作業内容はプルダウン選択（タイプ不要・ミス防止）
```

## 柱②：工賃計算・請求業務の自動化（Month 2〜3）

**使用ツール**：Google スプレッドシート ＋ GAS（Google Apps Script）

```
【自動化の仕組み】
  実績入力フォームの回答 →（自動集計）→ 工賃計算シート
                                      ↓（自動転記）→ 請求データ
                                      ↓（確認後）  → 国保連ソフトへ入力

期待効果：
  ・工賃計算：6時間/月 → 30分/月（確認のみ）
  ・請求業務：24時間/月 → 1〜2時間/月
  ・返戻リスク：ほぼゼロ（転記という行為がなくなるため）
```

## 柱③：個別支援計画書のAI補助作成（Month 3〜4）

**使用ツール**：ChatGPT（またはGemini）＋ 専用プロンプト

```
【変革前】
  山本さんが過去の計画書を見ながら手書き（2.5時間/名）

【変革後】
  利用者の基本情報・課題・目標をフォームに入力
  → AIが計画書の文章を下書き生成（5分）
  → 山本さんが確認・修正・押印（30分）

注意事項：
  ・AIの出力は必ず山本さんが確認・修正してから使用
  ・個人情報の入力ルールを事前に策定（律がチェック）
  ・最終的な判断・責任はサービス管理責任者にある

期待効果：
  ・計画書作成：2.5時間/名 → 40分/名
  ・年2回 28名分：140時間 → 37時間（103時間削減）
```
