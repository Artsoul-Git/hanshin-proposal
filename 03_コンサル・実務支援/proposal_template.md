# 【第3章】解決策：弊社の支援内容

## 3-1. ACTモデル（AI Core Transformation）とは

```
       【現状】              【6ヶ月後】
  ─────────────     ─────────────────
  ・作業に追われる毎日  →   ・AIが単純作業を自動化
  ・特定の人しかできない →   ・誰でもできる仕組み化
  ・残業・人手不足      →   ・余剰時間を価値ある仕事へ
  ・外注費がかさむ      →   ・内製化でコスト削減
```

## 3-2. 御社向け支援プログラムの全体像

### Phase 1：基礎構築（Month 1〜2）

| 内容 | 詳細 |
|------|------|
| **AI基礎研修（全___時間）** | ChatGPT/Gemini等の基本操作＋業務別プロンプト設計 |
| **優先業務の自動化実装** | 【第1優先業務名】の効率化（目標：___分→___分） |
| **AIマネージャー育成** | 社内推進者___名を集中育成 |

### Phase 2：実装・定着（Month 3〜4）

| 内容 | 詳細 |
|------|------|
| **第2・第3優先業務の実装** | 【業務名】【業務名】の効率化 |
| **業務フロー再設計** | AI込みの新業務フロー・SOPの整備 |
| **KPI計測体制の構築** | 月次成果を自動集計できる仕組み |

### Phase 3：拡張・自走（Month 5〜6）

| 内容 | 詳細 |
|------|------|
| **横展開** | 成功パターンを他部署・他業務へ展開 |
| **社内自走体制の完成** | AIマネージャーが独立して改善を推進できる状態 |
| **次期計画の設計** | さらなる成長への6ヶ月計画 or 顧問移行 |

## 3-3. 弊社サポート体制

```
【訪問・面談スケジュール】
  Phase 1（Month 1-2）：月1回訪問（またはオンライン）＋週1回オンライン面談
  Phase 2（Month 3-4）：隔週オンライン面談（月2回）
  Phase 3（Month 5-6）：月1回オンライン面談

【随時サポート】
  チャット相談：平日9:00〜18:00に原則24時間以内に回答
  緊急対応：システム・ツールのエラー等は優先対応

【担当チーム】
  プロジェクトリード  ：ケイ（代表）
  戦略・計画設計     ：策（さく）AI社員
  現場改善・実装     ：改（かい）AI社員
  データ・ROI分析    ：財（ざい）AI社員
  変革・定着支援     ：渉（わたる）AI社員
  システム開発      ：巧（たくみ）AI社員
  品質保証          ：守（まもる）AI社員
```
