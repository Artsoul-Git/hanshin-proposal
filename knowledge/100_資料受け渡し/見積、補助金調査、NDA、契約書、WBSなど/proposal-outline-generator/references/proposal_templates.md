# 提案パターン別テンプレート

## AI/DXアドバイザリー提案

### パターン1: 業務自動化提案

**対象**: 定型業務の手作業が多い企業

**課題例**:
- 請求書・経費精算の手入力
- データ転記・集計作業
- 定型レポート作成

**提案アプローチ**:
```
生成AIを活用した{業務名}の自動化と
業務フローの最適化
```

**なぜこのアプローチか**:
- 手作業の削減による工数・コスト削減効果が大きい
- 既存システムとの連携が容易
- 段階的な導入でリスクを最小化できる

|------|------|
| 工数削減 | 約{XX}%削減 |
| コスト | 年間約{XX}万円 |
| 品質向上 | 入力ミスの大幅削減 |


### パターン2: 情報活用・ナレッジ化提案

**対象**: 属人化・ノウハウ共有に課題がある企業

**課題例**:
- ベテランのノウハウが共有できていない
- 顧客対応履歴が活用できていない
- マニュアルが古い・探せない

**提案アプローチ**:
```
生成AIを活用したナレッジベース構築と
社内情報の一元化・活用促進
```

**なぜこのアプローチか**:
- 暗黙知を形式知化し、組織の資産にできる
- 自然言語で検索・質問できるため現場負担が少ない
- 継続的な知識蓄積の仕組みが構築できる

|------|------|

### パターン3: 意思決定支援提案

**対象**: データ分析・レポート作成に課題がある企業

**課題例**:

**なぜこのアプローチか**:
- 散在するデータを統合・分析できる

## 業種別アレンジ

### 製造業

**よくある課題**:
- 在庫管理の精度
- 生産計画の最適化
- 品質管理データの活用

**提案キーワード**:
- 生産性向上、歩留まり改善、予知保全


### 小売・サービス業

**よくある課題**:
- 顧客データの活用
- 需要予測
- スタッフシフト最適化

**提案キーワード**:
- 顧客体験向上、売上予測、人員最適化


### 金融・保険業

**よくある課題**:
- コンプライアンス対応
- 顧客対応履歴管理
- 帳票作成の効率化

**提案キーワード**:
- リスク管理、顧客満足度向上、業務効率化


### 福祉・介護

**よくある課題**:
- 記録業務の負担
- シフト作成の大変さ
- 国保連請求のミス

**提案キーワード**:
- 現場負担軽減、ケア品質向上、請求精度向上
