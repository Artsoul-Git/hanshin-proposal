## 緊急時の補充体制

| 欠員状況 | 対応フロー |

| 川口欠勤 | 山下が西市担当兼任。前田を一時呼び戻し検討 |
| 松岡欠勤 | 高橋が管理者代行。個別支援計画対応は翌日以降に延期 |
| 岡本欠勤 | 早島拠点の作業を縮小（10名→6名体制）。前田が応援 |
| 石井欠勤（送迎） | 岡田が西市送迎に回る。一部利用者に「本日自力来所」連絡 |
| 岡田欠勤（送迎） | 石井が早島まで対応。時間調整必要 |
| 2名以上欠員 | 高橋が判断し、場合によって当日の外就をキャンセル |
