# サンプル案件

## PILOT-001-sample
中小製造業向けAI活用セミナー（120分・80スライド版）の完成例。

### 含まれるファイル
- `brief.md`：案件ブリーフ
- `slide-spec-with-diagrams.json`：80スライド分の仕様
- `07_script.md`：80スライド分の本物の台本
- `sample_output.pptx`：dynamic_business_clean スタイルでビルドした実物

### 学習ポイント
- 必須オープニング5枚の実例（スライド1〜5）
- pattern-sales（営業型）の構造
- 12枚の図解組み込み（スライド7,15,18,31,33,36,39,47,51,53,55,60）
- クリシェ排除の実例
- 文体バリエーション（です・ます/体言止め/問いかけ/断言の混在）

### 自分の案件で活用するには
1. `brief.md` を自社案件用に書き換え
2. CHIEF に「[案件ID] の制作を進めて」と指示
3. TAKUMI が13工程を自動実行
4. 完成した .pptx を確認＆クライアント納品
