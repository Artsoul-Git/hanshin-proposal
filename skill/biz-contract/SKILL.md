# 業務委託契約書 自動生成スキル

AI支援・コンサルティング業務に最適化した業務委託契約書をWord形式で生成するスキル。受託者としての専門家的立場を守りつつ、委託者が安心して発注できるバランスを重視した15条構成。

## トリガーワード

- 「業務委託契約書を作成して」
- 「コンサル契約が必要」
- 「顧問契約書を作って」
- 「業務委託の書類を準備して」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 内容 |
|------|------|
| 委託者 | 発注側の企業名・代表者名 |
| 受託者 | 受注側の企業名・代表者名 |
| 業務内容 | 提供するサービスの具体的な説明 |
| 報酬タイプ | 月額顧問 / 時間単価 / 成果連動 / プロジェクト一括 |
| 報酬額 | 税抜金額 |
| 契約期間 | 開始日・終了日・自動更新の有無 |
| 知的財産権 | 受託者帰属（デフォルト）or 委託者帰属 or 共有 |
| 再委託 | 可否・事前承諾の要否 |
| 損害賠償上限 | 省略→月額の最大6ヶ月分 |

---

## 15条構成

| 条項 | タイトル | 内容・特徴 |
|------|---------|----------|
| 第1条 | 目的 | 委託・受託の基本関係の確認 |
| 第2条 | 業務の範囲 | 具体的な業務内容と対象外事項の明示 |
| 第3条 | 実施体制 | 担当者・連絡窓口・報告頻度 |
| 第4条 | 契約期間 | 1年間・自動更新・**2ヶ月前通知**で解約可 |
| 第5条 | 報酬と支払 | 月末締め翌月末払い・振込費用は委託者負担 |
| 第6条 | 成果物と検収 | 成果物の定義・検収期間（原則10営業日） |
| 第7条 | **知的財産権** | デフォルト：受託者帰属＋委託者への包括的利用許諾 |
| 第8条 | 情報管理 | 委託者情報の機密保持（NDAを別途締結する場合は優先） |
| 第9条 | **再委託** | デフォルト：事前書面承諾で可能 |
| 第10条 | 委託者の協力義務 | 情報提供・担当者選任・環境整備 |
| 第11条 | 受託者の義務 | 善管注意義務・報告義務・法令遵守 |
| 第12条 | **損害賠償と責任制限** | 上限：月額の最大6ヶ月・間接損害は除外・故意重過失は別途 |
| 第13条 | 契約の解除 | 重大な義務違反・支払遅延・信用悪化・破産 |
| 第14条 | 反社会的勢力の排除 | 暴力団等反社勢力との関与排除条項（即時解除あり） |
| 第15条 | 一般条項 | 変更手続き・可分性・協議義務・準拠法・合意管轄 |

## 知的財産権の帰属パターン

本スキルの標準は「**受託者帰属型＋包括ライセンス**」。コンサルタントとしての専門的ノウハウを守りながら、委託者が実務で活用できる権利を確保する。

| タイプ | 内容 | 適するケース |
|--------|------|------------|
| **受託者帰属＋包括ライセンス（標準）** | 著作権は受託者。委託者は委託目的内で無制限に利用可 | コンサル・教育・ノウハウ提供 |
| 共有型 | 双方が共同著作者として共有 | 共同開発・双方のリソースを投じる場合 |
| 委託者帰属型 | 著作権は委託者に帰属。受託者は実績として公表可 | システム開発・委託者専用ツール制作 |

---

## 報酬体系の設定

| タイプ | 標準設定 | 第5条の記述 |
|--------|---------|-----------|
| 月額顧問型（標準） | 月額固定 | 毎月同額・月末締め翌月末払い |
| 時間単価型 | 単価×実績時間 | 稼働時間を翌月10日までに報告・精算 |
| 成果連動型 | 基本報酬＋達成報酬 | 達成基準・測定方法・上限額を別紙で定める |
| プロジェクト型 | 総額分割 | 着手時・中間・完了時の3回分割（比率は個別設定） |

---

## 損害賠償の計算基準

```
賠償上限 = 月額報酬 × 最大6ヶ月分

例：月額30万円の顧問契約
  → 最大180万円が賠償上限

プロジェクト型の場合：契約総額の30%を上限とする
```

**除外事項**：間接損害・逸失利益・将来の収益喪失は賠償対象外（故意・重大な過失による場合を除く）

---

## 契約期間と解約の整理

- 標準期間：**1年間**（自動更新）
- 解約通知：更新拒絶は**期間満了2ヶ月前**までに書面で通知
- 即時解除事由：重大な義務違反・支払い遅延が2ヶ月以上・破産・反社関与
- 中途解約：委託者からの解約は1ヶ月前通知＋残存業務費用の精算

## 技術仕様

- ライブラリ：docx.js（Node.js）
- フォント：MS Mincho（日本語契約書標準）
- 出力形式：.docx（A4・余白上下25mm・左右30mm）

## 出力ファイル名

`業務委託契約書_{クライアント名}_{日付}.docx`

## 注意事項

本スキルが生成する契約書は実務的な標準ひな形です。案件の特性・委託者の要求・業種固有のリスクによって追加・修正が必要な場合があります。締結前には弁護士等の専門家への確認を推奨します。
