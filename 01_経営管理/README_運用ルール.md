# 01_経営管理 — 運用ルール

このフォルダはアートソウル自社の経営判断・戦略記録・Kaiとの思考ログを管理する。

---

## フォルダ構成

```
01_経営管理/
├── README_運用ルール.md         ← このファイル
├── 構造改革ロードマップ_2026.md  ← 中長期の設計書（Kaiが随時更新提案）
└── Kaiブリーフィング記録/        ← 時系列の戦略思考ログ
    └── YYYY-MM-DD_タイトル.md
```

---

## Kaiブリーフィング記録とは

Kaiが事業・戦略・案件について踏み込んだ分析・提言を出した時の記録。

**記録するタイミング：**
- 事業戦略・方向性について議論した時
- 重要な判断・意思決定をした時
- 新しい知見や方針転換があった時

**記録しないもの：**
- 提案書の通常修正作業（それはクライアント案件フォルダに記録）
- 単純なファイル作成・変換作業

---

## ファイル命名規則

```
YYYY-MM-DD_内容を表すキーワード（20文字以内）.md
例：2026-05-09_事業認識・構造改革提言.md
    2026-06-15_まる様フェーズ2戦略.md
```

---

## 閲覧・活用方法

- 「あの時どう議論したっけ」→ファイル名を見れば日付と概要がわかる
- 「Kaiの認識がずれてないか確認したい」→ファイルを開いて読む
- 「この方針って以前と変わった？」→複数ファイルを比較する

---

## 更新ルール

- 上書きせず新規ファイルを作成する（時系列を保つ）
- 方針が変わった場合は古いファイルに「→更新版：YYYY-MM-DD」と追記してよい
- git管理対象とする（重要な経営判断のバックアップ）
