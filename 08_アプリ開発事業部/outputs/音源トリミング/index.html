セキュリティ・利用ポリシー
🔒
完全ローカル処理 — 音声データは外部に出ません アップロードした音声ファイルはすべてブラウザ内のみで処理されます。 外部サーバーへの音声データ送信は一切行いません。
📡
外部通信について 通常の使用中は外部通信は発生しません。
MP3形式で書き出す場合のみ、エンコーダライブラリ（lamejs）を Cloudflare CDN から取得します。
※ 取得するのはコードのみです。音声データは送信されません。
💰
完全無料・API コストゼロ 外部 API は使用していません。GitHub Pages による静的配信のため サーバー運用コストも発生しません。
📊
ログ・トラッキングなし 個人情報の収集・行動トラッキングは行いません。 GitHub Pages の標準アクセスログ（匿名統計）のみが記録されます。
