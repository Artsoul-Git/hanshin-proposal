# 提案骨子 自動生成スキル

ヒアリング結果から1〜2ページの提案骨子をWord形式で生成するスキル。商談後の提案準備時間を大幅に短縮する。

## トリガーワード

- 「提案骨子を作成して」
- 「提案のたたきを作って」
- 「このヒアリングから提案を作って」
- 「提案アウトラインを生成して」

---

## 入力ソース（優先度順）

1. **hearing-sheet（.xlsx）** — `/hearing-sheet` で生成したExcelファイル（最優先）
2. **文字起こしテキスト（.txt）** — 音声録音の文字起こし
3. **手書きメモ（直接貼り付け）** — 会社名・業種・主要課題が最低限必要

---

## hearing-sheetからの自動抽出

| 抽出項目 | 抽出元 |
|---------|--------|
| クライアント名 | 基本情報シート |
| 業種・従業員数 | 基本情報シート |
| 課題の優先順位 | 優先度・ゴール整理シート |
| 理想の状態 | 優先度・ゴール整理シート |
| 予算感 | 優先度・ゴール整理シート |
| 困っていること | 部門別シート（チェック済み項目） |
| 具体的なエピソード | 部門別シート |

---

## 提案タイプの自動判定

| 検出キーワード | 提案タイプ |
|---------------|-----------|
| AI・生成AI・自動化・効率化・DX・デジタル化 | **AI/DX支援** |
| システム導入・ツール導入・クラウド・Excel脱却 | **IT導入支援** |
| 上記が混在・不明 | 両方を含む提案 |

---

## 出力フォーマット（A4縦1〜2ページ）

```
┌─────────────────────────────────────────────┐
│        ご提案骨子                            │
│        {クライアント名} 様                  │
│        {日付}                               │
├─────────────────────────────────────────────┤
│  ■ 現状課題の整理                           │
│    1. {課題1}                               │
│       └ {具体的な影響・数値}                │
│    2. {課題2}                               │
│    3. {課題3}                               │
├─────────────────────────────────────────────┤
│  ■ ご提案の方向性                           │
│    【アプローチ】                            │
│    {AI/DX導入 or IT導入}による解決策の概要  │
│    【なぜこのアプローチか】                  │
│    ・{理由1}                                │
│    ・{理由2}                                │
├─────────────────────────────────────────────┤
│  ■ 期待効果                                 │
│    工数削減    約XX%削減                    │
│    コスト      年間XX万円削減               │
│    品質向上    {定性効果}                   │
├─────────────────────────────────────────────┤
│  ■ 次のステップ                             │
│    □ 詳細ヒアリング（{日程候補}）           │
│    □ 正式見積のご提示                       │
│    □ PoC（概念実証）のご相談               │
└─────────────────────────────────────────────┘
```

---

## 文字起こしからの課題抽出ロジック

| 発話パターン | 抽出分類 |
|-------------|---------|
| 「困っている」「課題」「問題」 | 課題 |
| 「したい」「欲しい」「必要」 | 要望 |
| 数値表現（○時間・○人・○円） | 定量データ |

---

## 他スキルとの連携

```
/hearing-sheet  → ヒアリングシートに課題を整理
    ↓
/proposal-outline → 課題から提案骨子を生成
    ↓
/billing-docs → 提案内容をもとに見積書を作成
    ↓
/nda → 機密保持契約書の締結
    ↓
/biz-contract → 業務委託契約書の締結
    ↓
/wbs-gantt → プロジェクトスケジュール作成
```

## DO / DO NOT

### やること
- ヒアリング結果からの課題構造化
- 顧客目線の価値訴求文の生成
- AI/DX提案と汎用IT提案の両方に対応
- 1〜2ページのシンプルなアウトライン

### やらないこと（別スキルの役割）
- 詳細な実装計画（→ /wbs-gantt）
- 見積金額の算出（→ /billing-docs）
- 5ページ以上の詳細提案書（→ /sme-ai-proposal）
- 競合比較の詳細分析

## 出力ファイル名

`提案骨子_{クライアント名}_{YYYYMMDD}.docx`
