# まる様 AI記録自動生成システム — セットアップ手順

## 必要なもの
- Google Workspace Business Standard アカウント
- Gemini API キー（Google AI Studio: aistudio.google.com から無料取得）

---

## ファイル構成

```
src/
├── Setup.gs      ← スプレッドシート自動構築・カスタムメニュー・サイドバー
├── Config.gs     ← 設定値・書類種別定義
├── Code.gs       ← doGet（UI返却）+ クライアント呼び出し関数
├── Sheets.gs     ← 利用者取得・生成ログ保存
├── Masking.gs    ← 個人情報マスキング（送信前後）
├── Generator.gs  ← Gemini API + プロンプトテンプレート
├── Watcher.gs    ← Drive監視（Mode B）※Phase 2
├── UI.html       ← フロントエンドSPA（スマホ対応）
└── Sidebar.html  ← IT初心者向けガイド（スプレッドシートサイドバー）
```

---

## Step 1: 新しいスプレッドシートを作成

Google Drive で「新規」→「Google スプレッドシート」を作成する。
（シート名・内容はGASが自動で作るため、空白のままでOK）

---

## Step 2: GASプロジェクトの作成

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く
2. 左側の「ファイルを追加（+）」で以下のファイルを追加し、`src/`の内容をコピペ

| 追加するファイル | 種別 | コピー元 |
|---------------|-----|---------|
| Setup | スクリプト（.gs） | src/Setup.gs |
| Config | スクリプト（.gs） | src/Config.gs |
| Code | スクリプト（.gs） | src/Code.gs |
| Sheets | スクリプト（.gs） | src/Sheets.gs |
| Masking | スクリプト（.gs） | src/Masking.gs |
| Generator | スクリプト（.gs） | src/Generator.gs |
| Watcher | スクリプト（.gs） | src/Watcher.gs |
| UI | **HTMLファイル** | src/UI.html |
| Sidebar | **HTMLファイル** | src/Sidebar.html |

---

## Step 3: APIキーをスクリプトプロパティに設定

Apps Script エディタ左サイドバー「プロジェクトの設定」→「スクリプトプロパティ」→「プロパティを追加」

| プロパティ名 | 値 |
|-----------|---|
| `GEMINI_API_KEY` | Google AI Studio で取得したAPIキー |

※ `SPREADSHEET_ID` は**スプレッドシートを開いたときに自動保存**されるため手動設定不要

---

## Step 4: デプロイ

1. Apps Script エディタ右上「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」を選択
3. 実行ユーザー：「自分」
4. アクセスできるユーザー：「組織内のユーザー全員」
5. 「デプロイ」→ URLをコピーして控えておく

---

## Step 5: スプレッドシートの初期化（GASが自動で実行）

1. スプレッドシートに戻り、ページをリロードする
2. 上部メニューに「🤖 AI記録システム」が表示される（初回は権限の承認が必要）
3. 「🤖 AI記録システム」→「📋 初期セットアップ実行（初回のみ）」をクリック
4. ✅ 完了のアラートが出たら、3つのシートが自動で作成・フォーマットされる

---

## Step 6: 利用者マスターを入力

- 「利用者マスター」シートを開く
- サンプルデータ（黄色い行）を削除して実際の利用者を入力

---

## Step 7: 現場スタッフにURLを共有

- 「🤖 AI記録システム」→「🔗 アプリのURLを確認する」でWebアプリのURLを確認
- スマホ・PCのブラウザから開けることを確認して現場に共有

---

## 使い方（現場スタッフ向け）

1. アプリURLをブラウザで開く（GWSアカウントでログイン）
2. 利用者を選択 → 書類種別を選択
3. 担当者名を入力
4. 面談メモを自由入力（箇条書きでOK）
5. 「AIで書類を生成する」をタップ（約20〜40秒）
6. 生成内容を確認・修正して「保存する」

---

## サイドバーガイド（管理者・スタッフ向け）

スプレッドシートで「🤖 AI記録システム」→「📖 使い方ガイドを開く」

スプレッドシートの右側にIT初心者向けのガイドが表示されます：
- システムの使い方（5ステップ）
- 利用者マスターの登録方法
- 対応書類の種類
- 生成ログの見方
- よくある質問（FAQ）
- 管理者向け設定メモ

---

## 注意事項

- 個人情報はGAS側でマスキング後にGemini APIへ送信（氏名はプレースホルダーに変換）
- Gemini API無料枠：1日1,500リクエストまで（月50件×3種=150件なら余裕）
- Mode B（音声ファイル自動処理）はPhase 2で追加予定
