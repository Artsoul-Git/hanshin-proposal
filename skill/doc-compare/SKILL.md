# 新旧対比表 自動生成スキル

2つの文書を比較し、変更箇所を明確に可視化した新旧対比表をWord形式で出力するスキル。

## トリガーワード

- 「新旧対比表を作成して」
- 「対比表を生成して」
- 「比較表を作って」
- 「変更箇所を比較して」

## 用途

- 就業規則・社内規程の改訂管理
- 契約書・覚書の変更箇所の可視化
- 業務マニュアル・手順書の更新履歴
- 議事録・報告書の修正確認

---

## 基本ワークフロー

```
[準備] 変更前ファイル + 変更後ファイルをアップロード
    ↓
[解析] 文書の見出し構造・階層を自動検出
    ↓
[照合] 条文・項目レベルで変更箇所を特定
    ↓
[出力] 新旧対比表.docx を生成
```

## 入力形式

- Word文書（.docx）推奨
- PDF可（テキストを自動抽出して処理）

---

## 自動認識する見出しパターン（13種）

| パターン | 例 | 階層 |
|---------|-----|------|
| 法令条文 | 第3条、第十五条 | Level 1 |
| 法令章 | 第1章、第10章 | Level 1 |
| 附則 | 附則、附則（施行日） | Level 1 |
| 番号付き見出し | 3. (見出し) | Level 1 |
| 階層番号 | 1.1、3.2.1 | Level 2以上 |
| ハイフン番号 | 1-1、3-2 | Level 2 |
| 括弧番号 | (1)、（3） | Level 2 |
| 片括弧 | 1)、3） | Level 2 |
| 単純番号 | 1. 、2. | Level 2 |
| 角括弧 | 【1】、［3］ | Level 2 |
| 英語見出し | Article 3、Section 5 | Level 1 |
| 枝番条文 | 第3条の2、第5条の3 | Level 1 |
| 記号見出し | §3、■ 3 | Level 1 |

---

## 変更の表示ルール

| 種別 | 表示 |
|------|------|
| 変更後テキスト | 赤字・太字・下線 |
| 変更前テキスト | 黒字・太字・下線 |
| 新規追加 | 青字・太字、左セルに「(新規追加)」 |
| 削除 | 赤字・取り消し線、右セルに「(削除)」 |

- デフォルト列順：**変更後（新）→ 変更前（旧）**
- 変更なし条文は表示しない（変更箇所のみ抽出）
- 1条文につき1セルに集約（内部に区切り線なし）

---

## 列順序の指定

```
# 変更後→変更前（デフォルト）
→ そのまま実行

# 変更前→変更後（旧来の並び）
「旧→新の順で対比表を作って」と指定
```

---

## 照合の仕組み

**ステップ1：構造マッチング**
見出し名のテキスト類似度スコアが75%以上の条文を優先的に対応付け。「安全衛生管理」「健康管理」など名称が近い見出しを自動識別。

**ステップ2：内容マッチング**
ステップ1で未対応の残余条文を、本文のテキスト類似度スコアで対応付け。

条文番号がずれた場合（章の挿入・削除・番号振り直し等）でも正確に対応付けられる。

---

## 出力ファイル

- 形式：Word（.docx）
- ファイル名：`新旧対比表_{文書名}_{日付}.docx`
- フォント：メイリオ

---

## 対応シナリオ例

**就業規則の章追加**
```
旧: 第1条〜第50条（50条構成）
新: 第1条〜第50条 + 第5章（退職金規程）追加 → 第57条まで

→ 条文番号のずれを自動解決
→ 追加された章は「(新規追加)」で表示
```

**契約書の条項変更**
```
第5条（諸手当）の (1) 金額変更 + (6)(7) 新規追加
→ 変更された (1) のみ差分表示
→ 新規の (6)(7) は正しい順序で「(新規追加)」表示
→ 変更なしの (2)〜(5) は表示しない
```
