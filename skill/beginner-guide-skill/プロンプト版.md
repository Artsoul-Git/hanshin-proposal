# コピペ用プロンプト：初心者向けHTMLガイド作成

毎回長いSKILL.mdを読ませるのが面倒なときは、以下を丸ごとコピペして指示する。

---

## 短縮プロンプト（基本）

```
完全初心者（PC操作・IT用語ゼロレベル）向けのHTMLガイドブックを作って。

【テーマ】：（ここに作りたいガイドの内容を書く）

【読者像】：（ここに想定読者を書く。例：50代の経営者、新人事務員、機械が苦手な経営者など）

【最終ゴール】：（ここに読者ができるようになることを書く）

ガイドの仕様：
- HTML形式、Yu Gothic UIフォント、ネイビー＋オレンジ配色
- 表紙＋目次＋本編＋トラブルシューティング＋用語集＋付録という構成
- 各章にステップ番号付きカード（.step）と色分け枠（tip/warn/ok）
- フロー図はSVGで作成（縦並びで1ステップ100px）
- 操作画面はASCIIアートで再現
- 専門用語は全て初出時に超ざっくり定義
- 「クリックする場所」「打つ文字」を物理的に明示
- 「簡単」「すぐ」を多用しない
- 二人称（〜してください）で話しかける
- 複数の方法（メニューから / ショートカット / 右クリック）を併記

ファイル保存先：outputs/{ガイド名}.html
完了したら computer:// リンクで提示。
```

## 詳細指定したい時のプロンプト

```
完全初心者向けHTMLガイドブックを作って。SKILL.mdの仕様に沿って。

【テーマ】：

【読者像】：
- 知識レベル：（完全初心者 / 基本操作はできる / ある程度詳しい）
- 年齢層：
- 業務：
- 詰まりやすいポイント（推測）：

【最終ゴール】：（このガイドを読み終えると何ができるようになるか）

【使用環境】：
- OS：Windows / Mac / 両方対応
- 必要なソフト：
- モニタ枚数：1枚 / 2枚 / 不問

【ボリューム】：
- 30分で読める軽めの入門
- 1時間かけて全機能網羅
- 辞書的に都度参照する分厚い版

【トーン】：
- 堅め（社内文書）
- 標準
- カジュアル（フランクに語りかける）

【特に強調したいこと】：
- （複数あれば箇条書き）

【除外したいこと】：
- （触れて欲しくないトピックがあれば）

章構成は以下のテンプレに沿って：
1. このガイドで何ができるようになるか
2. 必要なもの（チェックリスト）
3. 使う言葉を超ざっくり説明
4. 全体の流れ（フロー図SVG）
5〜N. 操作の各ステップ
N+1. こんな時どうする（トラブルシューティング）
N+2. 用語集
付録A〜C. 効率化Tips、比較表、応用設定

完成したら outputs/{ガイド名}.html に保存して computer:// リンクで提示。
最後に章構成案だけ先に箇条書きで見せて、OKもらってから本文生成に入って。
```

## 既存ガイドを修正したい時のプロンプト

```
outputs/{既存ガイド名}.html を読んで、以下を修正して：

【修正内容】：
- （何をどう変えたいか具体的に）

修正のポイント：
- 既存の章番号・ID・スタイルは可能な限り維持
- 大きな変更は付録として追記する形で
- スタイル（色、CSS、構造）は崩さない
- 既存の用語と統一する

修正後、変更箇所のサマリーを箇条書きで報告して。
```

## サンプル使用例

### 例1：Slack新人向けマニュアル

```
完全初心者向けHTMLガイドブックを作って。

【テーマ】：Slack入社初日マニュアル

【読者像】：チャットツール未経験の新卒社員（20代前半）

【最終ゴール】：
- Slackにログイン
- 部署のチャンネルに参加
- メンション付きでメッセージ送信
- DMで上司に質問
- スレッド機能で会話を整理
- 通知をオフにできる

ガイドの仕様：
- HTML形式、Yu Gothic UIフォント、ネイビー＋オレンジ配色
- 表紙＋目次＋本編＋トラブル＋用語集＋付録
- 各章にstep番号カード、色分け枠
- フロー図はSVG、画面はASCII
- 専門用語は全部定義
- クリック場所まで明示

ファイル保存先：outputs/Slack新人マニュアル.html
完了したら computer:// リンクで。
```

### 例2：経費精算マニュアル

```
完全初心者向けHTMLガイドブックを作って。

【テーマ】：経費精算システム（freee）の使い方マニュアル

【読者像】：
- 知識レベル：基本のPC操作はできるが経費精算システムは初めて
- 年齢層：30〜50代
- 業務：営業職で出張多め
- 詰まりやすいポイント：領収書のスキャン、勘定科目の選択

【最終ゴール】：
- 出張から戻ったその日に経費精算を完了できる

【使用環境】：
- Windows / 社支給スマホ
- freeeアカウント支給済み
- スマホアプリでも操作可

【ボリューム】：30分で読める入門

【トーン】：堅め（社内文書）

【特に強調したいこと】：
- 領収書を捨てない（重要）
- 月末締め日の厳守
- 私用と業務の混在NG

完成したら outputs/freee経費精算マニュアル.html に保存。
章構成案だけ先に見せて。
```

## 使い方

1. 上記のプロンプトを丸ごとコピー
2. `【】` で囲まれた部分を自分の状況に合わせて埋める
3. Claudeに貼り付けて送信
4. 章構成案が出てきたらレビュー → OKなら「進めて」
5. HTMLが生成されたら computer:// リンクをクリックしてブラウザで確認
6. 修正したい箇所があれば「修正したい時のプロンプト」を使う
