# 業務委託契約書 自動生成スキル

AI支援・コンサルティング業務に特化した業務委託契約書をWord形式で生成するスキル。受託者・委託者双方に公平なバランス型の内容を標準とする。

## トリガーワード

- 「業務委託契約書を作成して」
- 「コンサル契約が必要」
- 「顧問契約書を作って」
- 「業務委託の書類を準備して」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 内容 |
|------|------|
| 委託者名 | 発注側の企業名 |
| 受託者名 | 受注側の企業名 |
| 業務内容 | 具体的な業務の説明 |
| 報酬体系 | 月額 or 時間単価 or 成果報酬 or プロジェクト型 |
| 月額報酬 | 税抜金額 |
| 契約期間 | 開始日・終了日（自動更新の有無） |
| 知的財産権 | 共有・委託者帰属・受託者帰属 |
| 再委託 | 可否・条件 |
| 損害賠償上限 | 金額（省略→月額報酬の3倍相当） |

---

## 標準的な契約構成（18条）

| 条項 | 内容 |
|------|------|
| 第1条 | 目的 |
| 第2条 | 業務内容 |
| 第3条 | 契約期間（1年・自動更新・3ヶ月前通知で解約） |
| 第4条 | 報酬・支払条件（月末締め翌月末払い） |
| 第5条 | 成果物 |
| 第6条 | **知的財産権**（デフォルト：共有型） |
| 第7条 | **再委託**（デフォルト：事前書面承諾） |
| 第8条 | 機密保持（別途NDAに従う） |
| 第9条 | 委託者の義務（情報提供・担当者選任） |
| 第10条 | 受託者の義務（善管注意義務） |
| 第11条 | 契約解除（義務違反・破産等） |
| 第12条 | **損害賠償**（上限設定・故意重過失除外・直接損害のみ） |
| 第13条 | 権利義務の譲渡禁止 |
| 第14条 | 反社会的勢力の排除 |
| 第15条 | 契約の変更（書面合意のみ） |
| 第16条 | 分離可能性 |
| 第17条 | 協議事項 |
| 第18条 | 管轄裁判所 |

## カスタマイズオプション

### 報酬体系

| タイプ | 内容 |
|--------|------|
| 月額顧問型（標準） | 月額固定報酬 |
| 時間単価型 | 時間単価×実績稼働時間 |
| 成果報酬型 | 基本報酬＋成果達成時の追加報酬 |
| プロジェクト型 | 総額を着手金・中間金・完了時に分割 |

### 知的財産権の帰属

| タイプ | 内容 |
|--------|------|
| 共有型（標準） | 委託者・受託者の共有 |
| 委託者帰属型 | 委託者に帰属、受託者は実績公表権のみ |
| 受託者帰属型 | 受託者に帰属、委託者に使用許諾 |

### 損害賠償の上限額

| 規模 | 目安金額 |
|------|---------|
| 小規模 | 月額報酬×3ヶ月分 |
| 標準 | 月額報酬×6ヶ月分 |
| 大規模プロジェクト | 個別に設定 |

## 技術仕様

- ライブラリ：docx.js（Node.js）
- フォント：MS Mincho（日本語契約書標準）
- 出力形式：.docx（A4・余白各25.4mm）

## 出力ファイル名

`業務委託契約書_{クライアント名}_{日付}.docx`
