# 機密保持契約書（NDA）自動生成スキル

企業間取引における機密情報保護のためのNDAをWord形式で生成するスキル。損害賠償上限と秘密保持期間を明示した、双方にバランスの取れた内容が標準。

## トリガーワード

- 「NDAを作成して」
- 「機密保持契約書を作って」
- 「秘密保持契約が必要」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 内容 |
|------|------|
| 開示者（甲） | 情報を開示する側の企業名 |
| 受領者（乙） | 情報を受け取る側の企業名 |
| 契約の目的 | システム開発・コンサルティング・業務委託 等 |
| 情報の流れ | 片方向（甲→乙）or 双方向 |
| 特に保護したい情報 | 顧客情報・技術情報・財務情報 等 |
| 損害賠償上限 | 省略→500万円（プロジェクト規模に応じて調整） |
| 秘密保持期間 | 省略→契約終了後5年間 |

---

## 標準的な契約構成（13条）

| 条項 | 内容 |
|------|------|
| 第1条 | 目的 |
| 第2条 | 機密情報の定義（書面・口頭・電磁的方法で開示された情報） |
| 第3条 | 機密保持義務（目的外使用禁止・第三者開示禁止） |
| 第4条 | 適用除外（公知情報・独自開発情報等） |
| 第5条 | **外部サービスの利用**（クラウドサービス利用規定・生成AI利用時の配慮） |
| 第6条 | 返還・破棄（契約終了時の処理） |
| 第7条 | 権利義務の譲渡禁止 |
| 第8条 | **契約期間**（有効期間3年・自動更新・秘密保持義務は終了後5年間） |
| 第9条 | **損害賠償**（上限500万円・故意重過失は除外） |
| 第10条 | 契約の変更 |
| 第11条 | 分離可能性 |
| 第12条 | 協議事項 |
| 第13条 | 管轄裁判所 |

## カスタマイズオプション

### 双方向NDA（相互開示型）

両当事者が相互に情報を開示する場合：
- 前文を「両当事者は相互に機密情報を開示し合う」に変更
- 甲・乙を対称的に記述

### 損害賠償の上限額調整

| プロジェクト規模 | 目安金額 |
|----------------|---------|
| 小規模 | 300万円 |
| 標準（デフォルト） | 500万円 |
| 大規模 | 1,000万円 |

### 秘密保持期間の調整

| 情報の性質 | 期間 |
|-----------|------|
| 技術情報（陳腐化が早い） | 3年間 |
| 標準（デフォルト） | 5年間 |
| 顧客情報等（重要性が高い） | 7年間 |

### 追加条項（オプション）

- 競業避止条項：競合事業への参入制限
- 監査条項：開示者による管理状況の監査権

---

## 現代的な条項（第5条）について

生成AI・クラウドサービスが普及した現代の業務環境に対応した条項を含む：

- Google Workspace等の企業向けクラウドサービスの利用を明示的に許可
- 生成AIを業務に利用する際の注意事項（機密情報をプロンプトに直接入力しない等）

---

## 技術仕様

- ライブラリ：docx.js（Node.js）
- フォント：MS Mincho（日本語契約書標準）
- 出力形式：.docx（A4・余白各25.4mm）

## 出力ファイル名

`機密保持契約書_{相手先企業名}_{日付}.docx`

---

本スキルが生成する契約書は標準的なひな形です。実際の締結前に必ず弁護士・司法書士等の専門家にご確認ください。Kaiは法務アドバイスを行う立場にありません。
