1. アプリ概要

テーマを入力するだけで、AIがマンダラチャートから順に深掘りビジュアルを自動生成します。テーマは複数作成・保存でき、履歴からいつでも続きを再開できます。

  • 生成済みコンテンツは state.json に保存され、次回起動時も維持されます

2. 初回セットアップ（Groq APIキー）

⚠️ APIキーをチャットやターミナルに直接貼り付けない キーは必ずWindowsのGUI（環境変数の編集画面）から登録してください。

STEP 1 — APIキーを取得する

  1. console.groq.com にアクセス（Google / GitHub / メールで登録）
  2. 左メニュー「API Keys」→「Create API key」
  3. 名前は任意 → 「Submit」
  4. gsk_ で始まるキーをコピー（この画面を閉じると二度と表示されない）
💡 Groq無料枠 1日14,400リクエスト、毎分6,000トークン。このアプリの通常利用では上限に達しません。

STEP 2 — Windowsの環境変数に登録する

  1. Windowsキー → 「環境変数」で検索 → 「システム環境変数の編集」を開く
  2. 「環境変数(N)...」ボタンをクリック
  3. 上段「ユーザー環境変数」の「新規(N)」をクリック
  4. 変数名：GROQ_API_KEY　値：コピーしたキーを貼り付け → OK → OK → OK
✅ 登録完了の確認 PowerShellを開いて [System.Environment]::GetEnvironmentVariable('GROQ_API_KEY','User') を実行し、gsk_ から始まる文字列が返れば正常です。

3. 起動方法

方法A：ダブルクリックで起動（通常利用）

▶️
起動してブラウザを開く.vbs（このマニュアルと同じフォルダ）
ダブルクリックするだけ。GROQ_API_KEYを自動読み込みし、サーバーを起動→ブラウザを自動オープンします。
▶ 起動する（クリックまたはダブルクリック）
💡 「Kai Visualize Server」のPowerShellウィンドウが開きます このウィンドウはサーバーログを表示しています。アプリを使っている間は閉じないでください。
終了するときは Ctrl+C で停止できます。

方法B：PowerShellから手動起動（確実）

以下を1行ずつ実行してください（複数行をまとめて貼り付けると警告が出ます）。

$env:GROQ_API_KEY = [System.Environment]::GetEnvironmentVariable('GROQ_API_KEY','User')
cd "C:\Users\kei\Dropbox\00_Antigravity\AS_AI導入支援事業_cc\08_アプリ開発事業部\outputs\kai-visualize"
py -3 server.py

起動後、ブラウザで http://localhost:3458 を開いてください。

4. 操作フロー

1
ホーム画面で「＋ 新規作成」をクリック
起動するとホーム画面が表示されます。テーマを入力（例：副業収入アップ、新規事業計画）して「マンダラを生成 →」をクリック。
2
「✨ マンダラを生成する」ボタンをクリック
AIが入力テーマから8サブテーマ×64タスクのマンダラを構築します（15〜25秒）。
3
マンダラ画面でセルをクリック → 4象限マトリクス生成
色のついたセルをクリックすると4象限マトリクスが生成されます（10〜20秒）。
4
4象限のアイテムをクリック → フロー図生成
どのアイテムでも「▶ フロー図を生成」からクリックして実行手順フロー図を生成できます。
5
「ガントチャートへ →」でガントチャート生成
スケジュール表＋タスク詳細（概要・注意点）が自動表示されます。
💡 続きはいつでも再開できます 生成済みコンテンツはセッションとして state.json に保存されます。ホーム画面の履歴から選択すれば、前回の続きをすぐに再開できます。
💡 複数テーマを並行して管理できます 「＋ 新規作成」で別テーマのセッションを作成できます。各セッションは独立しており、ホーム画面からいつでも切り替えられます。

6. セッションの管理（履歴・削除・リネーム）

セッションのリネーム

  1. ホーム画面の「📋 全履歴」ボタンをクリック
  2. 対象セッションのタイトル文字または ✏️ アイコンをクリック
  3. テキストボックスに新しい名前を入力 → 「保存」
💡 テーマとタイトルは別々 テーマはAI生成のプロンプト（変更不可）。タイトルは表示名（自由に変更可）。

メモの追加・編集

  1. 履歴一覧でメモ欄（「メモを追加...」と表示されている部分）をクリック
  2. テキストを入力 → 「保存」

セッションの削除

  1. 履歴一覧で対象セッションの「🗑 削除」ボタンをクリック
  2. 確認ダイアログで「OK」
⚠️ 削除は取り消せません そのセッションで生成したマンダラ・4象限・フロー図・ガントチャートのデータがすべて削除されます。

全データをリセットする場合

すべてのセッションを一括削除するには、サーバーを停止してから state.json を削除してください。

Remove-Item "C:\Users\kei\Dropbox\00_Antigravity\AS_AI導入支援事業_cc\08_アプリ開発事業部\outputs\kai-visualize\state.json"

7. APIキーの更新

  1. console.groq.com → API Keys → 新しいキーを発行
  2. Windowsキー → 「システム環境変数の編集」→「環境変数」→ ユーザー環境変数の GROQ_API_KEY を選択 → 「編集」→ 値を更新 → OK
  3. 方法B（PowerShell）でサーバーを再起動

8. トラブルシューティング

エラー原因対処
「手動生成モード（APIキーなし）」と起動時に表示 GROQ_API_KEYが環境変数から読み込まれていない 方法Bで起動（$env:GROQ_API_KEY = ...を最初に実行）。またはVBSで起動
生成エラー: HTTP Error 429 Groq APIのレート制限（分あたりリクエスト超過） 1〜2分待ってから1マスだけクリック。連続クリックしない
生成エラー: HTTP Error 403 APIキーが無効またはCloudflareブロック console.groqでキーの有効性を確認。新しいキーを取得して環境変数を更新
Syntax error in text (Mermaid) フロー図またはガントの構文エラー もう一度クリックして再生成を試す（LLMの出力が毎回異なります）
スピナーが止まらない APIエラー後にブラウザが更新されていない ブラウザページをリロード（F5）。サーバーを再起動してstate.jsonを削除
ブラウザが開かない（VBS起動後） サーバーの起動に2.5秒以上かかった 手動で http://localhost:3458 をブラウザで開く
