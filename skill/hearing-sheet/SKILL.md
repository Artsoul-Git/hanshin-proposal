# ヒアリングシート 自動生成スキル

AI導入・DX推進コンサルティングの初回商談に特化したヒアリングシートを業種・領域別に動的生成するスキル。「現状把握」と「AI活用余地の特定」を同時に行える設計。

## トリガーワード

- 「ヒアリングシートを作成して」
- 「商談準備シートを作って」
- 「現状把握シートを生成して」
- 「初回訪問前にヒアリング票を準備して」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 必須 | 内容 |
|------|------|------|
| 企業名 | ○ | 訪問先の会社名 |
| 業種カテゴリ | ○ | 12カテゴリから選択 |
| ヒアリング対象領域 | ○ | 4領域から複数選択 |
| 訪問予定日 | △ | 任意 |
| 主なテーマ | △ | AI活用・業務効率化・DX推進 等 |

### 業種カテゴリ（12種）

```
製造・加工 / 建設・工事 / 流通・物流 / 小売・EC
医療・福祉 / 金融・保険 / 不動産 / 飲食・観光
情報・通信 / 専門サービス / 農林水産 / 公共・組合
```

### ヒアリング対象領域（4領域）

```
管理部門（経理・人事・総務）
フロント部門（営業・マーケティング・顧客対応）
現場部門（生産・施工・物流・店舗）
IT・DX推進（システム・デジタル戦略）
```

## シート構成

| シート名 | 内容 | 生成条件 |
|---------|------|---------|
| 企業プロファイル | 基本情報・意思決定構造・DX姿勢 | 常時 |
| デジタル環境診断 | 現行ツール・データ管理・クラウド活用度 | 常時 |
| 【領域名】 | 領域別の業務フロー・課題・AI活用余地 | 選択領域ごと |
| 優先課題と投資意向 | 課題ランキング・ゴール・予算・決裁プロセス | 常時 |

例：管理部門とフロント部門を選択 → 5シート構成

## 各領域のヒアリング設計

### 管理部門（経理・人事・総務）

**組織・体制**
- 管理系スタッフ総数、専任・兼任の内訳
- 主な繁忙期・業務ピーク

**業務の現状（フロー確認）**
- 請求処理：紙中心 / Excel / 会計システム / 電子化済み
- 勤怠・給与：タイムカード / Excelシフト / クラウド勤怠 / 外部委託
- 入退社手続：紙・メール中心 / 部分的デジタル / 完全デジタル
- 月次報告：手集計 / Excel集計 / BI活用

**AI・自動化の余地（現状確認）**
- データの電子化率（帳票・台帳のデジタル化状況）
- 反復作業の割合（定型入力・突合・集計の工数比率）
- 現在の自動化・効率化への取り組み実績
- データ活用・レポーティングへの意欲

**課題の自由記述・エピソード**
- 最も時間を取られている業務とその理由
- 「これさえ解決すれば」という最優先課題

---

### フロント部門（営業・マーケ・顧客対応）

**組織・体制**
- 営業・顧客対応スタッフ数
- 顧客層（BtoB / BtoC / 両方）・平均顧客単価

**業務の現状**
- 顧客情報管理：名刺・手帳 / Excel / CRM導入済み
- 提案・見積：口頭・手書き / Excelテンプレ / システム連携
- 商談管理：個人管理 / 共有メモ / SFA活用
- 問い合わせ対応：電話中心 / メール / チャット / FAQ整備済み

**AI・自動化の余地**
- 顧客データの蓄積・活用状況
- 提案書・報告書の作成に費やす時間
- 問い合わせ対応の標準化・FAQ化の進捗
- マーケティング施策のデジタル化状況

**課題の自由記述・エピソード**
- 商談・受注のボトルネックとなっている作業
- 顧客データを「もっと活かせれば」と感じる場面

---

### 現場部門（生産・施工・物流・店舗）

**組織・体制**
- 現場スタッフ数・交代勤務の有無
- 現場拠点数・地理的分散状況

**業務の現状**
- 作業指示・伝達：口頭・紙 / 掲示板・ホワイトボード / デジタル掲示
- 実績・進捗入力：紙日報 / Excel / 専用システム
- 品質・安全管理：チェックシート（紙） / 写真記録 / デジタルシステム
- 在庫・資材管理：目視・手数え / Excel / 在庫管理システム

**AI・自動化の余地**
- 現場でのスマートフォン・タブレット活用状況
- 画像・映像データの保存・活用実績
- センサー・IoT機器の導入状況
- 熟練者に依存している業務・判断の範囲

**課題の自由記述・エピソード**
- 現場での「伝達ミス・確認作業」に費やす時間
- ベテランが退職した場合に失われそうなノウハウ

---

### IT・DX推進

**体制**
- IT担当者数（専任 / 兼任 / 外部委託のみ）
- DX推進の責任者・旗振り役の有無

**デジタル基盤の現状**
- 端末：デスクトップ中心 / ノートPC整備済み / モバイル対応
- サーバー：オンプレ / クラウド移行済み / ハイブリッド
- 社内ネットワーク：有線のみ / Wi-Fi整備済み / リモートアクセス可
- ID・アカウント管理：個別管理 / Active Directory / IDaaS導入

**AI・DX推進の現状**
- 過去の改善・DX施策とその結果（成功・頓挫した取り組み）
- 現在検討中または進行中のDXテーマ
- IT投資の意思決定フロー（担当者判断 / 部門長 / 経営会議）
- セキュリティポリシー・外部サービス導入の承認プロセス

**課題の自由記述**
- 「社内のITリテラシー」の現状認識
- AI導入に対する社内の期待と懸念

## 優先課題と投資意向シート（最終シート）

**課題の重み付け**
- 今最も解決したい業務課題（1〜3位）
- 放置した場合のリスク認識（人手不足・品質低下・競合差）

**理想の状態（1年後・3年後）**
- 1年後に実現したいこと（具体的に）
- 3年後のDX・AI活用の姿

**投資意向**
- 検討中の概算予算帯：〜100万 / 100〜300万 / 300〜500万 / 500万〜 / 未定
- 費用対効果で重視する指標（工数削減 / 売上向上 / リスク低減 / その他）

**意思決定プロセス**
- 最終決裁者と役職
- 検討・承認に要する標準的な期間
- 外部パートナー選定で重視する要素

**次のアクション（合意形成）**
- □ 詳細ヒアリング（部門別）
- □ 現場・システム見学
- □ 課題整理レポートの提示
- □ 概算見積・提案骨子の提示

## 自動記入機能（文字起こし → Excel）

ヒアリング音声の文字起こしを渡すと、各セルに自動記入する。

**記入の信頼度表示**

| 信頼度 | セル色 | 意味 |
|--------|--------|------|
| 確実 | 白 | 明確な発言に基づく |
| 推定 | 薄黄 | 文脈から推測（コメント付き） |
| 不確か | 薄橙 | 複数解釈あり（要確認） |
| 言及なし | 薄灰 | 発言が見当たらない |

**注意**：自動記入はあくまで下書き。黄・橙セルを中心に必ず人間がレビュー。

## Kaiビジュアル標準

- フォント：メイリオ統一
- 配色：ダーク系テキスト（#2C2C2C）＋グレートーン
- アクセント：#4A7E6B（緑系・入力セルのハイライトのみ）
- 入力欄背景：#F2F4F0
- グリッド線：非表示（区切りのみ細罫線）

## 出力ファイル名

`ヒアリングシート_{企業名}_{日付}.xlsx`
