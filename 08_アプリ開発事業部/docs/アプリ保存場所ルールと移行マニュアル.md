# アプリ保存場所ルールと移行マニュアル

作成：2026-05-12  
対象：Kai（AI）および上村桂右

---

## 1. ルール：どこに何を置くか

### 基本原則

| 種別 | 保存先 | 例 |
|------|--------|----|
| 新規アプリ・ツール | `08_アプリ開発事業部/outputs/<アプリ名>/` | `outputs/音源トリミング/` |
| 内製ツール（Kai自身が使うもの） | `08_アプリ開発事業部/outputs/<ツール名>/` | `outputs/slide-builder/` |
| 受託成果物（クライアント向け） | `08_アプリ開発事業部/outputs/<案件名>/` | `outputs/maru-ai-kiroku/` |

### 禁止事項

- **Cドライブへのファイル作成・編集・削除は行わない**（上村が明示的に許可した場合を除く）
- 上村がCドライブのパスを指定してきた場合も、Kaiは先に確認する

> **Kaiの確認文例：**
> 「Dドライブの `08_アプリ開発事業部/outputs/` 配下ではなく、そのパスで進めてよいですか？」

## 3. 完成後の移動手順（Kaiへの指示方法）

### Step 1：上村が「完成した、移動して」と伝える

```
「音源トリミングアプリが完成したので、正規の場所に移動して」
```

これだけで OK。以下はKaiが自律実行する。

### Step 2：Kaiが実行すること（自律）

```
1. 移動先ディレクトリを作成
   D:\Google Antigravity\AS_AI導入支援事業_cc\08_アプリ開発事業部\outputs\<アプリ名>\

2. Cドライブ（または仮置き場）のファイルをDドライブへコピー

3. コピーが正常に完了したことを確認

4. 上村に確認を取ってからCドライブの元ファイルを削除
   ※削除は必ずオーナー確認後（CONSTITUTION.md §3 の原則）

5. このマニュアルの「現在ルール外に存在するアプリ一覧」を更新
```

### Step 3：削除確認の文例（Kaiから上村へ）

```
「`C:\Users\kei\Downloads\音源トリミング\` のファイルを
`08_アプリ開発事業部/outputs/音源トリミング/` にコピーしました。
元のCドライブのファイルを削除してよいですか？」
```

## 4. 新規アプリを作る際のKaiの行動ルール

### ユーザーが保存パスを指定しなかった場合
→ Kaiは自動的に `08_アプリ開発事業部/outputs/<アプリ名>/` に保存する

### ユーザーがCドライブまたは別パスを指定した場合
→ 即座に確認する（作業開始前）

```
「今回のアプリは `08_アプリ開発事業部/outputs/<アプリ名>/` への保存が
デフォルトルールですが、指定されたパス（<指定パス>）で進めますか？」
```

### ユーザーが「Dドライブに置いて」と言った場合
→ 確認不要で `08_アプリ開発事業部/outputs/<アプリ名>/` に保存する

## 5. フォルダ構造の参考

```
08_アプリ開発事業部/
├── outputs/                    ← 完成・公開済みアプリの置き場（内製ツールも含む）
│   ├── kai-tasks/              （内製：Kaiタスク管理アプリ）
│   ├── slide-builder/          （内製：セミナースライド生成ツール）
│   │   ├── templates/          ← テンプレート（kawai-dark-v1 等）
│   │   ├── projects/           ← 作業中ステージング（完成後は06_セミナー事業部に移動）
│   │   ├── new-seminar.py      ← プロジェクト生成 CLI
│   │   └── index.html          ← ブラウザ管理画面
│   ├── maru-ai-kiroku/         （受託案件：まる様AI記録システム）
│   └── 音源トリミング/          （公開済み：音源トリミングツール）
├── agents/                     ← AI社員定義ファイル
└── docs/                       ← このファイルなどの設計文書

06_セミナー事業部/
└── outputs/                    ← セミナー成果物（完成・GitHub Pages 公開済み）
    ├── 契約書AIチェックセミナー/
    ├── morai-prompt/           （もらったプロンプトを使い倒そう！）
    └── m2/                     （同セミナー 画像版）
```
