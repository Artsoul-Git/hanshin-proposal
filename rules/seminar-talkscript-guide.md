## 1. 文体・トーン（トンマナ）

| 項目 | 設定 |
|------|------|
| フォーマリティ | カジュアル丁寧（礼儀正しいが肩の力は抜けている） |
| エネルギー | 標準ベース、要所でグッと上げる |
| 親密度 | フレンドリーだが芯はぶらさない |
| 誠実さ | 断定は根拠に限定、わからない時は正直に |
| ユーモア | 控えめ〜要所で効かせる（小さな"くすり"程度） |
| ロジック偏重度 | 共感→論理→行動 のバランス |
| 一人称 | 私 |
| 聴衆呼称 | 皆さま |
| 文末 | です・ます |
| 語彙レベル | 専門用語あり（初出で短い注釈） |

## 2. スライドの役割分類と話時間の目安

| 役割タイプ | 例 | 目安秒数 |
|-----------|-----|---------|
| 表紙・つかみ | slide-cover, slide-impact | 30〜45秒 |
| 共感・課題提示（Before） | 問題スライド、現状確認 | 45秒〜1分 |
| 理想・解決提示（After） | ゴール、理想像 | 30〜45秒 |
| 流れ説明 | 本日のアジェンダ | 20〜30秒 |
| セクション扉 | slide-section | 15〜25秒 |
| 解説・内容 | 通常スライド | 45秒〜1分30秒 |
| 数字・インパクト | slide-metric | 30〜45秒 |
| ワーク説明 | 手順、テンプレ紹介 | 1分〜2分 |
| ROI試算 | 時間削減・金額換算 | 1分〜1分30秒 |
| 今動く理由・特典 | 期限、フォロー案内 | 45秒〜1分 |
| CTA・まとめ | 今すぐできること | 1分〜2分 |

## 3. 1スライドのトーク構造（3要素）

すべてのスライドは以下の3要素で設計する。

```
① フック（5〜10秒）
   共感 / 問いかけ / "あるある" / 軽い驚き

② 本題（スライド内容の言語化）
   スライド情報を話し言葉で展開。根拠はスライド内に限定。

③ 接続（5〜10秒）
   次スライドへの橋渡し、または行動喚起の一言
```

---

## 3-A. 解説スライドの「中身」設計（主張＋4要素）

解説スライド（通常スライド・ノウハウ説明）は、トーク構造の「本題」部分を以下で組み立てる。

**スライド1枚 = 主張1つ**（複数の主張を1枚に詰めない）

```
【主張（まず言う）】
  尖っていて中立でない1文。「〜です」で断言する。
  例：「AIツールを選ぶ前に、業務フローを見直さないと逆効果です」

【説明（4要素から選ぶ）】
  ① Why（なぜ）  : 講師がその主張に至った理由＋受け入れるメリット
  ② What（根拠） : データ・事例・メカニズム・引用
  ③ How（方法）  : ステップ形式でやり方を提示（手順説明スライドのみ）
  ④ 事例/たとえ話: 業種別の実例・メタファー・よくある失敗パターン

【主張の再提示（最後に言う）】
  「つまり〇〇です」で締める（結論サンドイッチ構造）
```

**4要素の使い分け：**
- Why・事例はどのスライドでも入れられる（優先度高）
- Howはノウハウ・手順スライドのみ
- Whatはデータや引用がある場合のみ（無理に入れない）

**ファン化要素（可能な限り入れる）：**
講師自身のエピソード・価値観・失敗談を「本題」の中に組み込む。
感情が動く具体的な場面描写 → 主張との接続 → 共感・ファン化が起きる。

## 4. 特殊スライドの専用ルール

### 4-1. 冒頭30秒（cover / impact）

「身近な観察 → 一歩深い気づき → 安心の一言」の3ステップで引き込む。

```
例：
「皆さま、最近AIのニュースを見て…正直ちょっと疲れていませんか？（観察）
情報が多すぎて、どこから手をつければいいか分からない、という声をよく聞きます。（気づき）
今日は余計な話は一切なしで、今日からすぐ使えるものだけ持ち帰っていただきます。（安心）」
```

### 4-2. Before スライド（課題・共感）

デュアルターゲットで書く：

- **現場担当者向け**：「あるある」の具体場面で共感を取る
- **経営者向け**：時間・コスト・機会損失の数字で問題を可視化する

```
例：
「毎日こんな場面ありませんか。お客さんへのメール、チラシの文章、報告書…
一つひとつ1時間かけて書いている。月に換算すると何時間になるでしょう。
これ、実は今日から変えられるんです。」
```

### 4-3. After スライド（理想・ゴール）

Before と同じ切り口でAfterを語る。数字で対比する。

```
例：
「同じ作業が5分で終わる。月に20時間が戻ってくる。
その時間で何をするかは、皆さまが決めることです。」
```

### 4-4. ワーク説明スライド

手順は「やること → なぜやるか → 何ができるか」の順で説明する。

```
例：
「今から3分で、実際にやってみましょう。
画面の通りにコピペするだけです。
終わったら、そのまま明日使えるものができています。」
```

### 4-5. ROI試算スライド

「1人あたりの時間削減 → チーム全体 → 年間金額換算」の順で積み上げる。

経営者の心に刺さる順番：**時間 → 人数 → 金額**

```
例：
「仮に1日15分短縮できたとして、10人のチームなら月に50時間。
時給換算で月50万円分の生産性が生まれる計算です。」
```

### 4-6. 今動く理由（期限・特典）スライド

「今日が特別な日」という空気を作る。3点セットで締める：

1. 期限（「今月中に相談すると〜」）
2. 特典（「今日の参加者限定で〜」）
3. ハードルを下げる（「まず一つだけ試してみてください」）

### 4-7. CTA スライド

行動を1つに絞る。複数提示しない。

```
良い例：「今日帰ったら、まずこれを試してください」
悪い例：「①〜③を実践しましょう。また勉強会も参加してください。相談も受け付けています。」
```

## 5. レトリック（必須テクニック）

### リピート法
重要キーワードは言い換えを含め最大3回繰り返す。

```
例：「コピペするだけです。Ctrl+C、Ctrl+V。それだけです。」
```

### ギャップ理論（Before → After）
現実と理想のギャップを数字か場面で対比させる。

### 拡張話法（聴衆の視点を拾う）
感嘆 → 反復 → 共感 → 賞賛 → 質問 の流れで展開。

```
例：
「すごいですよね（感嘆）。
本当に、これだけで（反復）。
皆さまも同じ経験があるかもしれません（共感）。
実はこれ、使いこなしている方は密かにやっているんです（賞賛）。
皆さまはどうでしょう？（質問）」
```

### 問いかけ
自分ごと化を促す短い問いを差し込む。答えを求めない「レトリカルクエスチョン」でよい。

```
例：「もし1時間が5分になったら、その55分で何をしますか？」
```

### サプライズワード
意外性のある小話・比喩を1スライドに1つ入れる（要所のみ）。

## 6. デリバリー記号（data-notes内で使う）

| 記号 | 意味 |
|------|------|
| `（少し間）` | 一拍置く（強調の前後） |
| `（柔らかく）` | トーンを落とす |
| `（フック強め）` | エネルギーを上げる |
| `（落ち着いて要点）` | 情報量が多い箇所 |
| `（締めは前向きに）` | まとめ・CTAの直前 |

## 7. 禁則事項

- **陳腐なAI表現禁止**：「AIの時代が来ました」「革新的な」「パラダイムシフト」「ゲームチェンジャー」
- **テンプレ比喩禁止**：「羅針盤」「エンジン」「地図」などの使い古された比喩
- **過剰な決めつけ禁止**：「必ず〜できます」「絶対に変わります」
- **冗長・単調禁止**：同じ文型の繰り返し、体言止めの多用
- **固有名詞の無断使用禁止**：スライドに根拠がない企業名・人名・数値を入れない
- **複数CTAの禁止**：最後に行動を求めるのは1つだけ

---

## 8. エビデンス・安全ガード

- 事実はスライドの範囲内のみで断定する
- スライドにない外部情報はユーザー許可時のみ、出典付きで最小限に
- 数値・固有名詞・期間・単位はスライド通りに読む
- 曖昧な箇所は「図をご参照ください」「〜とされています」で中和する
- 比較・優位性の表現は根拠のある箇所のみ

---

## 9. 全体の目的導線

```
理解（わかった）→ 納得（そうだな）→ 行動（やってみよう）
```

CTAは最後の1つだけに集約する。途中での行動喚起はあくまで「予告」として扱う。
