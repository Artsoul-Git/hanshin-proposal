# ACTモデル：契約・ヒアリングツール一式

## 1. 契約書テンプレート（骨子）
※実際の運用には弁護士等の確認を推奨します。

- **第1条（業務内容）**: AI導入支援、ライモBiz運用支援、AIマネージャー育成。
- **第2条（期間）**: 3ヶ月ごとの更新。評価に基づきPhaseを移行。Phase 3（顧問）は1年契約。
- **第3条（報酬）**: 
  - Phase 1: 月額30万円（税別）
  - Phase 2: 月額15万円（税別）
  - Phase 3: 月額5万円（税別）
- **第4条（訪問・面談）**: Phase 1は月1回訪問、週1回Web面談。Phase 2以降はオンラインのみ。
- **第5条（知的財産）**: クライアントが開発したアプリ、プロンプト、マニュアル等はクライアントに帰属。弊社は事例公開の許可を得る（匿名化条件）。

## 2. 経営者向けヒアリングシート
1.  **経営課題**: 現在、最も頭を悩ませているコスト、または機会損失は何ですか？
2.  **採用・定着**: 人手不足を感じている部署、または離職率が高い部署はどこですか？
3.  **目標数値**: 3ヶ月後、どの程度（時間またはコスト）の削減ができれば「成功」と言えますか？
4.  **キーマン**: 現場で最もITに強く、周囲から信頼されている「AIマネージャー候補」は誰ですか？

## 3. 現場（AIマネージャー・スタッフ）向けヒアリングシート
1.  **ルーチンワーク**: 毎日、または毎週繰り返している「面倒な作業」を書き出してください。
2.  **ドキュメント作成**: 報告書、見積書、マニュアル作成にどれくらいの時間をかけていますか？
3.  **属人化**: 「◯◯さんしか知らない・できない」という業務はありますか？
4.  **AIへの期待と不安**: AIで楽をしたいと思う点はどこですか？ 逆に不安なことはありますか？

## 4. 現場観察チェックリスト（訪問時）
- デスクの上に紙の資料が山積みになっていないか。
- 電話対応で手が止まる回数はどれくらいか。
- 社員間のコミュニケーション手段は（対面、電話、メール、チャット）？
- PCの画面に付箋（パスワードや手順）が貼られていないか。
