# 技術スタックガイド

> ARCHが技術選定するときの判断基準。「最小コスト × 最大継続性」原則。

---

## 選定フローチャート

```
Q1: クライアントは追加コストをかけられるか？
  → NO（ライモBiz+GWSのみ）→ [GAS系スタック] or [HTML系スタック]
  → YES → Q2へ

Q2: モバイルで使う必要があるか？
  → YES → [LINE bot] or [AppSheet]
  → NO → Q3へ

Q3: 外部サービス（LINE/Notion等）との連携が必要か？
  → YES → [GAS + HOOKUP]
  → NO → [GAS系] or [HTML系]
```

---

## スタック別仕様

### GAS系スタック
| 構成要素 | ツール | 用途 |
| --- | --- | --- |
| バックエンド | Google Apps Script | 処理・自動化・API連携 |
| データ | Google Sheets | レコード保存・マスター管理 |
| UI（管理者） | GAS Web App (doGet) | 管理画面・フォーム |
| UI（現場） | AppSheet / ライモBiz | モバイルUI |
| AI処理 | Gemini API (gemini-2.0-flash) | 文書生成・分析 |

**向いている案件**：記録自動化、予約管理、申請・承認フロー、月次集計自動化

**制約**：
- GASは1実行6分タイムアウト（長時間処理は分割必須）
- AppSheet Core は GWS Business Standard に付属（追加コスト不要）
- Gemini API 無料枠：15 RPM / 1,500 RPD

---

### HTML系スタック
| 構成要素 | ツール |
| --- | --- |
| 構造 | HTML5 |
| スタイル | CSS3（インライン） |
| インタラクション | Vanilla JavaScript |
| チャート | Chart.js（CDN、必要な場合のみ） |

**向いている案件**：提案書、セミナー資料、インタラクティブレポート、社内ダッシュボード

**AS社標準仕様**：
- `html { zoom: 1.4; }` で140%スケール
- 単一HTMLファイル原則（依存ファイルを増やさない）
- カラーパレット：Primary #2B6CB0 / Accent #C05621

---

### 外部連携スタック
| 連携先 | 実装方法 | 認証 |
| --- | --- | --- |
| LINE Messaging API | GAS doPost() | Channel Access Token |
| Gemini API | UrlFetchApp.fetch() | API Key |
| Gemini File API | マルチパートUP → 生成 | API Key |
| Notion API | UrlFetchApp.fetch() | Integration Token |
| Slack | Incoming Webhook URL | Webhook URL |

**共通原則**：
- 認証情報はすべてスクリプトプロパティに保存
- 個人情報はマスキング後にAI APIへ送信
- 署名検証（LINE）・エラーハンドリング必須
