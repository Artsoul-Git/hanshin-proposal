# パターン#3：価値アンカリング・3日連続ローンチ型

> N日連続（3日典型）オンラインウェビナーで、**高単価商品（30-100万円級）への体験会ファネルを設計するための型**。
> 抽出元：2026-05-26取り込みの3日連続ウェビナー素材（合計297分・音声3本／詳細は内部メタ層参照）
> 著作権配慮：元動画の登壇者名・主催名・固有事例・具体的セミナー名は記録せず、構造・設計DNAのみ抽出

---

## このパターンが効くケース

| 条件 | 該当例 |
|---|---|
| **高単価商品の最終販売** | コンサル50-100万円、コーチング、講座、認定制度 |
| **複数日で関係性を作る必要** | 1回完結では信頼構築不足な高額帯 |
| **Zoomウェビナー＋カメラオン参加** | 受講者の集中度・能動性を高めたい |
| **背後にバックエンド商品** | 体験会→個別相談→高単価商品 のファネルを設計済 |
| **登壇者に実績数字がある** | 「〇〇名」「〇〇円達成」など信頼性に使える数字 |

**逆に向かないケース：** 単発で完結したい／実績数字が乏しい／オファーを軽くしたい教育主体型

## 動画構造（3日連続・合計4-5時間モデル）

```
[Day 1 / 90-120分]
  運営事項(2分) → 自己ブランディング・実績連射(3-5分) → 価値アンカリング(3分)
  → 早期ギフト(2分) → 問題提起(20分) → 思想解説(40分)
  → 実演・対話(20分) → 宿題提示＋次回予告(5分)

       ↓ （48-72時間の間）

[Day 2 / 90-120分]
  運営事項(2分) → Day1学びシェア(10-15分) → コアコンセプト提示(10分)
  → 型・フレーム解説(25分) → 思想転換(15分) → 実演・対話(25分)
  → 宿題提示＋次回予告(5分)

       ↓ （48-72時間の間）

[Day 3 / 90-120分]
  運営事項(2分・簡略化) → Day1-2学びシェア(10-15分) → 比較解説(10分)
  → 未来像・数字固定(25分) → バックエンド設計解説(25分)
  → 受講生ワーク・添削(10分) → 体験会CTA(7分)
```

**配分の鉄則（合計297分基準）：**

| パート | 比率 | 鉄則 |
|---|---|---|
| 運営事項＋自己ブランディング | 4-5% | 短く。実績数字は連射 |
| **価値アンカリング** | 1% | 1回明確に。「参加費〇〇万円と思って」 |
| Day連続性装置（学びシェア） | 8-10% | Day2-3冒頭に必ず置く |
| 問題提起＋思想解説 | 18-22% | Day1中心 |
| コアコンセプト＋型・テクニック | 18-22% | Day2中心 |
| 実演・対話・受講生ワーク | 18-22% | 全Day分散 |
| 未来像＋バックエンド設計解説 | 13-17% | Day3前半-中盤 |
| 宿題＋次回予告 | 3-4% | Day1-2末尾 |
| **メインCTA（体験会誘導）** | 2-3% | Day3末尾のみ |

## Day連続性装置（このパターンの核）

3日を「ひとつのセミナー」にまとめる設計：

| 装置 | 配置 | 効果 |
|---|---|---|
| **前日学びシェア** | Day2-3冒頭に10-15分 | 連続参加促進＋復習効果＋他者刺激 |
| **次回への引き** | Day1-2末尾に5分 | 「あさってお会いしましょう」「課題を出そう」 |
| **コアキラーフレーズ反復** | 全Day | 主題の刷り込み |
| **同じ運営ルール** | 全Day冒頭 | カメラオン推奨、録音許可など |
| **Day3で全体を統合する未来像** | Day3前半 | 「ここまでの学びで月〇〇万円可能」 |

---

## 価値アンカリングの鉄則

Day1冒頭5-10分以内に必ず：

```
「これは参加費 〇〇万円相当のセミナーだと思って参加してください」
「〇〇万円以上の価値があります」
```

これにより視聴者は **「真剣に聞かないと損する」** 心理状態になり：
- ノートを取る／集中する／離脱しない
- 学んだ内容を高く評価する
- 後続のCTA（体験会）への抵抗感が下がる

**注意：** 価値アンカリングは登壇者の実績数字（信頼性）と必ずセットで運用する。実績が薄いと「盛りすぎ」と見られて逆効果。

## このパターンのツボ（再現のコツ）

- **価値アンカリングは「明確な金額」で。** 「価値ある」では弱い、「〇〇万円相当」と数字を出す
- **Day連続性装置を必ず仕込む。** Day1-2末尾の引きとDay2-3冒頭シェアで離脱を防ぐ
- **コアキラーフレーズを3日で30回以上反復。** 主題が脳に焼き付く
- **未来像は具体的な数字で。** 「月3000万円」「5人で」と量化する
- **体験会は低リスクCTAに徹する。** 無料・選抜・フィードバック付きで心理ハードルを下げる
- **登壇者の実績数字を冒頭で連射。** 価値アンカリングの信頼性を担保

---

## このパターンの落とし穴

- **価値アンカリングの金額が登壇者の実績と乖離すると逆効果** → 信頼性とセットで運用
- **Day間の宿題が重すぎると離脱増** → 5-10分でできるレベルに
- **Day3で複数の商品を見せるとファネル迷子** → バックエンドは1本に絞る
- **体験会CTAでセールス感を出すと教育主体性が崩れる** → 「フィードバックの場」と位置付ける
- **未来像の数字を盛りすぎると誇大広告と見られる** → 自身の実績or受講生実績に基づく数字を使う

---

## 著作権・倫理ガイド

このパターンは **構造・配分・話術設計** のみ抽出している。元動画の登壇者・固有商品名・具体的金額・固有事例は記録していない。
適用時は **新規テーマ／新規ターゲット／オリジナル数字** で構成すること。価値アンカリング額・未来像数字は **登壇者自身が裏付けられる範囲** で設定すること。
