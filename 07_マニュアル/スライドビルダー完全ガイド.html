1このシステムでできること

セミナーテーマを Kai に投げると、受講者に共有できる Web スライドシステムが丸ごと出来上がります。PDF や PowerPoint の代わりに、ブラウザで動くリアルタイムのスライドを GitHub Pages で公開します。

何が作られるか

受講者向けURL

エクスポート・編集機能なし。閲覧専用。URLを知っている全員が見られる。

プレゼンター画面

現在スライド＋次スライド＋トークスクリプト＋タイマー。パスワード保護。レーザーポインタ・全画面連動。

管理画面

共有URLの確認・コピー、パスワード設定。

フル操作画面

スライド編集・PDF出力・PPTX出力。発表者自身の手元用。

4-2. Step 2: PDF/PPTX からテキストを抽出する（任意）

既存の資料がある場合、ここにドロップするとテキストが抽出されます。Kaiへの依頼プロンプトに自動で添付されます。

PPTX の場合

各スライドのテキストを「--- スライド N ---」区切りで抽出。JSZip を使ってブラウザ内で処理。

PDF の場合

各ページのテキストを「--- ページ N ---」区切りで抽出。PDF.js を使用。

抽出テキストの活用 既存の PowerPoint の内容をもとにスライドを作りたいとき、テキストを抽出して Kai に渡すと、そのコンテンツを再構成したスライドを作ってくれます。デザインや構成はゼロから kawai-dark-v1 スタイルで作り直されます。

4-3. Step 3: Kaiへの依頼プロンプトを生成する

「プロンプト生成」ボタンを押すと、入力内容が自動的に Kai への依頼文に変換されます。「コピー」ボタンで Claude Code に貼り付けるだけです。

4-4. Step 4 & 5: コマンドを確認してデプロイ

アプリが自動生成するコマンドをコピーして、PowerShell で順番に実行するだけです。

コマンドは自動計算される 入力したスラッグ・タイトルから、new-seminar.py コマンドと git デプロイコマンドが自動生成されます。コピーして貼り付けるだけでOK。

6-2. ブラッシュアップ方法

1 CSS変数を変えるだけでカラースキームが変わる
templates\kawai-dark-v1\css\style.css の :root セクションの変数値を変更。
2 template-spec.md のバージョン履歴を更新
変更内容と日付を記録する（例: v1.1 2026-06-01 フォントサイズ調整）。
3 既存プロジェクトには影響しない
各プロジェクトはテンプレートの独立コピーを持つので、テンプレートを変えても過去のスライドは変わらない。次回 new-seminar.py を実行したときから新デザインが使われる。

6-3. 新テンプレートを追加する

# 例: light-blue-v1 という新テンプレートを作る 1. templates\kawai-dark-v1\ をまるごとコピー → templates\light-blue-v1\ 2. css\style.css の CSS変数を新しいカラーに変更 3. template-spec.md を更新（名前・バージョン・カラー表） 4. 次回 new-seminar.py --template light-blue-v1 で指定できる

9パスワードのしくみ

パスワードはブラウザの localStorage に保存される。ソースコードには一切書かれていない。だから GitHub に公開してもパスワードは漏れない。

仕組みを3行で

  1. admin.html でパスワードを設定 → そのPCのブラウザの localStorage に保存
  2. presenter.html を開く → localStorage からパスワードを取り出して照合
  3. 別のPCでは → そのPCにパスワードが保存されていないので入れない。再度 admin.html で設定が必要。

パスワードを変えたいとき

admin.html を開いて新しいパスワードを入力 → 「設定・変更」。次に presenter.html を開いたときから新パスワードが有効。

別デバイスで presenter.html を使いたいとき

そのデバイスのブラウザで admin.html を開いてパスワードを設定する。何度でも同じパスワードを設定してOK。

ブラウザのキャッシュをクリアすると localStorage もクリアされる。presenter.html が開けなくなったら admin.html で再設定する。初期パスワードは projects\{スラッグ}\manual.html に記載。

10ファイル・フォルダ名ルール

GitHub Pages では日本語ファイル名が使えない URLエンコードされて汚くなり、リンクが壊れることがある。英数字・ハイフンのみで命名すること。
対象ルールOK例NG例
GitHubスラッグ（リポジトリ名）英数字 + ハイフン、小文字、先頭は英字sales-ai-seminar採用AI研修
プロジェクトフォルダ名スラッグと同じprojects/sales-ai-seminar/projects/採用AI/
JS/CSS ファイル名英数字 + ハイフン + ドットslides.jsスライド.js
テンプレート名英数字 + ハイフン + バージョンkawai-dark-v1ダークv1

スラッグ命名のコツ

  • テーマ＋対象＋seminar の組み合わせが分かりやすい
  • 例：keiyaku-ai-check / sales-ai-seminar / hr-ai-intro
  • 同じ名前のリポジトリは作れない。年や枝番をつける：keiyaku-ai-2026

11トラブルシューティング

Qpresenter.html が開けない（パスワードが効かない）▼

原因：このブラウザの localStorage にパスワードが保存されていない。

対処：admin.html を開いて「プレゼンターパスワード」欄に初期パスワードを入力して「設定・変更」。初期パスワードは projects\{スラッグ}\manual.html を参照。

QGitHub Pages の URL を開くと 404 になる▼

原因①：GitHub Pages がまだビルド中（push後1〜2分かかる）。

対処①：2分待ってから再度アクセス。

原因②：gh-pages ブランチが存在しない。

対処②：以下を実行：

git checkout -b gh-pages git push origin gh-pages git checkout master
Qレーザーポインタが受講者画面に表示されない▼

原因：presenter.html と viewer.html（または index.html）が別ブラウザタブ・別ウィンドウで開かれていない。BroadcastChannel は同一ブラウザ内のタブ間でのみ動作します。

対処：受講者画面（viewer.html）を同じPCの同じブラウザで別タブ・別ウィンドウで開く。別のPCで開いている場合は動作しません（同じデバイスのみ有効）。

Qスライドを更新したのに URL を開くと古いまま▼

原因①：gh-pages ブランチに反映していない。

対処①：以下を実行：

git checkout gh-pages git merge master git push origin gh-pages git checkout master

原因②：ブラウザのキャッシュ。

対処②：Ctrl+Shift+R（強制リロード）。

Qslides.js で文字が表示されない・レイアウトが崩れる▼

原因：slides.js の JavaScript 構文エラー。特に data-notes 内のシングルクォート（'）のエスケープ漏れ。

対処：ブラウザの開発者ツール（F12）→ Console タブでエラーを確認。data-notes 内のシングルクォートを ' に置換する。

// NG: シングルクォートがエスケープされていない data-notes="今日はAIについて学んでいただけます。" // OK: 文字参照でエスケープ data-notes="今日はAI's活用法を学んでいただけます。"

12slides.js の書き方リファレンス

基本構造

(function () { function H(title) { return '<header class="slide-header"><h2 class="slide-h2">' + title + '</h2></header>'; } function slide01() { return '<section class="slide slide-cover" data-section="cover" data-title="タイトル" data-notes="トークスクリプト。'シングルクォート'は'&#39;でエスケープ"> <!-- スライドコンテンツ --> </section>'; } /* ... 他のスライド関数 ... */ window.SLIDES = [slide01, slide02, ...]; })();

必須ルール（Kai も守る、手書きも守る）

  1. 全体を IIFE（即時実行関数）で包む
  2. H() ヘルパーを冒頭で定義
  3. 各スライドは slideNN() 関数（ゼロ埋め2桁）
  4. 全スライドに data-section / data-title / data-notes を設定
  5. data-notes 内の ' は &#39; でエスケープ
  6. 時間表記（60分・20分）をスライド本文に書かない
  7. 最後に window.SLIDES = [slide01, slide02, ...]; で配列を登録
