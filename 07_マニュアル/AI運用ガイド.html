AIエージェント「Kai」安全・快適運用ガイド

このガイドでは、AIエージェント「Kai（Antigravity）」を、より速く、より安全に、そしてストレスなく使い続けるための設定とコツを解説します。

1. PC環境の引越し手順（Dドライブ → Dropbox）

外付けSSD（Dドライブ）での作業は、通信の遅れや暗号化の負担で動作が重くなりがちです。CドライブにあるDropboxフォルダへ移動させることで、爆速かつ自動バックアップ付きの環境になります。

1 Kaiを完全に終了する
動いているターミナル（黒い画面）をすべて閉じます。

2 Dropbox内に専用フォルダを作る
C:\Users\kei\Dropbox\Dev\Antigravity のように、分かりやすい場所にフォルダを作成します。

3 フォルダを「コピー」する
Dドライブの AS_AI導入支援事業_cc フォルダを、今作ったDropbox内の場所へコピーします。
コツ「切り取り」ではなく「コピー」を使うと、万が一失敗しても元のデータが残るので安全です。

4 動作を確認する
コピー先のフォルダでKaiを起動し、いつものように動くか確認します。

5 Kaiに「住所の書き換え」を頼む
引越しで住所が変わったので、Kaiに以下のようにお願いしてください。
「フォルダの引越しをしたので、全てのファイルの中にある C:\Users\kei\Dropbox\00_Antigravity\AS_AI導入支援事業_cc という文字を、新しい場所のパス（ C:\Users\kei\Dropbox\Dev\Antigravity\AS_AI導入支援事業_cc ）に一括で書き換えて」
これで全てのリンクが元通りになります。

2. Git（ギット）を「防波堤」にする手順

「Git（ギット）」とは、一言で言うと**「ファイルのタイムマシン」**です。AIに大きな修正を頼む前に、今の状態を「セーブ（保存）」しておくことで、もし失敗しても1秒で元の状態に巻き戻すことができます。

ステップ0：Gitが入っているか確認する

黒い画面（ターミナル）で git --version と打ってみてください。数字が表示されれば準備完了です。
エラーが出る場合は、以下の手順でインストールしましょう。

インストール方法（Windowsの場合） 1. Git for Windows の公式サイトからダウンロードします。
2. インストーラーを起動し、基本的に全て「Next（次へ）」を押して進めればOKです。
3. インストール後、PCを一度再起動してください。

ステップ1：最初の1回だけ必要な設定（名前の登録）

Gitを使うには「誰が保存したか」を登録する必要があります。以下の2行をターミナルで1回ずつ入力してください。（名前とメールは自分のものでOKです）

git config --global user.name "Your Name"
git config --global user.email "your@example.com"

ステップ2：実際に「防波堤」を作る（作業前）

Kaiに「〇〇をやって」と頼む直前に、以下の2つを打つのがプロのコツです。

1 git add .
（「全ての変更を保存する準備をして」という意味）

2 git commit -m "作業前バックアップ"
（「今の状態に名前をつけて保存して」という意味）

【緊急事態！】Kaiが失敗して、ファイルが壊れたら？ 落ち着いて git restore . と打ってください。一瞬で、さっき保存した「作業前」の状態に完全に元通りになります。

3. 日々の運用の注意点とアドバイス

① Dropboxの「同期完了」を待つ

ファイルを保存した後、Dropboxのアイコンが「青いぐるぐる」から「緑のチェック」になるのを待ってからPCを閉じたり移動したりしましょう。これだけで、データの食い違いを防げます。

② 大量ファイルの時は少し休憩

一度に100個以上のファイルを一気に作った時は、Dropboxの同期に数分かかることがあります。その間は少し休憩して、同期が終わってから次の指示を出すとスムーズです。

③ Kaiに「迷ったら聞いて」と伝える

Kaiは非常に優秀ですが、時々勝手に想像して進めてしまうことがあります。指示の最後に**「やり方がいくつかある場合は、勝手に進めずに一旦相談して」**と添えると、より確実な仕事をしてくれます。

④ パスワード管理

DropboxやGitHubなど、大事なツールのパスワードは使い回さず、安全な場所に保管しておきましょう。PC環境をCドライブに集約することで、セキュリティ対策も一箇所で済むようになります。
