# /finance スキル

**用途:** 財務モデリング・損益シミュレーション・DCF分析・価格戦略・シナリオ分析・リスク定量化を行い、「数字に裏付けられた意思決定」を支援する

> このスキルはユーザーが提供する前提数値をもとに計算・シミュレーションを行う。
> 実在する企業の非公開財務データは取得できない。ユーザー自身の事業数値が必要。

---

## 発動条件

ユーザーが `/finance` を入力したとき、または以下の依頼があったとき：

- 「損益シミュレーションして」「PL作って」「売上予測を立てたい」
- 「DCFで企業価値を計算して」「NPVを出して」
- 「損益分岐点を計算して」「いくら売ればいいか」
- 「価格設定を見直したい」「値付けの戦略を考えて」
- 「楽観・悲観シナリオで試算して」「リスクを数字にして」
- 「キャッシュフローがいつ回るか確認したい」

---

## モード一覧

| モード | 内容 |
|--------|------|
| A: 損益シミュレーション（P&L） | 3年間の収益・費用・利益を3シナリオで試算 |
| B: DCF・企業価値分析 | 将来キャッシュフローを割引率で現在価値化 |
| C: 損益分岐点分析 | 固定費・変動費・単価から黒字化条件を算出 |
| D: 価格戦略設計 | 原価積上・競合比較・価値ベースの3軸で最適価格を設計 |
| E: キャッシュフロー計画 | 月次CF予測・資金ショートリスクの特定 |
| F: リスク定量化 | シナリオ別の損失規模・確率・優先度を数値化 |

## プロセスA：損益シミュレーション（P&L）

### 必要な入力情報

```
以下の数値を教えてください（概算・仮定でもOK）：

【収益サイド】
1. 主な売上の種類（例：月額契約、スポット販売、複数商品）
2. 想定客数・件数（月あたり）
3. 単価（商品・サービスごと）

【費用サイド】
4. 固定費（例：人件費、家賃、システム費）月額
5. 変動費（売上に連動するもの）売上比率または単価
6. 初期投資（設備・開発など）

【前提】
7. 目標とする期間（例：3年）
8. 成長率の仮定（例：月5%成長、初年度フラット）
```

### 出力形式

3シナリオ（楽観・基本・悲観）×3年間のP&Lを表形式で出力する。

```
【損益シミュレーション】

前提条件：
  楽観：成長率〇%・顧客獲得〇件/月
  基本：成長率〇%・顧客獲得〇件/月
  悲観：成長率〇%・顧客獲得〇件/月

        1年目         2年目         3年目
        楽観/基本/悲観  楽観/基本/悲観  楽観/基本/悲観
売上高
変動費
粗利益（粗利率）
固定費
営業利益（営業利益率）
累計損益
投資回収月（基本シナリオ）：○ヶ月目

⚠ 注意点：〇〇の仮定が実現しない場合のリスク
```

## プロセスB：DCF・企業価値分析

### 必要な入力情報

```
1. 今後5〜10年の予想フリーキャッシュフロー（FCF）
   （P&Lシミュレーション済みであればそこから算出可）
2. 割引率（WACC）または想定リターン率（例：10%）
3. 永続成長率（ターミナル値の計算用、例：2%）
4. 現在の負債・現金（企業価値→株式価値変換時に使用）
```

### 出力形式

```
【DCF分析結果】

割引率：〇%  永続成長率：〇%

年度   FCF予測   割引係数   現在価値
1年目  〇〇万円  〇〇       〇〇万円
...
5年目  〇〇万円  〇〇       〇〇万円

ターミナルバリュー現在価値：〇〇万円
企業価値（EV）合計：〇〇万円

感応度分析：
          割引率8%  割引率10%  割引率12%
成長率1%  〇〇万    〇〇万     〇〇万
成長率2%  〇〇万    〇〇万     〇〇万
成長率3%  〇〇万    〇〇万     〇〇万

→ 最も現実的なシナリオでの企業価値：〇〇万円
```

## プロセスC：損益分岐点分析

```
【損益分岐点分析】

固定費合計：〇〇万円/月
変動費率：〇〇%（または単価〇〇円）
販売単価：〇〇円

損益分岐点売上高：〇〇万円/月
損益分岐点販売数：〇〇個/月（〇〇件/月）

現在の売上が〇〇万円の場合：
  安全余裕率：〇〇%（高いほど安全）
  必要成長：あと〇〇万円/月で黒字化

視覚的なイメージ：
[売上ライン] ────────────────→
[総費用ライン] ───────────────→
[損益分岐点] ◆ 〇ヶ月目/〇〇万円
```

## プロセスD：価格戦略設計

3つの軸で最適価格を導き出す。

```
【価格戦略分析】

① コスト積上げ価格（フロア）
  原価：〇〇円
  目標利益率：〇〇%
  → 最低価格：〇〇円

② 競合比較価格（市場相場）
  競合A：〇〇円（/月 or /件）
  競合B：〇〇円
  市場平均：〇〇円
  → 競合水準：〇〇〜〇〇円

③ 価値ベース価格（シーリング）
  顧客が得られる価値（時間削減・売上増など）：〇〇万円
  顧客が支払える上限（価値の〇〇%）：〇〇円
  → 価値上限：〇〇円

【推奨価格帯】
  ローンチ価格：〇〇円（競合比△△%・コスト比△△%）
  成熟後価格 ：〇〇円
  理由：〇〇

価格変更シミュレーション：
  現行価格〇〇円 → 〇〇円に値上げした場合
  必要な解約抑制率：〇〇%以下なら増収
```

## プロセスF：リスク定量化

```
【リスクマトリクス】

リスク項目          発生確率  影響額    優先度  対策
顧客獲得が計画の50%  40%      -〇〇万円  🔴高   最低限の固定費構造に変更
主要顧客の離脱       20%      -〇〇万円  🔴高   複数顧客分散・解約防止策
競合の値下げ         30%      -〇〇万円  🟡中   差別化の強化
為替・原材料高騰      15%      -〇〇万円  🟡中   仕入れ先多様化
キーパーソン離脱      10%      -〇〇万円  🟢低   マニュアル化・採用準備

期待損失総額（確率×影響の合計）：〇〇万円
バッファ推奨額：〇〇万円（期待損失の1.5倍）
```
