## **はじめに**

### **Agent Skillsとは？**

Agent Skillsは、Claudeに特定のタスクを実行させるための専門機能です。「こんな文書を作って」と話しかけるだけで、プロフェッショナルなビジネス文書を自動生成できます。

### **3つのマスタートリガー**

まとめて複数のスキルを実行したい場合は、以下のトリガーワードを使います：

| トリガー | 実行内容 | 用途 |
| ----- | ----- | ----- |
| **「提案準備」** | ヒアリングシート → 補助金確認 → 提案骨子 | 商談後の提案準備 |
| **「契約準備」** | 上記 \+ 見積書 → NDA → 契約書 → WBS | 契約締結まで一気通貫 |
| **「月締め」** | 日報集計 → 月次レポート → 請求書 | 月末の定例処理 |

---

## **基本的な使い方**

### **Step 1: スキルを呼び出す**

Claudeに以下のように話しかけます：

```
「見積書を作成して」
「ヒアリングシートを作って」
「契約書が必要です」
```

### **Step 2: 必要情報を入力する**

Claudeが必要な情報を質問してきます。回答を入力してください。

```
Claude: クライアント名を教えてください。
あなた: 合同会社大吉です。

Claude: 金額（税抜）はいくらですか？
あなた: 月額30万円です。
```

### **Step 3: ファイルをダウンロードする**

生成が完了すると、ダウンロードリンクが表示されます。クリックしてファイルを取得してください。

## **営業フェーズのスキル**

### **1\. hearing-sheet-generator（ヒアリングシート生成）**

**用途**: 初回商談・現状把握のためのヒアリングシートを作成

**呼び出し方**:

```
「ヒアリングシートを作成して」
「現状把握シートを生成して」
「商談準備シートを作って」
```

**必要な情報**:

* クライアント名  
* 業種（製造業、小売業、金融業など14種類）  
* 対象部門（経理、人事、営業など）  
* ヒアリング予定日（任意）

**出力ファイル**: `hearing_sheet_{クライアント名}_{日付}.xlsx`

**特徴**:

* 業種に応じた質問項目を自動追加  
* 部門別に専門シートを生成  
* 文字起こしテキストからの自動記入にも対応

---

### **2\. jgrants-mcp（補助金検索）**

**用途**: Jグランツ（政府補助金ポータル）から活用可能な補助金を検索

**呼び出し方**:

```
「補助金を調べて」
「使える助成金はある？」
「IT導入補助金について教えて」
```

**必要な情報**:

* 業種  
* 従業員数  
* 対象地域（香川県、全国など）  
* 導入目的（生成AI導入、IT導入、業務効率化など）

**出力**: 提案骨子や見積書に情報を反映

**注意点**:

* 補助金情報は参考情報です。採択を保証するものではありません  
* 出典「Jグランツ」を必ず明記します

---

### **3\. proposal-outline-generator（提案骨子生成）**

**用途**: ヒアリング結果から1〜2ページの提案骨子を作成

**呼び出し方**:

```
「提案骨子を作成して」
「提案のたたきを作って」
「このヒアリングから提案を作って」
```

**必要な情報**:

* ヒアリングシート（Excel）または文字起こしテキスト  
* クライアント名（自動抽出も可能）

**出力ファイル**: `proposal_outline_{クライアント名}_{日付}.docx`

**自動反映される内容**:

* クライアントの課題（ヒアリングシートから抽出）  
* 活用可能な補助金情報  
* 提案アプローチと期待効果

## **契約フェーズのスキル**

### **4\. billing-documents（見積書・請求書生成）**

**用途**: 見積書または請求書を作成

#### **見積書の場合**

**呼び出し方**:

```
「見積書を作成して」
「見積もりが必要です」
```

**必要な情報**:

* 見積先企業名  
* 業務内容  
* 金額（税抜）  
* 有効期限（省略時は30日後）

**出力ファイル**: `御見積書_QUO-YYYYMM-XXX.xlsx`

#### **請求書の場合**

**呼び出し方**:

```
「請求書を作成して」
「インボイスが必要です」
```

**必要な情報**:

* 請求先企業名  
* 業務内容  
* 金額（税抜）  
* 請求日（省略時は今日）

**出力ファイル**: `請求書_INV-YYYYMM-XXX.xlsx`

**共通の特徴**:

* 消費税10%を自動計算  
* Jony Iveデザインで統一された外観  
* PDF変換が必要な場合はExcelから印刷→PDF保存

---

### **5\. nda-generator（機密保持契約書生成）**

**用途**: 企業間の機密保持契約書（NDA）を作成

**呼び出し方**:

```
「NDAを作成して」
「機密保持契約書を作って」
「秘密保持契約が必要です」
```

**必要な情報**:

* 開示者（情報を開示する側の企業名）  
* 受領者（情報を受け取る側の企業名）  
* 契約の目的（システム開発、コンサルティングなど）

**出力ファイル**: `nda_{クライアント名}_{日付}.docx`

**含まれる条項**:

* 機密情報の定義  
* 機密保持義務  
* 外部サービス利用規定（Google Workspace等）  
* 損害賠償の上限（500万円）  
* 秘密保持期間（終了後5年間）

---

### **6\. consulting-contract-generator（業務委託契約書生成）**

**用途**: コンサルティング・アドバイザリー業務の委託契約書を作成

**呼び出し方**:

```
「業務委託契約書を作成して」
「コンサル契約が必要です」
「顧問契約書を作って」
```

**必要な情報**:

* 委託者（発注側の企業名）  
* 受託者（受注側の企業名）  
* 業務内容  
* 月額報酬  
* 契約期間

**出力ファイル**: `contract_{クライアント名}_{日付}.docx`

**含まれる条項**:

* 業務内容の明確化  
* 報酬・支払条件  
* 知的財産権の帰属（共有型がデフォルト）  
* 再委託の許可  
* 損害賠償の上限（300万円）

---

### **7\. gantt-chart-generator（WBS/ガントチャート生成）**

**用途**: プロジェクトのWBS（作業分解構成）とガントチャートを作成

**呼び出し方**:

```
「ガントチャートを作成して」
「プロジェクトスケジュールをExcelで」
「WBSを作って」
```

**必要な情報**:

* プロジェクト名  
* 開始日  
* 終了日（契約期間）  
* フェーズ・タスク情報

**出力ファイル**: `gantt_{クライアント名}_{日付}.xlsx`

**特徴（v3.0 動的関数版）**:

* 開始日・終了日を変更するとバーが自動伸縮  
* ステータスを変更すると色が自動変更

* Jony Iveデザイン（グレースケール＋アクセント1色）

## **実行フェーズのスキル**

### **8\. daily-report-voice（音声入力日報）**

**用途**: 音声で話した業務内容を日報として記録

**呼び出し方**:

```
「今日の日報を記録して」
「日報を入力します」
```

**入力方法**: 自然な言葉で業務内容を話すだけでOK:

```
 データベース設計で課題が発生しています。
 明日はB社との要件定義会議の予定です。」
```

**出力ファイル**: `MIRAICHI_日報_YYYY-MM-DD.xlsx`

**自動抽出される項目**:

* 日付（自動取得）  
* 報告者  
* 作業内容  
* 課題  
* 次回予定

**呼び出し方**:

```
「月次レポートを作成して」
```

## **メタスキル**

### **15\. jony-ive-design-system（デザインガイドライン）**

**用途**: 全文書に統一デザインを適用するためのスタイルガイド

**基本原則**:

1. 極限までシンプルに  
2. 余白を贅沢に使う  
3. 完璧な整列  
4. グレースケール基調＋アクセント1色のみ  
5. 濃淡で階層を表現

**カラーパレット**:

| 用途 | 色コード | 使用場面 |
| ----- | ----- | ----- |
| ブラック | \#000000 | タイトル |
| ダークグレー | \#333333 | 本文 |
| ミディアムグレー | \#666666 | 見出し |
| ライトグレー | \#999999 | 補足 |
| アクセントブルー | \#5B7B94 | マイルストーンのみ |

**フォント**: メイリオ統一

## **トラブルシューティング**

### **Q: ファイルが生成されない**

**A**: 以下を確認してください：

1. 必要な情報をすべて入力したか  
2. エラーメッセージが表示されていないか  
3. 再度スキルを呼び出して試す

### **Q: 日本語が文字化けする**

**A**: ファイルを開く際にエンコーディングをUTF-8に設定してください。Excelの場合は「データ」→「テキストファイル」から読み込むとエンコーディングを選択できます。

### **Q: デザインが崩れる**

**A**: メイリオフォントがインストールされているか確認してください。また、ファイルを編集する際は、元のフォーマットを維持するようにしてください。

### **Q: 補助金情報が見つからない**

**A**: 検索条件を広げてみてください：

* 業種を「中小企業」「小規模事業者」に変更  
* 対象地域を「全国」に変更  
* 導入目的を「設備整備・IT導入」に変更
