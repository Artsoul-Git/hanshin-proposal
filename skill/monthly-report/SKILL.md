# 月次活動レポート 自動生成スキル

日報データをもとに、クライアント向けの月次活動レポートを自動生成するスキル。A4縦2ページに収まる「読まれる」設計。

## トリガーワード

- 「月次レポートを作成して」
- 「今月の活動報告を作って」
- 「月報を生成して」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 内容 |
|------|------|
| クライアント名 | レポート宛先の企業名 |
| 対象月 | 例：2026年5月 |
| 稼働実績 | 日数・時間（日報から自動集計 or 入力） |
| 主要活動 | 今月実施した業務（3項目程度） |
| 成果 | 達成した結果・数値 |
| 課題と対応 | 発生した課題と対応策 |
| 次月の計画 | 来月の予定（3〜5項目） |

---

## レポート構成（A4縦2ページ固定）

### 1ページ目：概要

**ヘッダー**
- タイトル「月次活動レポート」
- 対象月・クライアント名

**稼働実績**
- 稼働日数・稼働時間

**活動内訳（2カラム）**
- 左：業務別の日数・割合リスト
- 右：円グラフ（業務内訳の視覚化）

**主要活動（箇条書き3項目）**
- 各活動の詳細サブ項目

### 2ページ目：詳細

**成果**
- ✓ 達成事項と具体的な数値
- 定量的な成果を必ず記載

**課題と対応**
- 課題と対応策をセットで記載

**次月の計画**
- 5項目程度のアクションリスト

**フッター**
- 自社名（小さく・控えめに）

---

## デザイン仕様

**設計原則：「間延びせず、詰め込みすぎず」**

- 2ページきっちりに収まる設計
- グレーとブラックのみ（控えめな色使い）
- フォントサイズで重要度を表現

| 要素 | フォント |
|------|---------|
| タイトル | メイリオ 22pt 太字 |
| セクション見出し | メイリオ 13pt 太字 |
| 本文 | メイリオ 9〜9.5pt |
| フッター | メイリオ 8pt |

余白：上下2cm・左右2.5cm

---

## 業務分類の自動集計

日報の作業内容から5カテゴリに自動分類して集計：

| カテゴリ | 検出キーワード |
|---------|--------------|
| 戦略策定 | 戦略・ミーティング |
| 研修・教育 | 研修・教育 |
| 資料作成 | レポート・資料 |
| 定例会議 | 会議・定例 |
| その他 | 上記以外 |

---

## 活用シーン

- **月末の定例送付**：継続契約クライアントへの活動報告
- **成果の可視化**：数値・事実でアドバイザリーの価値を証明
- **次月の合意形成**：次月計画を事前に共有

---

## 業務フロー

```
【毎日】日報入力（/daily-report）
    ↓
【月末】月次レポート生成（/monthly-report）
→ 所要時間：5〜10分（微調整込み）
    ↓
クライアントへ送付
    ↓
顧客満足度向上 → 継続契約
```

---

## 日報との連携

`/daily-report` で蓄積した日報ファイルがあれば、稼働実績・業務内訳を自動集計できる。なければ手入力でも対応。

## 出力ファイル名

`月次レポート_{クライアント名}_{YYYYMM}.docx`
