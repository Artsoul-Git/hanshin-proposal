# /ma スキル（M&A支援）

**用途:** 取引規模5,000万円程度までのスモールM&A案件において、企業価値評価・デューデリジェンス・ストラクチャー設計・PMI計画・価格交渉の論点整理を行う。

---

## 免責・適用範囲の明示（必須）

> **このスキルが提供するもの：** 分析フレームワーク・チェックリスト・試算モデル・論点整理・参考資料の草案
>
> **このスキルが提供できないもの：**
> - 法的拘束力のある契約書・文書の作成（弁護士・司法書士が必要）
> - M&A仲介業としての登録行為・媒介契約（登録業者が必要）
> - 税務・会計処理の確定判断（税理士・公認会計士が必要）
> - 最終的な取引価格・条件の保証
>
> **対象規模：** 取引価格1,000万〜5,000万円程度のスモールM&A
> （これ以上の規模は専門FA・M&A仲介会社との連携を推奨）

---

## 発動条件

- 「会社を買いたい・売りたい」「事業承継の検討をしたい」
- 「この会社、いくらで買えるか試算したい」
- 「M&Aのデューデリジェンスで何を確認すべきか」
- 「株式譲渡と事業譲渡、どちらがいいか」
- 「買収後の統合計画（PMI）を作りたい」
- 「LOIの骨子を整理したい」

| モード | 内容 |
|--------|------|

## プロセスA：企業価値評価

### 入力情報

```
以下の情報があれば試算できます（概算でもOK）：

【財務情報】
1. 直近3期の売上高・営業利益（または純利益）
2. 直近の貸借対照表（総資産・総負債・純資産）
3. 設備・不動産などの含み損益（わかれば）
4. 簿外債務・偶発債務（未払い残業、保証債務など）

【事業情報】
5. 業種・主要サービス
6. 主要顧客の集中度（上位3社の売上比率）
7. 従業員数・平均勤続年数
8. オーナー依存度（オーナー不在でも事業継続できるか）
```

### 3手法による試算

```
【企業価値評価レポート】

■ 手法①：修正純資産法（清算価値・下限の目安）
  帳簿純資産：〇〇万円
  含み益（不動産・設備）：+〇〇万円
  簿外債務（未払い残業等）：−〇〇万円
  修正純資産：〇〇万円
  → 時価純資産ベースの企業価値：〇〇万円

■ 手法②：倍率法（EBITDAマルチプル）
  EBITDA（営業利益＋減価償却）：〇〇万円/年
  業種標準マルチプル：〇〇〜〇〇倍
  （中小企業サービス業：3〜5倍が目安）
  企業価値レンジ：〇〇万円〜〇〇万円
  ネットデット調整後：〇〇万円〜〇〇万円

■ 手法③：DCF法（将来価値）
  正常化EBITDA：〇〇万円
  成長率仮定：〇〇%
  割引率（WACC）：〇〇%
  予測期間：5年
  企業価値（EV）：〇〇万円

【総合評価レンジ】
  保守的（修正純資産ベース）：〇〇万円
  標準的（倍率法中央値）：〇〇万円
  楽観的（DCF高成長想定）：〇〇万円
  → 交渉レンジの目安：〇〇万円〜〇〇万円

⚠ リスク調整要因（価値を下げる要因）：
  - オーナー依存度が高い → −〇〇%調整
  - 顧客集中（上位3社で売上70%超）→ −〇〇%調整
  - 有利子負債が大きい → 要ネットデット控除
```

## プロセスB：DDチェックリスト生成

業種・規模・ストラクチャーに応じたカスタムDDチェックリストを生成する。

```
【デューデリジェンス チェックリスト】

■ 財務DD（優先度：高）
  □ 直近3期の決算書（BS/PL/CF）の入手・確認
  □ 正常収益力の算定（一時的な損益の除外）
  □ 売掛金・棚卸資産の実在性確認
  □ 借入金・リース債務の全額確認
  □ 未払い費用・引当金の網羅性確認
  □ 役員報酬・オーナー関連費用の正常化
  □ 関連会社取引の条件・金額の確認
  □ 税務申告書との整合性確認

■ 事業DD（優先度：高）
  □ 主要顧客リスト・売上集中度
  □ 主要顧客との契約内容・解約条項
  □ 競合状況・市場ポジション
  □ 主要仕入先・サプライチェーンのリスク
  □ 特許・商標・ノウハウなど無形資産の確認
  □ 許認可・免許の譲渡可否（事業譲渡の場合）
  □ オーナー依存業務の特定と移管可能性

■ 法務DD（優先度：高）※弁護士確認推奨
  □ 定款・株主名簿・株主構成の確認
  □ 重要契約書（顧客・仕入先・賃貸借）の確認
  □ 訴訟・紛争・クレームの有無
  □ 担保・保証の状況
  □ 許認可・行政処分の有無
  □ 知財の権利帰属確認

■ 労務DD（優先度：中）※社労士確認推奨
  □ 雇用契約書の整備状況
  □ 未払い残業代のリスク（36協定・時間外管理）
  □ 退職金規程・積立状況
  □ キーパーソンの処遇・継続意向
  □ 就業規則の整備・周知状況

■ ITシステムDD（優先度：中）
  □ 基幹システムの保守状況・契約
  □ サイバーセキュリティ対策の確認
  □ データの所有権・個人情報管理

【DDの優先順位と進め方】
  第1弾（LOI前）：財務DDの概要 + オーナー依存確認
  第2弾（LOI後）：全DD項目の詳細確認
  第3弾（SPA前）：懸念事項の解消確認 + 最終確認
```

## プロセスC：ストラクチャー比較

```
【取引ストラクチャー比較】

■ 株式譲渡（最も一般的なスモールM&A手法）
  メリット：手続きが比較的シンプル / 許認可を引き継げる
  デメリット：簿外債務・偶発債務ごと引き継ぐ / 表明保証リスク
  適合場面：許認可が事業の核心 / 顧客契約を引き継ぎたい

■ 事業譲渡（資産・契約を選んで取得）
  メリット：不要な負債・事業を切り離せる / 簿外債務リスクを限定化
  デメリット：顧客・仕入先との契約を個別に引き継ぐ / 許認可は原則再取得
  適合場面：事業の一部だけ欲しい / 債務リスクを避けたい

■ 会社分割（新会社に事業を切り出す）
  メリット：事業の切り出しが比較的クリーン
  デメリット：手続きが複雑・時間がかかる / 専門家費用が高い
  適合場面：グループ内再編 / 事業の一部切り出しが必要

【今回の案件への推奨ストラクチャー】
  推奨：〇〇方式
  理由：〇〇（許認可・簿外債務リスク・コストを考慮）
  注意点：〇〇については専門家（弁護士・税理士）の確認必須
```

## プロセスD：PMI 100日プラン

```
【PMI（統合後管理）100日プラン】

Day 1〜30：安定化フェーズ
  人材：キーパーソンと個別面談・処遇確認・離職防止
  業務：現行オペレーションを変えない（様子見）
  コミュニケーション：全従業員への方針説明（不安の解消）
  数字：財務モニタリング開始（週次CF確認）

Day 31〜60：理解深化フェーズ
  人材：AIマネージャー候補の特定・非公式な関係構築
  業務：業務フロー・顧客・仕入先の全容把握
  システム：既存ツール・データの棚卸し
  数字：正常収益力の再確認（簿外費用・一時費用の整理）

Day 61〜100：改善着手フェーズ
  改善①：最優先課題（Day 30〜60で特定）への着手
  人材：評価制度・役割の見直し案の策定（実施は100日後）
  統合：自社とのシステム・文化統合の方針確定
  報告：Day 100成果報告（KPI初期実績 + 今後の計画）

Day 100以降：成長フェーズ（PMIフェーズ2）
  シナジー実現（売上・コスト・ノウハウ）
  AI・デジタル化の導入
  KPI管理・定着
```

## プロセスE：価格交渉の論点整理

```
【価格交渉 論点マップ】

■ 買い手側の論点（価格を下げる根拠）
  ・DD結果で発覚したリスク：〇〇（−〇〇万円調整）
  ・オーナー依存リスク：〇〇（移管コスト見込み：〇〇万円）
  ・顧客集中リスク：上位3社で〇〇%（業界標準比リスク高）
  ・設備の老朽化・更新投資の必要性：〇〇万円見込み
  BATNA（最低限受け入れられる条件）：〇〇万円

■ 売り手側の論点（価格を上げる根拠）
  ・過去3年の安定した利益実績
  ・既存顧客との長期契約・高い更新率
  ・許認可・ブランドの取得コスト
  ・買い手にとっての戦略的プレミアム（市場参入・人材獲得）

■ 交渉の落としどころ設計
  希望価格：〇〇万円（売り手）
  提示価格：〇〇万円（買い手）
  想定妥結レンジ：〇〇万円〜〇〇万円
  価格以外の交渉カード：
    - アーンアウト条項（一部を業績連動で後払い）
    - 表明保証保険の活用
    - オーナーの移行期間同行（3〜6ヶ月）
    - 退職金・弔慰金の扱い
```

## プロセスF：LOI骨子作成支援

```
【LOI（意向表明書）骨子 ※法的効力なし・参考用】

1. 対象会社・取引対象
   （株式100% / 事業の一部 etc.）

2. 想定取引価格レンジ
   （DDの結果次第で変動する旨を明記）

3. 取引ストラクチャー
   （株式譲渡 / 事業譲渡）

4. 独占交渉期間
   （例：LOI締結後30日間）

5. 実施予定のDD内容と期間

6. クロージング予定時期

7. 前提条件・解除条件
   （DDにて重大な問題が発見された場合 etc.）

8. 秘密保持の確認

⚠ 実際のLOI作成・締結は弁護士に依頼してください。
```

## スモールM&Aの判断基準（¥5,000万円以下）

```
【買い手として検討すべき最低ライン】

財務健全性：
  □ 直近3期すべてで営業利益が黒字
  □ 有利子負債が年間EBITDAの3倍以内
  □ 売掛金の回収サイクルが正常（90日以内）

事業継続性：
  □ オーナー以外に業務を知る人間が最低2名いる
  □ 顧客上位3社の売上集中が70%以下
  □ 主要顧客との契約が1年以上残っている

統合実現性：
  □ 自社（買い手）が事業を理解・管理できる業種
  □ キーパーソンが買収後も残る意向を確認
  □ 自社リソースでPMIを実行できる（外部委託不要）
```
