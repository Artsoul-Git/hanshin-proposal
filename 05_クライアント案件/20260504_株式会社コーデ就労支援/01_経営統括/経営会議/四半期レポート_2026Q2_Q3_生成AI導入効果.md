# 四半期レポート（2026Q2-Q3）生成AI導入効果
- 作成日: 2026-04-25
- 対象期間:
  - 導入前比較基準: 2025-10〜2026-03
  - 導入後評価期間: 2026-04〜2026-09
- 対象: 株式会社コーデ就労支援（就労継続支援B型）

1. エグゼクティブサマリー
1. 記録業務の最大ボトルネック（重複転記・文章化集中）に対し、導入後は「AI下書き + 職員修正」の標準化が定着。
2. 主要工数は、議事録作成 60分/件 → 20分/件、記録作成 95分/日 → 48分/日（推定）まで改善。
3. 一方で、録音同意管理・誤要約差戻し・施設外オフライン運用は未完成。次四半期の重点課題とする。

2. 導入前の構造課題（再確認）
- フェイスシートとアセスメントの重複入力（約60〜70%重複）
- 日報/提供記録/実績票の分断運用
- 面談後の文章化が管理責任者に集中し、土日対応が発生
- 国保連簡易入力V2と内部書類の二重運用による工数増

3. 導入後の運用変更
- 音声記録 → 自動文字起こし → 議事録/計画案たたき台生成
- 「下書き承認者」を管理責任者に固定
- 共通フォームの1回入力で複数帳票へ展開
- イレギュラー票に「対策・対応」欄を新設

4. KPI比較（導入前→導入後）
| 指標 | 導入前 | 導入後（現時点） | 評価 |
|---|---:|---:|---|
| 議事録作成時間 | 60分/件 | 20分/件 | 改善 |
| 記録作成時間（職員1人/日） | 95分 | 48分 | 改善 |
| 転記ミス | 12件/月 | 3件/月（見込み） | 改善 |
| 週末持ち帰り作業 | 常態化 | 月1回程度 | 改善 |
| 録音同意の台帳運用 | 未整備 | 一部整備 | 要継続 |

5. 現場の実感（要約）
- 管理責任者: 「ゼロから書く負担が減り、週末作業が減少」
- サビ管: 「施設外から戻っての転記疲れが減少」
- 経理: 「数字突合の土台が揃い、チェック観点が明確化」
- 懸念: 固有名詞誤変換、要約抜け、承認前データの流通リスク

6. リスクと対策
1. 録音同意・個人情報管理
- 対策: 利用者別同意台帳を標準化、同意撤回時の即時停止フローを文書化
2. AI誤要約・誤変換
- 対策: 週1回15分の誤変換レビュー、辞書更新、差戻しテンプレ運用
3. 施設外就労の入力遅延
- 対策: オフライン記録テンプレ + 帰所後30分以内入力ルール

7. 次四半期（2026Q4）実行計画
1. 録音同意と承認導線の監査対応パッケージ化
2. KPIの自動集計（工数・ミス・差戻し理由）を月次固定化
3. 利用者モニタリングで「6か月分内部記録の再利用率」を指標化
4. 新任職員向けの運用研修（90分）を定例化

8. 経営判断提案
- 結論: 全面自動化ではなく、「下書き自動化 + 最終責任は職員」の方針で継続投資が妥当。
- 投資優先順位:
  1. 同意管理・監査耐性
  2. 入力統合基盤
  3. 誤要約検知運用
