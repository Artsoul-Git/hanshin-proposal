# パターン#1：逆説フック・実演証明型（v1.1）

> 短尺（60〜90秒）の縦型動画で「ツール／機能」の威力を訴求するための型。
> 抽出元：Keiさんが2026-05-26に共有した「Claude Codeのスキルで爆速資料作成」（76秒・縦型・60fps）
>
> **v1.1 更新（2026-05-26）：** Whisper統合のextract再実行により、配分比率・痛み増幅の手法・差別化示唆・締めの設計を補正。

---

## このパターンが効くケース

| 条件 | 該当例 |
|---|---|
| 訴求対象が **ツール／機能／プラグイン／ライフハック** | Skills機能、Cursorのエージェント、Excel関数、Notion AI |
| **Before（手作業のしんどさ）**を視覚化できる | 既存のレポート作成、手動データ整理、定型業務 |
| **After（自動化／時短）**を画面で実演できる | 数十秒で完了するデモが撮れる |
| 視聴者ターゲットが **時間に追われている層** | ビジネスパーソン、フリーランス、副業層 |

**逆に向かないケース：** 概念だけの抽象トピック、感情訴求中心の発信、長尺ストーリー型

---

## 動画構造（7パート・77秒モデル）

```
[0-2s]    フック       ─── 強烈否定型タイトル（「〇〇しないとヤバい」）
[2-14s]   Before       ─── 手作業の現状を画面録画で見せる（即・主題突入）
[14-30s]  痛み増幅     ─── 図解 + 「項目連射」で手作業の負荷を可視化＆音響化
[30-37s]  解決概念     ─── 仕組みを「7秒で言い切って実演に投げる」（短い）
[37-56s]  実演証明     ─── ターミナル／PC画面でAfterを一発で見せる
[56-66s]  キラーワード ─── 「全部自動です」＋ロゴ・細部の喜び表現
[66-77s]  競合差別化＋CTA ─── 「今までの〇〇では難しかった」→「これで回ったら時間浮きますよね」→CTA
```

**配分の鉄則（v1.1で実測値ベースに補正）：**

| パート | 秒 | 比率 |
|---|---|---|
| フック | 2 | 3% |
| Before | 12 | 16% |
| 痛み増幅 | 16 | 21% |
| 解決概念 | 7 | 9% |
| 実演証明 | 19 | 21% |
| キラーワード | 10 | 14% |
| 競合差別化+CTA | 11 | 16% |

- **痛み + 実演 ≥ 40%**（共感→証明にリソース集中、v1.1実測 42%）
- フック：3秒以内 ／ CTA含む最終ブロック：10〜15秒
- **解決概念は7秒で言い切る**（長く説明せず実演で殴る設計が肝）
- 60〜90秒ならこの比率を等倍スケール

## 画面構成（5層固定UI）

```
┌──────────────────────────┐
│ ① 上部・固定タイトル帯（赤地白文字＋黄ハイライト） │ ← 最終秒まで掲出
├──────────────────────────┤
│                          │
│ ② メインビジュアル領域（40-60%）            │ ← 顔出し／PC録画／図解が切替
│                          │
├──────────────────────────┤
│ ③ ナレ字幕（白文字・1-3秒で切替）           │ ← 無音再生対応
├──────────────────────────┤
│ ④ 固定要約（白文字・数値対比型）             │ ← 「2時間→30秒」
├──────────────────────────┤
│ ⑤ 固定CTA（黒地白文字・矢印付き）           │ ← 「本編は下の▷から」
└──────────────────────────┘
```

**鉄則：**
- 上下のテキスト帯は **縦の合計約40%** を占有 → メイン領域は中央60%
- 視聴者が **音声OFF＋途中入り** でも主題・結論・行動を理解できる設計
- ①と④と⑤は **77秒間ずっと固定**

## 言葉のDNA

| パターン | テンプレ | 機能 |
|---|---|---|
| **強烈否定型フック** | 「〇〇しないとヤバい／知らないと損／使えないと終わる」 | 損失回避バイアスで離脱阻止 |
| **時間圧縮の数値対比** | 「X時間 → Y秒」「X日 → Y分」 | 効果を一瞬で伝える（多くは下部固定要約に置く） |
| **項目連射型痛み増幅**（v1.1新規） | 「業種、商品、カテゴリ、取引、担当者、売上金額、粗利…」など項目を早口列挙 | 音声だけで「データが多くて手作業はしんどい」と体感させる |
| **絶対化キラーワード** | 「全部自動です／一発でできます／勝手にやってくれます」 | 信頼感と簡潔さ |
| **競合ツール比較示唆**（v1.1新規） | 「今までの〇〇では難しかった／ここまでは〇〇でもできなかった」 | 旧ツール経由で新ツールの優位性を証明 |
| **未来仮定 + ROI同梱**（v1.1強化） | 「これで回るようになったら、かなりの時間が浮きますよね」 | 単独の未来仮定でなく**1文に時間浮き／コスト削減を同梱**して締める |
| **CTA定型** | 「本編は下の▷から／詳しくは固定コメントから」 | 回遊導線を明示 |

**v1.1で得た締めの黄金パターン：**

```
[競合差別化示唆] →（即つなぎ）→ [未来仮定+時間浮き同梱] → [CTA定型]
```

この3手で 10〜12秒を使い切ると、視聴後の「本編見たい」率が最大化する設計。

## このパターンの再現スイッチ

`apply` モードで呼び出すとき、Kaiは以下のスロットを埋める：

| スロット | 必須／任意 | 例 |
|---|---|---|
| 対象ツール | 必須 | Claude Code / Notion / Excel |
| 対象機能 | 必須 | Skills機能 / AI記事生成 / XLOOKUP |
| Before業務 | 必須 | 月次レポート作成 / 議事録まとめ |
| Before所要時間 | 必須 | 2時間 / 半日 / 1週間 |
| After所要時間 | 必須 | 30秒 / 5分 / 即日 |
| ターゲット層 | 必須 | 中小企業経営者 / バックオフィス |
| 動画長 | 任意（既定77秒） | 60-90秒 |
| キラーワード候補 | 任意 | 「全部自動です」など |
| **痛み増幅の項目列挙**（v1.1新規） | 任意 | 「業種・商品・カテゴリ・担当者・金額…」など3-7個 |
| **競合ツール比較相手**（v1.1新規） | 任意 | 「GPTs」「Excel単独」「手作業」など |

これらを揃えれば **同DNAの新ショート動画コンテプロット** を1分で生成できる。

**apply時の標準アウトプット（v1.1で明文化）：**
1. シーン別タイムライン（2秒粒度の表）
2. 撮影指示書（顔出し／PC録画／図解の切り分け）
3. ナレ台本（フルテキスト・敬体）
4. テロップ＋ハッシュタグ
5. 撮影前チェックリスト（配分検証含む）
6. 想定到達指標（Reels基準のKPI例示）

## 著作権・倫理ガイド

このパターンは **構造・比率・設計** のみ抽出している。元動画の登壇者・固有企業名・具体的な台詞は記録していない。
適用時は **新規テーマ／新規ターゲット／オリジナルの台詞** で構成すること。元動画のフレーズを直接コピーしない。
