# Nolia セットアップ手順書

作成：2026-05-13

---

## 全体の流れ

```
STEP 1  Googleスプレッドシートを作成
STEP 2  GASプロジェクトをセットアップ
STEP 3  GASにAPIキーを設定
STEP 4  GAS Web Appをデプロイ
STEP 5  GitHubにフロントエンドをアップロード
STEP 6  動作確認（テストユーザーで試す）
```

---

## STEP 1 — Googleスプレッドシートを作成

1. Google Driveを開く
2. 「新規」→「Googleスプレッドシート」
3. 名前を「Nolia-DB」に変更
4. URLの `/d/` と `/edit` の間の長い文字列を **スプレッドシートID** としてメモしておく
   ```
   例: https://docs.google.com/spreadsheets/d/【ここがID】/edit
   ```

---

## STEP 2 — GASプロジェクトをセットアップ

1. 上で作ったスプレッドシートを開く
2. メニュー「拡張機能」→「Apps Script」をクリック
3. 左側のファイル一覧から「コード.gs」をクリック
4. 中身を全部消す
5. `outputs/supplement_app/gas/` の各ファイルの中身を**ファイル名ごとに**貼り付ける

   | 貼り付け先ファイル名 | ソースファイル |
   |------------------|--------------|
   | コード.gs (→ Code.gs に名前変更) | `gas/Code.gs` |
   | ＋ファイルを追加 → `Config.gs`   | `gas/Config.gs` |
   | ＋ファイルを追加 → `Auth.gs`     | `gas/Auth.gs` |
   | ＋ファイルを追加 → `Records.gs`  | `gas/Records.gs` |
   | ＋ファイルを追加 → `Reports.gs`  | `gas/Reports.gs` |
   | ＋ファイルを追加 → `Admin.gs`    | `gas/Admin.gs` |
   | ＋ファイルを追加 → `ContentManager.gs` | `gas/ContentManager.gs` |

6. **Sheetsの初期化を実行する**
   - GASエディタ上部の関数選択で `setupSheets` を選択
   - ▶️実行ボタンをクリック
   - 「承認が必要」と出たら「権限を確認」→「許可」
   - 実行完了後、スプレッドシートを開いて6つのシートができているか確認

---

## STEP 3 — APIキーをスクリプトプロパティに設定

> ⚠️ APIキーをコードに直接書かないこと。プロパティに保存する。

1. GASエディタ左のナビゲーション「プロジェクトの設定」（⚙️ アイコン）をクリック
2. 「スクリプトのプロパティ」セクションまでスクロール
3. 「プロパティを追加」ボタンを押して以下を1つずつ追加：

   | プロパティ名 | 値 |
   |------------|---|
   | `SPREADSHEET_ID` | STEP 1 でメモしたID |
   | `GEMINI_API_KEY`  | Google AI StudioのAPIキー |
   | `LINE_TOKEN`      | LINE Messaging APIのChannel Access Token |
   | `ADMIN_TOKEN`     | 自分で決めた管理者パスワード（例: nolia-admin-2026） |

---

## STEP 4 — GAS Web AppをデプロイしてURLを取得

1. GASエディタ右上「デプロイ」→「新しいデプロイ」
2. 種類：「ウェブアプリ」を選択
3. 設定：
   - 説明：「Nolia v1.0」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」をクリック
5. 表示された **ウェブアプリのURL** をコピーしてメモ
   ```
   例: https://script.google.com/macros/s/AKfyc.../exec
   ```

---

## STEP 5 — GitHubにフロントエンドをアップロード

### 5-1. リポジトリ作成

1. GitHub.com（Artsoul-Gitアカウント）にログイン
2. 「New repository」
3. Repository name: `nolia-app`
4. Public（パブリック）を選択
5. 「Create repository」

### 5-2. config.js にGASのURLを設定

`_publish-staging/nolia-app/js/config.js` を開いて、
`YOUR_GAS_DEPLOYMENT_ID` の部分を STEP 4 でコピーしたURLに変更：

```javascript
API_BASE: 'https://script.google.com/macros/s/【ここに貼り付け】/exec',
```

### 5-3. LINEのIDを設定

`_publish-staging/nolia-app/index.html` の最下部を開いて：
```javascript
const lineUrl = 'https://line.me/R/ti/p/YOUR_LINE_ID';
```
`YOUR_LINE_ID` を公式アカウントのLINE IDに変更。

### 5-4. GitHub Pagesにアップロード

PowerShellで以下を実行（`_publish-staging/nolia-app/` フォルダで）：

```powershell
cd "D:\Google Antigravity\_publish-staging\nolia-app"
git init
git add .
git commit -m "feat: Nolia v1.0 initial release"
git branch -M main
git remote add origin https://github.com/Artsoul-Git/nolia-app.git
git push -u origin main
```

### 5-5. GitHub Pages を有効化

1. GitHub → `nolia-app` リポジトリ → 「Settings」
2. 左メニュー「Pages」
3. Source: 「Deploy from a branch」
4. Branch: `main` / `/ (root)`
5. 「Save」

数分後にアプリが公開されます：
```
https://artsoul-git.github.io/nolia-app/
```

---

## STEP 6 — テストユーザーを作って動作確認

### テストユーザーを作成（GASから実行）

GASエディタで新しいスクリプトファイルを作成し、以下を実行：

```javascript
function createTestUser() {
  const config = getConfig();
  const result = Admin.createUser(config.ADMIN_TOKEN, {
    email: 'あなたのメールアドレス',
    name:  'テストユーザー',
  });
  Logger.log(result.getContent());
}
```

実行するとメールが届きます。届いたリンクをクリックしてアプリに入り、
初期設定 → 日次記録 → の流れを確認してください。

## よくあるトラブル

| 症状 | 原因 | 対処 |
|------|------|------|
| 「リンクが見つかりません」と表示される | GASのURLが間違っているか、トークンが無効 | config.jsのAPI_BASEを確認。GASを再デプロイ |
| 保存しても何も起きない | GASのCORSエラー | GASのデプロイ設定で「アクセスできるユーザー：全員」になっているか確認 |
| レポートメールが届かない | GmailApp送信上限 or APIキーエラー | GASのログを確認 |
| Sheetsにデータが入らない | SPREADSHEET_IDが違う | スクリプトプロパティを再確認 |

## 週次レポートの自動送信設定（Phase 2）

GASで時間ベースのトリガーを設定します：

1. GASエディタ左の時計アイコン（トリガー）をクリック
2. 「トリガーを追加」
3. 実行する関数：`generateWeeklyReports`
4. イベントのソース：「時間主導型」
5. 時間ベースのトリガーのタイプ：「週ベースのタイマー」
6. 曜日：「毎週日曜日」
7. 時刻：「午後 10 時〜11時」
8. 「保存」

これで毎週日曜夜にレポートが全会員に自動送信されます。
