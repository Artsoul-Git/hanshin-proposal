# 音声入力 日報作成スキル

音声や自然文で話した業務内容を、構造化された日報Excelに変換するスキル。

## トリガーワード

- 「今日の日報を記録して」
- 「日報を入力します」
- 「今日の業務をまとめて」

---

## 音声入力例

```
「今日はA社向けにAI導入支援の提案書を4時間かけて作成しました。
要件定義の認識ずれが課題です。
明日はB社との定例ミーティングと議事録作成を予定しています。」
```

→ Kaiが自動的に6項目に振り分けて日報を生成する。

---

## 処理フロー

```
[入力] 自然言語での業務報告（音声テキストでも可）
    ↓
[解析] 作業内容・工数・課題・翌日予定を自動抽出
    ↓
[ヒアリング] 不足情報があれば追加質問
    ↓
[出力] 6列形式のExcelファイル生成
```

---

## 自動抽出する6項目

| 列 | 内容 | 自動取得 |
|----|------|---------|
| 日付 | 本日の日付 | ○（自動） |
| 報告者 | 担当者名 | △（不明時はヒアリング） |
| 作業内容 | 顧客名・業務の概要 | ○（発話から抽出） |
| 工数（h） | 作業にかけた時間 | ○（発話から抽出） |
| 課題 | 発生した問題・懸念事項 | ○（発話から抽出） |
| 翌日計画 | 翌日以降の予定 | ○（発話から抽出） |

---

## 不足情報のヒアリング例

| 不足項目 | 追加質問 |
|---------|---------|
| 工数不明 | 「作業時間はどのくらいでしたか？」 |
| 顧客不明 | 「どちらの顧客でしょうか？」 |
| 課題なし | 「特に課題はありませんでしたか？」 |
| 翌日予定なし | 「明日の予定はありますか？」 |

---

## 対応する業務パターン

- **コンサルティング**：ヒアリング・分析・提案書作成
- **AI/DX支援**：導入支援・ツール設定・効果測定
- **研修・教育**：セミナー準備・実施・フォローアップ
- **事務・管理**：書類作成・報告・調整業務

---

## 出力ファイル

- 形式：Excel（.xlsx）
- ファイル名：`日報_YYYY-MM-DD.xlsx`
- 構成：6列形式のシンプルテンプレート

---

## 月次レポートとの連携

日報を蓄積することで `/monthly-report` スキルが月次活動レポートを自動集計できます。

```
[毎日] 日報入力（/daily-report）
    ↓
[月末] 月次レポート生成（/monthly-report）
    ↓
クライアントへ送付
```
