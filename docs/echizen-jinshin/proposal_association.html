0. 本資料の前提（仮置数値と確認事項）

本資料の数値は「業務改善の方向性を判断するための仮置」です。実数値が確定し次第、KPI（施策の進捗を測る数値目標）・予算・スケジュールを精緻に組み直します。

仮置している主要前提

  • 協会員：約1,200名（賛助会員加入1年目）

  • 発言枠：2分間のマイク＋A5チラシ配布許可

確認待ち事項

1. 背景認識 — なぜいま「調理師会連合会」なのか

営業現場の事実

営業部7名で年間延べ800社訪問。新規開拓率は12%。10年前から半減。個別営業の限界が来ている。

市場の地殻変動

プロ料理人数は10年で22%減。最大代理店・井垣商店にヘンケルスが参入。受け身では縮む局面。

千載一遇の機会

協会員約1,200名／賛助会員1年目／2分マイクの発言枠。だが「お願いして入れてもらった立場」だからこそ売り込まない姿勢が活きる。

戦略の本質

総会で売り込まない。
「お役立ち情報の窓口」として認知してもらい、後の継続接触で関係を深める。
これは賛助会員1年目の越前刃心だからこそ無理なくできる姿勢。

賛助会員の立場 — 弱みは強みに転換できる

当初の弱み転換後の強み
協会内の信頼ゼロ「協会のメンバーになりたい」という低姿勢が共感を生む
2分マイクの限られた時間「売り込みではなくお役立ち資料の案内」に絞れる清々しさ
越前刃心ブランド認知率は30〜40%「知る人ぞ知る職人ブランド」と位置付けられる
これまで業界団体と疎遠新規参入のためフレッシュな情報を提供できる

2. 戦略骨格 — 「個別営業」から「個対多数」へ

どぶ板営業の限界は、社員の体力・時間に売上が完全に縛られることにあります。総会という「1対1,200」が成立する場で、属人化を解消する仕組みを同時に立ち上げます。

本戦略の本丸は「LINE公式アカウントを使うこと」ではありません。受注プロセスを誰でも回せるように整えることが本丸で、LINEはその上に乗る補助道具です。仕組みができていない状態でツールだけ入れても、結局は社長と一部社員に問い合わせが集中して終わります。

3. 4本柱施策

総会1日を起点に、「お役立ち情報の窓口」として継続接触する4つの仕掛けです。それぞれは独立に動きますが、合わさると相乗効果が生まれます。

施策1：DLコンテンツ3パターン＋アンケート版併用

パターンA：白書系

「2026年版 プロ料理人のための包丁メンテナンスレポート」公的データ＋現場ヒアリング。経営者・組合幹部向け。

パターンB：実務系

「明日から使える研ぎ直し10のコツ」職人頭・川口さん監修。現場の調理師さん向け。

パターンC：制度系

「HACCP対応 包丁衛生管理ガイドライン2026」食品衛生法改正対応。施設食堂運営者向け。

3パターンのDLそれぞれにアンケート版（5問）を併設。ニーズの定量化＋メールアドレス取得を同時に行う。

施策2：2分マイクの「姿勢の宣言」スクリプト

📜 2分マイク・スクリプト

「皆様、初めまして。福井県越前市から参りました、越前刃心株式会社 代表の山岸と申します。本日、賛助会員として初めて参加させていただきました。」

「私どもは1928年から、プロの料理人の皆様の包丁をお作りしてきました。ただ、これまで業界団体さんとは疎遠でして、今日初めてこの場に立たせていただいています。」

「ですので、まずはお役に立つことから始めさせていただきたいと思っております。研ぎのコツ、衛生管理、業界動向まとめ。協会員の皆様のお役に立てそうな資料を3点、無料でご用意しました。」

「お手元のチラシのQRコードからダウンロードいただけます。協会の一員として認めていただけるよう、貢献から始めます。本日はありがとうございました。」

要点は3つ。①「売り込まない」と先に宣言する／②「貢献から始める」と協会への敬意を示す／③ QRコード回収のフックを物理的に置く。これで「あの会社、なんか感じいいな」という第一印象を作ります。

施策3：1本目を手に取ってもらう仕組み

「研ぎ無料 × サンプル貸出」

協会員のうちDLしてくれた方限定で、「お手持ちの包丁を1本、無料で研ぎ直し」のオファー。送料も越前刃心負担。研ぎ直して返送する際に、新製品『刃心』カタログを同梱（売り込みなしの「ご自由に」レター付き）。

「貸出サンプル制度」

『刃心』柳刃や『黒備』牛刀を「2週間無料貸出」。気に入ったらお買い上げ店紹介、気に入らなくても返送だけでOK。代理店経由の販売を担保しつつ、現物体験の機会を作る。

施策4：既存事例化＋業界誌持込

既に『刃心』を採用いただいている著名店主・有名ホテルを「お客様の声」として事例化します。これは総会前に完了させ、当日DL資料に掲載することで信頼性が一気に上がります。

事例化対象（候補）

  • 銀座の老舗寿司店 親方
  • 京都の老舗料亭 料理長
  • 都内ミシュラン獲得割烹
  • 大手ホテルチェーン総料理長

業界誌持込

  • 「料理用品ニュース」「月刊厨房」「専門料理」
  • 無償記事として「越前打刃物の今」を寄稿
  • 会報誌・メルマガに「お役立ちコラム」を寄せる
事例化は「総会日までに最低1社、できれば2〜3社」を目標に即着手します。総会後では遅く、当日配布資料に「事例あり」と書ける状態を作るためです。

📢 プロモーションのレーン

「役立つ情報の発信元」というポジション

0ヶ月：DLコンテンツ配布で接点獲得 → 1〜2ヶ月：定期配信で接触頻度を上げる → 3〜4ヶ月：協会の公式媒体（会報誌・メルマガ）に無償記事を持ち込む → 5〜6ヶ月：業界誌・専門誌に取材を仕掛けて権威化。営業色を出さず役立つ情報の発信元というポジションを作る。

💼 営業のレーン

「個別商談」を仕組みで生む

0ヶ月：マイク発言＋チラシ配布 → 1〜2ヶ月：DL者へのサンプル貸出 → 3〜4ヶ月：返送時に事例化打診 → 5〜6ヶ月：協会内紹介で初期受注へ。属人化せず複数営業マンで分担できる仕組みを作る。

🏛 組織露出のレーン

「協会内のポジション」を中長期で取りに行く

0ヶ月：賛助会員として姿勢を宣言 → 1〜2ヶ月：協会内の関係者に挨拶回り → 3〜4ヶ月：協会メルマガに名前が載る → 5〜6ヶ月：「会員向け技能情報配信係」に立候補して公式チャネル枠を獲得。個別営業の50倍のレバレッジが効くゴール。

💡 並走の意味：3レーンを「順番にやる」のではなく「同時に動かす」のがポイント。プロモーションで知名度、営業で売上、組織露出で長期ポジション、それぞれ別の人が担当できるので、社長一人に依存せず組織として広域展開できます。
