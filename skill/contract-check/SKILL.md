# 契約書レビュー スキル

受領した契約書を指定の立場で分析し、問題点と改善提案をExcel比較表で可視化するスキル。作成ではなく**受領・確認**フェーズに特化。

## トリガーワード

- 「この契約書をチェックして」
- 「受け取った契約書を甲側の立場でレビューして」
- 「どこが不利な条件か確認して」
- 「契約書の問題点を洗い出して」
- 「この条項は大丈夫？」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 内容 |
|------|------|
| 契約書 | docx / PDF / テキスト貼り付けで提供 |
| **立場設定** | **甲-有利 / 乙-有利 / 公平** |
| レビューの目的 | 締結前確認 / 修正交渉用 / リスク把握のみ |
| 特に気になる箇所 | 任意（例：知財条項、解除条件）|

---

## 立場設定の効果

| 立場 | レビュー視点 | 主な用途 |
|------|------------|---------|
| **甲-有利** | 甲（発注側・委託者）の利益を守る観点でリスクを洗い出す | 外部から受け取った契約書を発注側として確認する時 |
| **乙-有利** | 乙（受注側・受託者）の利益を守る観点でリスクを洗い出す | コンサルタント・業者として受け取った契約書を確認する時 |
| **公平** | 双方のリスクを中立的に評価する | 社内確認・第三者チェック・雛形精査 |

---

## 出力1：Excel比較表

### 列構成（7列）

| 列 | 項目 | 内容 |
|----|------|------|
| A | 条文番号 | 第○条、前文、附則 等 |
| B | 元の条文（要約） | 問題となる箇所を抜粋 |
| C | 問題点・懸念事項 | 何が問題か・なぜリスクか |
| D | リスクレベル | 高🔴 / 中🟡 / 低🟢 |
| E | 改善提案 | 修正案または代替表現 |
| F | 立場への影響 | 甲-不利 / 乙-不利 / 双方 / 中立 |
| G | 対応優先度 | 要対応 / 検討 / 参考 |

### 機能
- リスクレベル・対応優先度でオートフィルタ設定済み
- 高リスク行は背景色（薄赤）で強調

### ファイル名
`契約書チェック_{契約種別または相手先}_{日付}.xlsx`

---

## 出力2：レビューレポート（Word）

### 構成（A4縦2〜3ページ）

**1. エグゼクティブサマリー**
- レビュー対象・立場の確認
- 発見された問題の件数（高リスク○件・中○件・低○件）
- 総合評価：締結推奨 / 修正後締結 / 要再交渉 / 締結不推奨

**2. 条項別レビュー（高・中リスクのみ）**
```
【第○条 ○○】
元の条文：〜
問題点：〜
根拠：民法第○条 / 業界慣行 / 実務上の解釈
改善提案：〜
```

**3. 欠落条項の指摘**
- 標準的な同種契約に含まれるべき条項で記載がないもの

**4. 交渉ポイントの優先順位**
- 必ず修正を求めるべき条項
- 交渉できれば要求する条項
- 許容できる条項（参考情報）

### ファイル名
`契約書レビューレポート_{相手先}_{日付}.docx`

---

## 5視点チェックフレームワーク

| 視点 | 確認内容 |
|------|---------|
| 法的妥当性 | 民法・下請法・労働法等に照らして有効か、強行規定に抵触しないか |
| 実務慣行 | 業界の標準的な契約条件と比較して逸脱していないか |
| リスク配分 | 損害賠償・責任制限・免責条項が一方に過度に偏っていないか |
| 曖昧性 | 解釈の分岐が生じる表現・定義が不明な用語・期間の不明確さはないか |
| 欠落条項 | 不可抗力・個人情報・知財・反社条項等の標準条項の有無 |

根拠を示せない指摘は行わない。解釈の分岐がある場合は「○○という解釈と△△という解釈がある」と複数視点で提示する。

## 他スキルとの連携フロー

```
相手先から契約書ドラフト受領
    ↓
/contract-check  → 問題点・改善提案をExcel比較表で可視化
    ↓
修正交渉・条文修正
    ↓
/doc-compare     → 修正前後の新旧対比表を生成
    ↓
/biz-contract または /nda  → 合意内容をもとに最終版を新規生成
```

---

## 対応できる契約書の種類

- 業務委託契約書・コンサルティング契約書
- 機密保持契約書（NDA）
- 売買契約書・購入契約書
- 利用規約・サービス契約
- 覚書・基本合意書（MOU）
- その他 日本語の契約文書全般

---

## 注意事項

本スキルによるレビューは実務的なリスク把握を目的とした参考情報です。法的判断が必要な場合や高額・高リスクな取引は弁護士等の専門家に確認してください。推論で根拠なく断言することはせず、確認できない事項は「確認が必要」として明示します。
