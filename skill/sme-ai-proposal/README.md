# SME AI導入支援 提案スキル

## 概要

中小企業・小規模事業者（10〜50名規模）へのAI導入支援提案書を、
ヒアリング記録や提出書類から自動生成するスキル。

「オペレーション改善が先・ツールは補助」の哲学を軸に、
業種・予算・ITリテラシーに応じた現実的な提案を設計する。

## 起動方法

```
/sme-ai-proposal
```

または

```
/sme-ai-proposal [クライアント名] [業種]
```

## 対応業種パターン（SKILL.md に詳細）

| パターン | 業種例 |
|---------|------|
| A | 障害福祉（就労継続支援B型・グループホーム） |
| B | クリニック・整体院・美容サロン |
| C | 製造・建設（現場記録・品質管理） |
| D | 士業・コンサル・研修機関 |

## 出力物

| ファイル | 内容 |
|--------|------|
| `AI導入支援_完全提案パッケージ_{クライアント名}_{v}.html` | 提案HTMLパッケージ |
| `要件定義.md` | プロジェクト要件・設計哲学・変更履歴 |

## ゴールデンスタンダード（参照実装）

```
05_クライアント案件\20260326_合同会社まる\
AI導入支援_完全提案パッケージ_合同会社まる_v3.html
```

このファイルのCSS・SVG・セクション構成を流用することで
業種が違っても高品質な提案書を効率よく生成できる。
