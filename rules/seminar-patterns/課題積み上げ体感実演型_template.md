# 課題積み上げ体感実演型 — 台本テンプレート

**パターン:** 課題積み上げ体感実演型
**品質基準:** `rules/seminar-script-rules.md` に準拠

---

## 変数（apply前に必ず埋める）

```
{{テーマ}}      = 例: DX推進 / 採用効率化 / 在庫管理
{{ゴール}}      = 例: 参加後に〇〇の初期設定を完了させる
{{ターゲット}}  = 例: 中小製造業の現場担当者・30〜50代
{{数値フック}}  = 例: 〇〇に月いくらかけていますか？
{{表面課題}}    = 例: ツールが乱立してコストが膨らんでいる
{{本質課題}}    = 例: データが分散して意思決定の質が下がっている
{{思想転換軸}}  = 例: ツールを増やすのではなく、情報の土台を一本化する
{{チップス3選}} = 例: A機能・B機能・C活用法
{{CTA}}         = 例: 無料相談 / 説明会登録 / コミュニティ参加
{{あるある}}    = 例: 議事録を作っても誰も見ない
{{ROI}}         = 例: 週5時間の削減 / 月〇万円のコスト削減
{{登壇者実績}}  = 例: 〇〇業種×〇〇社への支援経験
{{登壇者失敗談}}= 例: かつて〇〇で失敗した経験（具体的に）
```

---

## セクション1: オープニング（4〜6分）

### 冒頭フック（チャット参加型）

```
[台本]
まず最初に皆さんに質問させてください。

{{数値フック}}

チャット欄に数字を書いてみてください。
（コメントをリアルタイムで実況）
みなさん、〇〇、〇〇、なるほどなるほど——
ありがとうございます。結構みなさん意識されてますよね。

これ、実は最大の課題がこの数字の裏に隠れているんですが、
そのお話は少し後にしますね。
まず自己紹介をさせてください。
```

### 自己紹介（実績 + 失敗談）

```
[台本]
私は現在、{{登壇者実績}}をやっています。

実は以前、{{登壇者失敗談}}という経験をしました。
そこで気づいたのが、〇〇だったんですね。
そこからフルベットして今があるといった形です。

今日は、きれいごとではなくリアルな話をお伝えします。
```

### KPI設定（今日の目標3つ）

```
[台本]
今日この場を終えるころには、3つの状態になっていただきたいと思っています。

1つ目が、{{ゴール1}}を理解していること。
2つ目が、{{ゴール2}}という選択肢を持って帰っていただくこと。
そして3つ目、これが一番大事で、{{ゴール3}}の意味そのものを
腑に落とした状態になっていること。

この3つがゴールです。では進めていきましょう。
```

### アジェンダ提示

```
[台本]
今日の流れはこの通りです。

前半は「なぜそれが必要なのか」という考え方・座学的な内容。
後半は「実際にどう使うか」という実践よりの内容です。

前半でしっかりと「なぜか」を理解していただいてから
実演に入る構成にしています。理由があります。
あとでお話しします。
```

## セクション2: 問題提起（表面課題）（約10〜15分）

```
[台本]
さて、先ほど皆さんに{{数値フック}}を聞きましたよね。

こんな感じで、{{表面課題}}というのが
今、多くの方に起きていることだと思います。

例えば——（{{あるある}}を3つ列挙する）

これ、なんとなく解約しにくいというのも
あると思うんですね。それぞれ理由があって入れてるから。

[参加者コメントがある場合はここで実況する]

でも問題はコストだけじゃないんです。
ここが今日の本質です。
```

## セクション3: 原因の深掘り（本質課題）（約10〜15分）

```
[台本]
最大の課題は実は——{{本質課題}}というところにあります。

これどういうことかと言いますと、
〇〇するということは、単に〇〇が増えるだけではなくて、
〇〇というものも分散すると同義になります。

例えば、〇〇では知っている情報を、〇〇は知りませんよね。
こうなるとですね——（影響を具体的に説明）

2025年まではそれでもギリよかったんですけれども、
2026年以降は——（トレンドの変化を示す）

だからこそ、生まれた選択肢があります。
```

## セクション4: 新しい視点の提示（思想転換）（約10〜15分）

```
[台本]
そこで、ようやく今日の問いに入っていきます。

{{思想転換軸}}

これどういうことか。（丁寧に説明）

ここで必ず来る質問があります。
「でも他にも良い選択肢があるじゃないですか」と。

それはそれでおっしゃる通りです。
（反論を先に認める）

ただしかし——（なぜそれでも〇〇が正解かを説明）

実は、これを全部やってしまうとこういうことが起きます。
（AI鬱的な問題・本末転倒のリスクを説明）

だからこそ、まずは〇〇に的を絞ることをお勧めしたい。
それはなぜかと言いますと——
（理由を3点で整理して説明）
```

## セクション5: 実務実演 チップス{{チップス3選}}（約30〜35分）

### 移行ブリッジ

```
[台本]
つまらん座学はここまでにして（笑）、
ここからは実際に動くところをお見せします。

今日はこの中でも特に——
・再現性が高くて
・体感差が大きいもの
この3つに絞ってご紹介します。
```

### チップス1: [{{チップス1}}]

```
[台本]
まず1つ目、{{チップス1}}についてです。

[画面共有を開始]

これ、過小評価されがちなんですが、
個人的にはかなり愛用しています。

使い方はとてもシンプルで——（操作手順を実演しながら説明）

注意点が1つあります。（制限事項を正直に伝える）

でも、（どんな用途なら最適かを示す）
という目的で使う分には、これで十分です。

実際にやってみましょう。
```

### チップス2: [{{チップス2}}]

```
[台本]
2つ目は{{チップス2}}です。

これ、〇〇って結構「作ること自体が目的」になりがちな方
多いと思うんですね。

でも本来は——（本来の目的を再設定する）

{{チップス2}}はその点をかなり解決してくれます。

実は、{{あるある2}}という経験、ありませんか？
（チャットでコメントを取っても良い）

これがこうすることで解決します。（実演）

しかも、ここにおまけのチップスが2つあります。（追加tips）
```

### チップス3: [{{チップス3}}]

```
[台本]
今日一番皆さんに紹介したかったのが、これです。

{{チップス3}}

なぜこれが最後かと言いますと、
これだけで前の2つが10倍生きてくるからです。

日常業務でAIを使う時に一番だるいのって、
毎回ゼロからプロンプトを書くことだと思うんですね。
（共感の取り方を説明）

{{チップス3}}を使うとどうなるか——（実演）

これ、AIが苦手な人にこそ使ってほしいんです。
なぜかと言いますと——

チームで使うとどうなるか。（チーム活用の説明）
これが{{ROI}}につながります。
```

## セクション6: クロージング・CTA（約5分）

### まとめ

```
[台本]
今日のまとめです。

まず、{{表面課題}}という状況をご確認いただきました。
そしてその裏に{{本質課題}}があるというお話をしました。
だからこそ{{思想転換軸}}という新しい選択肢があります。

複数ツールへのバラバラな取り組みが
全員にとっての最適解ではないというお話もしました。

そして実際に{{チップス3選}}で体感していただきました。
```

### 3段階CTA

```
[台本]
ここまで聞いて——

1. {{テーマ}}をちゃんと使いこなしたいと思った方へ
   → まずは（入口レベルのアクション）

2. これを自分のビジネスに活かしたい、
   他者に提案できるようになりたいと思った方へ
   → （ビジネスレベルのアクション）

3. 一緒に市場を作っていきたいという方へ
   → {{CTA}}（パートナーレベルのアクション）

どこから始めても大丈夫です。
押し売りとかは一切しないので、
まずは「ちょっと聞いてみたい」くらいの温度感でOKです。

本日はありがとうございました。
```
