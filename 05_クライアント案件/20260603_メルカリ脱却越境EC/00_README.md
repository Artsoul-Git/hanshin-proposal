## 1. 案件サマリ

中古衣類（古着）4,000点以上を扱うクライアント。主販路だったメルカリで2025年後半から売上急減、海外比率3割（代行業者経由）が消失。Yahoo審査落ち・楽天コスト合わずで打開策を求めている。

本案件は、**メルカリ依存からの脱却**と**eBay・Shopee等の海外直販体制構築**を支援する。
