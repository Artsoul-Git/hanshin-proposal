# ヒアリングシート 自動生成スキル

初回商談・現状把握に使うExcelのヒアリングシートを業種・部門に合わせて動的に生成するスキル。

## トリガーワード

- 「ヒアリングシートを作成して」
- 「商談準備シートを作って」
- 「現状把握シートを生成して」

---

## 必要情報（Kaiがヒアリング）

| 項目 | 必須 | 内容 |
|------|------|------|
| 企業名 | ○ | ヒアリング先の会社名 |
| 業種 | ○ | 14種類から選択 |
| 対象部門 | ○ | 複数選択可 |
| ヒアリング予定日 | △ | 任意 |
| 目的 | △ | 初回商談・深掘りなど |

### 業種選択肢（14種）

製造業 / 小売業 / 卸売業 / 建設業 / 福祉・介護 / 医療 / 金融・保険 / 不動産 / 運輸・物流 / 飲食・宿泊 / 情報通信・IT / その他サービス業 / 農林水産業 / 公共・団体（農協・商工会等）

### 部門選択肢（5種）

経理 / 人事・総務 / 営業 / 現場・製造 / 情報システム

---

## シート構成（動的生成）

| シート | 内容 | 生成条件 |
|--------|------|----------|
| 基本情報 | 会社概要・担当者情報・従業員数 | 常時生成 |
| IT環境 | 使用ツール・システム・インフラ | 常時生成 |
| 【部門名】 | 部門別ヒアリング項目 | 選択部門ごと |
| 優先度・ゴール整理 | 課題優先度・理想の状態・予算感 | 常時生成 |

例：経理・営業を選択した場合 → 4シート（基本情報・IT環境・経理・営業・優先度）

---

## 部門別ヒアリング項目

### 経理部門
- 組織体制（担当者数・決算期）
- 業務フロー（請求書処理・経費精算・支払処理・月次決算）
- 困っていること（手入力多い・承認フロー煩雑・月次決算に時間・インボイス対応・電帳法対応 等）
- 具体的なエピソード・数値

### 人事・総務部門
- 組織体制（担当者数・採用数・退職数）
- 業務フロー（勤怠管理・給与計算・入退社手続・評価制度）
- 困っていること（勤怠集計・有給管理・入退社属人化・社保手続 等）

### 営業部門
- 組織体制（担当者数・顧客数）
- 業務フロー（顧客管理・見積作成・受注管理・日報）
- 困っていること（顧客情報属人化・見積時間・商談履歴共有・売上予測 等）

### 現場・製造部門
- 組織体制（作業者数・シフト体制）
- 業務フロー（作業指示・実績入力・在庫管理・品質管理）
- 困っていること（指示伝達ミス・二重入力・在庫不一致・ノウハウ継承 等）

### 情報システム部門
- 組織体制（専任/兼任）
- 業務フロー（PC管理・アカウント管理・ヘルプデスク・バックアップ）
- 困っていること（問い合わせ対応・資産把握・セキュリティ・属人化 等）

## 業種特有の追加質問

| 業種 | 追加される項目 |
|------|--------------|
| 製造業 | 生産管理システム・設備保全・IoT導入状況 |
| 小売業 | POS連携・EC展開・顧客分析 |
| 福祉・介護 | 介護ソフト・国保連請求方法 |
| 金融・保険 | コンプライアンス体制・顧客対応記録 |
| 公共・団体 | 組合員管理・共済融資管理 |

## 優先度・ゴール整理シート（最終シート）

- 課題の優先順位（上位3つ）
- 理想の状態（1年後にどうなっていたいか）
- 予算感（〜50万 / 50〜100万 / 100〜300万 / 300〜500万 / 500万以上 / 未定）
- 希望スケジュール
- 意思決定プロセス（決裁者・検討体制）
- 次のステップ

## 自動記入機能（文字起こし → Excel）

ヒアリングの文字起こしテキストを渡すと、シートに自動記入できる。

| 確信度 | セル背景色 | 表示 |
|--------|-----------|------|
| 高 | 白 | そのまま記入 |
| 中 | 薄黄 | コメント付き（推測根拠） |
| 低 | 薄オレンジ | コメント付き（複数候補） |
| 不明 | 薄グレー | 「該当発言なし」 |

**注意**：自動記入結果は必ず人間がレビューすること。黄色・オレンジのセルを優先確認。

---

## 提案骨子との連携

ヒアリングシートを `/proposal-outline` スキルに渡すと、課題・理想状態・予算感を自動抽出して提案骨子を生成できる。

```
/hearing-sheet → Excel生成・記入
    ↓
/proposal-outline → 提案骨子生成
    ↓
/billing-docs → 見積書生成
```
