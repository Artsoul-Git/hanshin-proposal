## 実演を始める前に（2〜3分）

### この実演で何を見ていただくか

「今日はキッチンカーでから揚げを販売するフランチャイズ——通称FC——への加盟を例に、AIを使った契約書の多角的なチェックをお見せします。

具体的には、リスクの洗い出しから始まり、費用の妥当性検証、FC本部の信用度確認、契約後の運営上の留意点、専門家への相談準備、そして日常的に使えるAIエージェントの設定まで、順を追って進めます。

画面に映っているステップ表を見てください。今日はこの流れで進みます。時間次第でどこまで進むか変わりますが、骨格の部分は必ずお見せします。」

---

### 数値・条件は業界・状況によって変わる

「一点、先にお伝えしておきたいことがあります。

今日の実演で出てくるロイヤルティの率や金額、競業禁止の期間、損害賠償の条件といった数値は、このから揚げFCという特定の設定に基づいています。

飲食業のFCでは、ロイヤルティ3〜7%が一般的な目安です。ただし同じ飲食でも業態によって違う。FC以外の業務委託や売買契約では、全く別の基準になります。

今日の数字をそのまま覚えようとする必要はありません。ご自身の業界に置き換えながら聞いていただくと、より実感が持てると思います。"自分の業界ではこの数字は何%なんだろう""うちの場合は何が引っかかるかな"というイメージを持ちながら見てください。」

### AIの出力は補正して精度を上げる

「もう一点だけ。

今日の実演では、プロンプトを1回入力して出力を見る流れでお見せします。ただ実際の使い方は、1回で終わらせる必要はありません。

たとえば"この業界では下請法より優越的地位の濫用が問題になりやすい、その観点も加えて"とか、"第3条についてもっと具体的なシナリオで説明してほしい"という補正の指示を続けて入力することで、出力の精度を段階的に高めていけます。

AIは1回で完璧な答えを出す機械ではなく、対話しながら深めていく道具です。今日はその入口として、まず1回の出力を読み解く体験をしていただきます。」

## Step 1：FC契約書の総合リスクチェック（5分）

### プロンプト

```
あなたは日本のフランチャイズ契約に精通した法務専門家です。
添付したFC加盟契約書について、加盟を検討している個人事業主の立場から確認してください。

【状況】
・キッチンカーによるから揚げ移動販売フランチャイズへの加盟を検討中
・加盟金・初期費用は自己資金と銀行融資を組み合わせる予定
・書類は本部から提示されたものであり、条件変更の余地は限定的

【確認してほしいこと】
1. 加盟者に著しく不利な条項を、リスクの大きい順に5つ挙げてください
   （条項番号・内容・なぜリスクなのかのシナリオを添えて）

2. 業界標準的なFC契約と比較して「これは異常だ」と感じる条件があれば指摘してください
   （ロイヤルティ水準・テリトリー保護・解除条件など）

3. 中小小売商業振興法に基づく法定開示書面に必要な項目が開示されているか
   確認できる範囲でチェックしてください

4. この契約書を締結する前に、加盟者が確認・交渉を試みるべきことを
   優先度順に教えてください
```

### 出力を読み解くポイント

**着目1：業界標準との比較が出ているか**

「ロイヤルティが10%という数字が出てきていますね。業界平均は売上の3〜7%とされているので、これは高い水準です。AIがここを指摘しているということは、数字として引っかかる要素があるということです。」

**着目2：テリトリー保護の問題**

「テリトリー（営業区域）の項目を見てください。"テリトリーの独占性が保証されていない"という指摘が出てきています。契約書の表現を確認すると"参考区域"となっています。これは、同じエリアに別の加盟者が入る可能性を本部が否定していない、ということです。」

**着目3：解除条件の非対称性**

「解除条件の項目も見てください。本部は30日前通知で解除できる一方、加盟者は6か月前通知が必要という、明らかな非対称性が指摘されています。加盟者が初期投資をまだ回収できていない段階でも、本部の判断で1か月後に契約が終わる可能性がある。これが数百〜数千万円を投じた後に起きうることです。」

**着目4：法定開示書面のチェック**

「中小小売商業振興法では、加盟契約締結の20日前までに法定開示書面を交付することが義務付けられています。AIがその観点でも確認してくれていますね。この書面をもらっているかどうか、本部に確認するポイントです。」

## Step 2：費用の全体像と収支の妥当性検証（5分）

### プロンプト（別紙1も一緒に渡す）

```
添付した費用明細書（別紙1）と契約書を合わせて確認してください。

【確認してほしいこと】

1. 加盟から開業までに必要な費用の合計を、明示されているものと
   「別途定める」として不明確なものに分けてリストアップしてください

2. ロイヤルティ・広告分担金・最低保証額を合計した月次の固定費用を
   計算してください。さらに、これらを賄うために必要な最低月次売上を
   試算してください（食材原価30%・人件費20%・車両維持費・燃料費等を
   仮定して）

3. 加盟金・研修費・保証金・設備費を初期投資とした場合、
   この初期投資を回収するには月次純利益がいくら必要で、
   何ヶ月かかるかの目安を計算してください

4. 費用構造として、加盟者にとって特に不透明または不利な点を指摘してください
```

### 出力を読み解くポイント

**着目1：「別途定める」費用の洗い出し**

「明示されている費用と、"別途定める"として金額が見えない費用が分かれて出てきていますね。研修費60万円は別紙3に初めて金額が出てきます。契約書の加盟金300万円だけを見ていると、実際のスタートコストが全く見えない構造になっています。」

**着目2：収支シミュレーションの結果**

「ロイヤルティ10%に広告分担金2%を加えると、売上の12%が毎月本部に流れます。さらに指定食材の購入義務があるので、食材コストの水準も本部がコントロールしている。最低月次売上の試算も出てきています。本部が提示している収支計画とこの数字を並べると、両者の間にギャップがあるかどうかが見えてきます。」

**着目3：初期投資回収の試算**

「初期費用の概算が出てきていますね。仮に一番高い試算で合計1,000万円を超えるとしたら、月次純利益がどれくらい必要で、何年かかるか。この数字を本部が提示している収支計画と比べてみると、ギャップが見えやすくなります。」

## Step 3：FC本部の信用度・実態確認の方法（5分）

### プロンプト（この質問は書類なしでもできる）

```
フランチャイズ本部「株式会社カラアゲーニョジャパン」について
加盟前に実施すべき信用度・実態確認の方法を教えてください。

【確認してほしいこと】
1. 自分でできる調査方法のリスト（無料・有料それぞれ）
   ・会社情報・財務状況の確認方法
   ・既存加盟者の評判・クチコミの調べ方
   ・トラブル事例・訴訟歴の調べ方
   ・行政による指導・処分歴の確認方法

2. FC本部に直接確認すべき質問リスト（加盟説明会・面談で使える）
   ・財務状況・加盟店数・解約率など

3. 確認する際の注意点（FC本部が不誠実な場合の見分け方）

4. 専門家（中小企業診断士・FC専門弁護士など）への確認を
   依頼すべきポイント
```

### 出力を読み解くポイント

**着目1：自分でできる調査の具体性**

「法人番号・登記情報の確認、国税庁の法人情報、日本フランチャイズ協会への登録有無、公正取引委員会への相談窓口、こういった具体的な確認先が出てきていますね。これらは無料でできます。」

**着目2：FC本部への直接質問リスト**

「説明会で本部に聞くべき質問が出てきています。"現在の加盟店数と過去2年間の解約・退会数"という質問は特に重要です。解約率が高いFCは、構造的な問題がある可能性があります。本部が答えを渋る場合も判断材料になります。」

**着目3：不誠実な本部の見分け方**

「"数字を見せない""既存オーナーとの面談を避ける""契約を急かす"こういった行動パターンがリスクサインとして出てきていますね。感覚的に分かっていることでも、AIで整理すると確認リストとして使いやすくなります。」

## Step 4：契約後の運営上の留意点と対策（5分）

### プロンプト（契約書・別紙を全部渡して使う）

```
このFC加盟契約書と別紙一式を確認した上で、
加盟後の日常運営において発生しやすいトラブルと
加盟者が取るべき対策を教えてください。

【確認してほしいこと】
1. 契約書・別紙の条項から読み取れる、運営上のリスク場面を
   具体的にシナリオ化してください
   （例：本部が指定食材価格を値上げした場合、テリトリー内に
   競合店が出た場合、検収基準に関するトラブルが起きた場合、など）

2. 各リスクシナリオに対して、加盟者ができる事前の備えを提案してください

3. 日常的な証拠・記録の残し方について、具体的なアドバイスをください
   （本部とのやり取り・売上データ・品質管理記録など）

4. 本部とのトラブルが発生した場合の初動対応の手順を教えてください
```

### 出力を読み解くポイント

**着目1：リスクシナリオの具体性**

「"本部が指定食材価格を月次で改定できる"という条項が、実際の経営に与える影響のシナリオが出てきていますね。食材原価が上がっても売価を変えにくい移動販売では、ここが直撃します。AIがシナリオを具体化してくれると、想像しやすくなります。」

**着目2：記録の残し方**

「本部とのやり取りは口頭ではなく必ずメールや書面で残す、というアドバイスが出ていますね。特に"品質基準への指摘"や"エリアへの他加盟店の出店"に関する本部からの説明は、証拠として残しておく価値が高いです。」

**着目3：初動対応**

「トラブル時の初動として、まず自社で事実関係を記録・整理してから本部に問い合わせる順序が出ています。感情的に動く前に、事実を固めることが重要です。」

```
これまでの分析を踏まえて、FC加盟を最終判断する前に
弁護士またはFC専門の中小企業診断士へ相談するための準備資料を作成してください。

【作成してほしいもの】

1. 相談の背景サマリー（400字程度）
```

## Step 6：Gemを使った日常的な活用方法（5〜8分）

### Gemとは何か（1分）

「ここまで使ってきたのは通常のGeminiチャットです。

Geminiには"Gem"という機能があります。特定の目的に特化したAIエージェントを自分で作れる機能です。

今日やったFC契約チェックの流れを、一度Gemとして設定しておけば、次からは"Gemを開いて書類を貼るだけ"で同じ分析が自動的に動きます。」

### Gem作成の手順（3〜4分）

#### 操作手順（画面で実際に見せる）

1. Geminiのサイドメニューから「Gem を作成」または「My Gems」を開く
2. 「新しい Gem を作成」をクリック
3. 名前を入力：`FC加盟審査アシスタント`
4. 指示（カスタムインストラクション）に以下を貼り付ける

---

**Gem に設定するカスタムインストラクション：**

```
あなたはフランチャイズ（FC）加盟を検討している事業者のための審査アシスタントです。

以下の専門知識を持っています：
・日本のフランチャイズ契約の一般的な条件と業界水準
・中小小売商業振興法に基づく法定開示書面の要件（締結20日前の交付義務）
・飲食業FCの一般的なロイヤルティ水準（売上の3〜7%が一般的な範囲）
・独占禁止法・下請法上の問題になりやすいFC条件
・FC本部の信用度調査の方法と確認すべき情報

書類を渡されたら、必ず以下の順番で分析してください：

【STEP 1】費用の透明性チェック
・明示されている初期費用の合計
・「別途定める」として不明確な費用の洗い出し
・ロイヤルティ・広告分担金・最低保証額の月次合計と、それを賄う最低売上の試算

【STEP 2】テリトリー保護の確認
・独占エリアが明確に定義されているか
・「参考区域」「本部の裁量による」などの曖昧な表現がないか

【STEP 3】解除・更新・退会条件の確認
・本部と加盟者で解除条件に差がないか（通知期間の非対称など）
・更新料・更新条件が明確か
・競業禁止の期間・範囲が合理的か（退会後2年・全国は過大）

【STEP 4】仕入・調達の確認
・指定仕入先への強制とその価格水準
・市場価格との比較可能性

【STEP 5】法令遵守の確認
・法定開示書面（中小小売商業振興法）の提供が確認できるか
・下請法・独占禁止法上のリスク

各項目について：
・リスクの大きさ（高・中・低）
・なぜリスクなのかの理由と具体的なトラブルシナリオ
・業界標準との比較（分かる範囲で）
・加盟者として取るべき次のアクション

を明記してください。

回答は日本語で、見出しと箇条書きを使って整理してください。
```

### 想定される質問と回答（FC実演特有）

**Q：Geminiで個人情報を扱っても大丈夫ですか？**  
「今日は架空のサンプルを使っています。実際のFC契約書を使う場合は、Googleアカウントの利用規約とGeminiのデータ使用ポリシーを事前に確認してください。BusinessプランやEnterpriseプランであればデータの扱いがより明確になります。」

**Q：FC本部が提示した収支シミュレーションと全然違う数字が出てきたのですが**  
「それは非常に重要な気づきです。本部が提示する収支計画はモデルケースであることが多く、ロイヤルティ・食材費・車両維持費を全部加味した試算でないことも多い。AIで出した数字をベースに本部に説明を求めると、より詳細な情報が引き出せます。」

**Q：このGemをスタッフに使わせることはできますか？**  
「Gemは作成者のアカウントに紐づいています。同じプロンプトを渡してスタッフ自身のアカウントでGemを作ってもらう形になります。組織での利用はGoogle WorkspaceのGemini Businessプランが対応しています。」
