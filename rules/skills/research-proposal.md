# /research-proposal スキル — リサーチ提案

**用途:** 対象（企業・事業・テーマ）を受け取り、徹底リサーチ→ベンチマーク発見→転用提案までを一気通貫で生成する。エビデンスファースト原則を徹底し、推定値は明示・出典は必ず添付する。

**代表事例:** 阪神素地株式会社（履物製造）× ワークマン戦略転用5路線提案（2026-05）

---

## 発動条件

- 「○○社の戦略を提案して」「○○社の販路拡大を考えて」
- 「○○について多方面で分析して」「ベンチマーク分析を」
- 「他社の成功事例を○○に転用して提案して」
- 「リサーチ提案」「競合転用」「事業提案」「成功企業に学んで」
- 既存リサーチ資料があり、それを起点に独自視点で提案を求められたとき

---

## 8ステップ実行手順

### Step 1：受付・分析方針の合意

**動作：**
1. テーマ・対象・既存資料を受領
2. **指示の濃度を判定**：
   - 詳細指示あり → その方向で進行
   - 「何も指示なし」または「シンプルなテーマだけ」→ Kaiが多方面分析方針を提示
3. 「こういう方針で進めますか？」と確認（Kei承認後に着手）

**デフォルト分析の多方面とは：**
- 経営・業績／販路・チャネル／商品・技術／顧客・市場／組織・人材／競合・代替／機会・脅威

---

### Step 2：対象の徹底分析（一次情報優先）

**必須調査ソース：**

| カテゴリ | ソース | 取得すべき情報 |
|---|---|---|
| 公式 | 公式サイト・会社案内 | 沿革・事業内容・代表者・住所・資本金・従業員数 |
| 法人情報 | gBizINFO | 法人番号・許認可・調達実績・知財・財務（公開分） |
| 流通 | ECモール（Amazon/楽天/モノタロウ/アスクル/ミスミ/ナチュラム/ヨドバシ等） | 実出品数・商品構成・価格帯・レビュー |
| SNS | 公式 Instagram/Facebook/YouTube/X | 投稿頻度・コラボ実績・コミュニティ |
| ニュース | TDB/帝国DB／PRTIMES／業界紙 | 直近動向・受賞・提携・投資 |
| 業績 | 決算公告／有報／IR | 売上・利益・成長率（上場企業のみ） |
| 取引 | 業界DB・ジェトロ・経産省・農水省 | 業界全体トレンド・人口動態 |

**チェック項目：**
- 数値はすべて出典明記（取得日も記載推奨）
- 公開資料で確認できない項目は **「未公開」「未確認」と明示**
- 推測で穴埋めしない

---

### Step 3：課題・機会の構造化

**動作：**
1. **エグゼクティブサマリー作成**：対象の現状を200〜400字で整理
2. **ポートフォリオ俯瞰**：商品・販路・顧客の3軸でマッピング
3. **構造的課題の抽出**：表面の問題でなく根本原因（コアイシュー）
4. **追い風・逆風の整理**：人口動態・市場縮小・規制変化など

---

### Step 4：ベンチマーク企業の発見（Kaiの自発提案）

**判断基準：**
- 対象企業の業態・商品・顧客が似ている
- 同じ構造的課題（市場縮小、客層単一など）に直面していた
- それを乗り越えた具体的成功例がある
- 公開情報が豊富で多視点解析できる

**選定パターン：**

| パターン | 例 |
|---|---|
| 同業界の成功例 | 阪神素地（履物製造）× ワークマン（作業服→アウトドア） |
| 異業界・類似ビジネスモデル | 中小製造業 × ニトリ（垂直統合・PB集中） |
| 同顧客層を取った異業界 | シニア向け食品 × 旅行業（高齢者シフト成功例） |
| 構造的縮小から脱出した企業 | 釣具メーカー × ワークマン（建設職人縮小から客層拡大） |

**確認ステップ：**
- 候補を 1〜3社挙げて Keiさんに確認
- 「○○社が最も参考になると考えますが、いかがでしょうか？」
- Keiさんからの指名があればそれを優先

---

### Step 5：ベンチマーク企業の徹底分析（多視点）

**5視点フレームワーク：**

| 視点 | 抽出ポイント |
|---|---|
| **経営学** | 経営理念・事業ポートフォリオ・成長戦略・財務 |
| **マーケティング** | 客層拡大・ブランド・販促・アンバサダー・SNS |
| **組織論** | 組織構造・人事・文化・データ経営 |
| **IT** | DX・データ活用・自動化 |
| **グローバル** | 海外展開・現地化・段階展開 |

**出力：成功原則 N カ条**
- 通常 8〜12 個に抽出
- 各原則に「数値・実例・出典」を必ず付ける
- ワークマンの例：客層拡大／ブルーオーシャン特定／PB集中／アンバサダー／共同開発／UGC×TV撤退／機能格付け／業態多層化／データ経営／海外段階展開

---

### Step 6：成功原則 → 自社への転用提案

**転用マップの作成：**

| 列 | 内容 |
|---|---|
| ベンチマーク要素 | 「ワークマンプラス」「ワークマン女子」等 |
| 自社への転用形 | 「Hanshin Field+」「あなた想いプラス」等 |
| 対応商品 | 既存PBラインの活用 |
| 結果イメージ | 何が変わるか・どう刺さるか |

**N 路線への構造化：**
- 国内 3〜5 路線・国外 1〜2 路線が標準
- 各路線にペルソナを言語化（インサイト・こだわり・満足感情）
- 戦略×戦術×販路の3軸で具体化
- 4象限マトリックス（影響度×実行難易度）で優先度可視化

---

### Step 7：エビデンス整備（鉄則）

**4つの鉄則：**

1. **全数値に出典明記**（数値・市場規模・売上・人口・成長率すべて）
2. **推定値は「推計／想定／参考値」と明示**（業界平均からの逆算等）
3. **公開情報で取れない数値は「未公開」「未確認」と書く**（推測で埋めない）
4. **リンク取得できる場合は必ず添付**（出典URL）

**禁止事項：**
- もっともらしい数字を確信なく言う
- 出典なしで「業界では一般的に〜」と書く
- 推定値を断定で書く

---

**標準フォーマット（提案書末尾に必ず配置）：**

## 阪神素地ケース（実例参照）

### 入力
- テーマ：阪神素地株式会社の販路拡大
- 既存資料：deep-research-report.md
- 指示濃度：シンプル（「違った視点からの方法もアドバイスを」）

### 流れ
1. **Step 1**：「ファクトチェック＋違った視点の販路拡大策」を提示・承認
2. **Step 2-3**：公式サイト・gBizINFO・ECモール8チャネル実調査・SNS稼働確認・釣り市場-75%データ取得
3. **Step 4**：ベンチマーク候補としてワークマンを提案（Keiさんから即指名）
4. **Step 5**：ワークマンを5視点・10カ条で多視点解析
   - 売上1,752億円・PB比率68.5%・広告費率0.8%・アンバサダー40名・台湾2029年出店等
5. **Step 6**：5路線（道具女子／シニア／法人BCP／台湾東南／欧米プレミアム）に転用
6. **Step 7**：全数値に出典・推定値明示
7. **Step 8**：📊🏢🏆🛒🌏 のカテゴリ別エビデンス一覧

### 成果物
- `proposal.html` — 販路拡大アドバイザリー（6視点・7施策）
- `proposal_workman.html` — ワークマン戦略転用5路線提案
- `rashinban_proposal_1.html / _2.html` — 上記をラシンバン構造分解
- GitHub Pages 公開（パスワード保護）

## 重要な動作原則

### Kaiの自律判断ルール

**自律実行できること：**
- 公開情報からの事実収集
- WebSearch / WebFetch でのファクトチェック
- 数値の出典確認
- 既存資料の整理

**必ず確認すること：**
- ベンチマーク企業の選定（Keiさん意向を優先）
- 提案の方向性
- 公開・納品

**禁止事項：**
- 不確かな数値を断定で言う
- 出典なしで「業界平均は〜」と書く
- 推定値を「実績値」のように見せる

### 既存スキルとの関係

- `/research` 単独 → 調査のみ。`/research-proposal` は調査＋ベンチマーク発見＋提案までやる
- `/rashinban` 連携 → 本スキルの成果物を羅針盤化したい時に呼び出す
- `/sme-ai-proposal` 連携 → 提案書HTMLに統合したい時に呼び出す
- `/marketing` 連携 → 戦略壁打ちで使い、本スキルで構造化

## チェックリスト（自己検証）

成果物提出前に確認：

- [ ] 全ての数値に出典がついているか
- [ ] 推定値・推計値が明示されているか（「推計」「想定」「参考値」）
- [ ] 取れない情報を「未公開／未確認」と明記しているか
- [ ] 出典URLが切れていないか（WebSearch直後なら新鮮）
- [ ] ベンチマーク企業の選定理由が論理的か

- [ ] 4象限マトリクスで優先度が可視化されているか
