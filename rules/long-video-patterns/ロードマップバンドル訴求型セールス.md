# パターン#4：ロードマップ＋バンドル訴求型セールスウェビナー

> 単発60-90分のセールスウェビナーで、**「体系化されたスキル（ロードマップ）」を売りつつ、バンドル訴求と不安喚起でメインオファーへ誘導する型**。
> 抽出元：2026-05-26取り込みの78分セールスウェビナー素材（詳細は内部メタ層参照）
> 著作権配慮：元動画の登壇者名・社名・固有事例・具体的金額・固有商品名は記録せず、構造・設計DNAのみ抽出

## このパターンが効くケース

| 条件 | 該当例 |
|---|---|
| **体系化されたスキル**を売りたい | 営業AI／マーケAI／DX推進／コーチング体系 |
| **継続学習プラットフォーム**へ誘導したい | サブスク講座・コミュニティ・スクール |
| **複数の特典・バンドル**で価値を演出できる | プロンプト集／ツール込み／マニュアル付き |
| **不安喚起が刺さる層** | 「置いていかれる恐怖」を持つビジネスパーソン |
| LP配置のオンデマンドセミナー | アーカイブ視聴・録画配信可能 |

**逆に向かないケース：** 単発の高額コンサル（個別性が必要）／教育主体で営業しない場合／不安喚起が逆効果なターゲット

## 4つの核となる手法

### 手法1：感情アンカー（金額型ではない）

冒頭で「**セミナー終わる頃には『〇〇』と必ず思っていただける**」と感情的に約束。
価値アンカリング（金額型）が登壇者の実績数字を要するのに対し、**感情アンカーは未来の感情を約束するだけなので実績要件が低い**。

### 手法2：ロードマップNステップで体系化

本論冒頭で「**僕が推奨してるロードマップは、このNステップです**」と宣言し、各ステップを順番に解説。
- N=4-6が現実的（多すぎると散漫）
- 各ステップで**実演デモを挟む**ことで具体性UP
- 視聴者は「全体像→各論」の順で理解でき、自分の現在地が見える
- 後のメインオファーで「このロードマップを完走するためのプラットフォーム」と位置付け可能

### 手法3：バンドル訴求（早期プレゼント連発）

価値アンカリング（金額型）の代替手法。
- 「これも特典でプレゼントするんですけど」を全編で5-10回反復
- 月額数万円の商品が「**込み**」と言うことでバリュー積み上げ
- 視聴者の脳内に「これだけのものが付いてくる」感覚を作る

### 手法4：二元対立で不安喚起→行動誘発

末尾近くで「**A vs B**」の二元対立を提示：
- 「**経営者**はそういう思考で考えるので／**会社員**はそういう思考で見られる側」
- 「**やる人**はやる／**やらない人**は置いていかれる」
- 「**5年後勝つ人**／**5年後負ける人**」

その後「**だからこそ学んで一歩踏み出してほしい**」と行動促し。
不安喚起＋情緒的訴求（「**僕が責任を持って教えます**」）のセットで、メインオファーへの心理的ハードルを下げる。

## 「セールスだが講座素材としても使える」二重用途設計

このパターンの素材は、**セールス目的のセミナーをそのまま流用して、独立した講座コンテンツが作れる**二重用途。

### 講座流用可能な要素

| 要素 | 抽出方法 | 講座への転用例 |
|---|---|---|
| **ロードマップNステップ** | Step1-Nの解説を抜き出し | 「〇〇入門：Nステップで学ぶ」コース |
| **落とし穴・勘違い解説** | 失敗パターン部分 | 「〇〇で失敗しない10のポイント」記事 |
| **複数の実演デモ** | 各実演10-15分にカット | チュートリアル動画化 |
| **マインドセット** | 思考法部分 | 講座オリエン素材 |
| **特典xlsx・PDF** | そのまま配布 | 講座教材として完成済 |

### 講座転用時に取り除く要素

- 感情アンカー（「明日使える」等）→講座では不要
- 早期プレゼント連発→講座では教材で十分
- 二元対立フック→講座では教育的視点で書き直す
- メインオファー発表→講座では削除（次プラン誘導は別途）

**→ ロードマップ＋実演＋マインドセット＋特典＝独立講座として完成**

## 三位一体ファネル設計（2026-05-26 追記・PDF分析で確定）

このパターンの真の威力は、**セミナー＋PDFマニュアル＋特典xlsx＋メインオファーが完全に一貫した設計**になっている点。

```
[1] LP（縦長セールスLP）
         ↓
[2] セミナー動画（60-120分）
    ├ 感情アンカー＋実績連射で集中促進
    ├ ロードマップNステップ＋実演デモ
    └ メインオファー発表
         ↓
[3-A] 配布PDFマニュアル（10-15ページ程度）
    ├ セミナー内容を体系的に文章化
    ├ 実装コード／手順／事例まで完成形
    └ 最終ページでメインオファー再誘導
         ↓
[3-B] 特典xlsx（プロンプト集 / テンプレ集）
    └ 即実践可能な素材
         ↓
[4] メインオファー（継続学習プラットフォーム）
    └ バックエンド・継続収益
```

### 配布PDFマニュアルの設計鉄則（追加必須要素）

`apply` 時にPDFも同時設計するなら、以下の構造を守る：

| ページ位置 | 内容 | 役割 |
|---|---|---|
| 1 | 表紙 | カバー |
| 2 | 目次＋著者紹介＋まえがき | オリエン |
| 3-5 | 基礎理解（ツール比較／コツ） | **基礎スキル教材** |
| 6-7 | 著者の活用事例（具体例） | **動機づけ素材** |
| 8-13 | **N個の実装サンプル**（コード／手順／スクリーンショット） | **講座流用可な核** |
| 14-15 | メインオファー再誘導 | セールス連動 |

**PDFの講座流用可能率：** 最終ページ（オファー部）を「次の学習リソース」に差し替えれば、独立講座教材として配布可能。

### 三位一体ファネルが効く理由

- **マニュアル自体が「メインオファーの予告編」として機能** ─ 受講者は無料配布段階で「完成された講座っぽさ」を体感
- **メインオファー申込のハードル低下** ─ マニュアルで価値を実感→「もっと深く学びたい」と自然に動機形成
- **配布物の二重用途** ─ セールス用とは別に、マニュアル単独でリードマグネット／講座教材としても流用可能

### このファネル設計のための追加スロット（apply時）

| スロット | 必須／任意 | 例 |
|---|---|---|
| 配布PDFマニュアル | 任意（推奨） | 10-15ページ、ロードマップNステップに対応 |
| 特典xlsx／テンプレ | 任意（推奨） | プロンプト集／チェックリスト等 |
| マニュアル最終ページのオファー | 任意 | セミナーのメインオファーと一致させる |
| 「マニュアル単独配布版」 | 任意 | 最終ページのオファー部を差替して講座素材化 |

## このパターンのツボ（再現のコツ）

- **ロードマップNステップは「シンプルかつ実用的」に。** 4が黄金値、6超は散漫
- **各ステップで必ず実演デモ。** 言葉だけで説明しない
- **早期プレゼントは「全編散発」が肝。** 1回まとめてだと弱い
- **二元対立フックは末尾近くで1回だけ。** 連発すると説教臭くなる
- **メインオファーは「ロードマップ完走のためのプラットフォーム」と位置付ける。** ロードマップとの一貫性を保つ
- **感情アンカーは「未来の感情」を約束。** 金額型より実績要件が低くて安全

---

## このパターンの落とし穴

- **ロードマップNステップが多すぎる（7超）と散漫** → 4が最適
- **二元対立フックが説教臭くなる** → 末尾1回に絞る、共感ベースで
- **バンドル訴求が「盛りすぎ」と見られる** → 込みのツールは実際に使われているもののみ
- **メインオファー時間が短すぎる** → 15-20%は確保（10%では「とってつけた感」）
- **早期プレゼントを最初に全部提示** → 散発配置で価値積み上げ

## 著作権・倫理ガイド

このパターンは **構造・配分・話術設計** のみ抽出している。元動画の登壇者・社名・固有商品名・具体的金額・固有事例は記録していない。
適用時は **新規テーマ／新規ターゲット／オリジナル数字** で構成すること。
