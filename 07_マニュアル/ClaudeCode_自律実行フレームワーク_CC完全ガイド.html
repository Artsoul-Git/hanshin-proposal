🔍 第一章：CCが持つ「12つの強力な武器」（モード解説）

AIエージェントが、課題の難易度や内容に応じて使い分ける12の特殊機能です。

1. goal (ゴール逆算) Core
最終目標から「今何が必要か」を逆算し、中間タスクを自ら発見・設定して自律的に進む探索モード。
2. batch (一括高速) Core
複数のファイル作成・コマンド実行などをバラバラに行わず、一括でまとめて超高速で処理するモード。
3. Hooks (イベント連動) Optional
「ファイル保存時」や「完了時」などのタイミングに合わせて、自動検証やログ保存を自動的にトリガーする仕組み。
4. Rules (憲法遵守) Core
プロジェクトに規定されている「憲法（CONSTITUTION.md）」や各種決定ルールの枠組みを絶対に外さない制約モード。
5. DCI (データ・インタラクション) Optional
データ（情報源）、コンテキスト（状況背景）、インタラクション（対話・連携）を明確に分離して論理的にシステムを操作する設計。
6. fork (並行検証ルート) Optional
安全な別ブランチを切って一時作業を逃がしたり、別アプローチを並行して試すことができるルート分岐機能。
7. allow (承認ゲート) Core
「AIが自律的にやっていい安全な作業」と「人間の承認が必須な危険作業（Pagesデプロイ等）」を切り分けるゲート。
8. Mem (記憶永続化) Core
ユーザー情報や前回の会話の決定事項を `memory/` に保存し、セッションを跨いで確実に持ち越す記憶モード。
9. sec (セキュリティ保護) Optional
APIキーの漏洩防止（.env管理、.gitignore設定）や個人情報の漏洩を100%遮断する安全保障ガード。
10. tasks (進捗管理) Core
「Kai Tasks（task.md）」と完全連携し、作業を中間タスクにブレイクダウンして進捗をパーセント表示で管理。
11. Teams (マルチエージェント) Core
専門特化した複数のサブエージェント（分身）を同時に召喚し、並列してそれぞれの担当パートを実行させる仕組み。
12. Ultra (ウルトラ・クオリティ) Core
「ただ動くもの」で妥協せず、上村様が驚くような美しいUI・洗練された構成・徹底検証を行う最高品質モード。

🏃‍♂️ 第二章：自律実行から報告までのフロー

AIはこの指示を受けると、以下の5段階の超高度なステップで動き始めます。

1 最適機能の自律選定

与えられた課題（例：複数マニュアルの更新）に対して、12の機能から「今回は batch, tasks, Ultra が最適」と自ら判定し、準備を行います。

2 進捗の明示と超高速「並列」実行

ターミナル画面上に「[1/3] フォルダ作成 30%...」などの進捗をリアルタイム表示。また、並行して動かせる作業（別ファイルの書き出しなど）は、シングルタスクではなくマルチタスクで**「並列で一気」**に処理し、待ち時間を極限まで削ります。

3 自己完結型セルフレビュー

ファイル作成後、コードの崩れがないか、リンクパスが実在するかなどをセルフレビュー（自己検証チェックリストの確認）します。

4 A2Aチェック（Agent-to-Agent Check / エージェント間多重検証）

規模が大きい修正の場合、実行したAIエージェントとは別の「第三者の検証専門エージェント」を召喚。作成されたコードやテキストを別角度から厳しく評価させ、品質の抜け漏れ・バグ・スペルミスをゼロにする二重チェック体制です。

5 5大アジェンダによる完璧なスマートレポート

作業完了後、ユーザーに対してダラダラ説明せず、以下の「5項目」に沿って明快に報告を行います。
