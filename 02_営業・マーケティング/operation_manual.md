# ACTモデル：準備・運営マニュアル

一人で3社を並行稼働させながら、高品質な支援を提供するための標準マニュアルです。

## 1. 事前準備チェックリスト
- [ ] **ツール・環境**
    - [ ] ライモBiz 管理者アカウントの発行・設定
    - [ ] Gemini (Advanced推奨) の契約・プロンプト集の整理
    - [ ] クライアント共有用フォルダ（Google Drive / Dropbox等）の作成
- [ ] **パートナー連携**
    - [ ] 提携社労士への「研修開始予告」連絡
    - [ ] 助成金申請用書類一式のテンプレート用意

## 2. 標準オペレーションフロー（月次）

### 【Phase 1: 1〜3ヶ月目】
- **週次**: 1時間のWeb面談（進捗確認、プロンプト修正、アプリ開発相談）。
- **月次**: 1回の現地訪問（2時間）。
    - 現場の観察（ボトルネックの発見）。
    - 経営層へのショートレポート提出。
- **随時**: チャットツール（Slack/Chatwork等）での質問回答。回答期限は「24時間以内」を標準とする。

### 【Phase 2: 4〜6ヶ月目】
- **隔週**: 1時間のWeb面談。
    - 自走状況 babysitter チェック。
    - 他部署への展開プランの策定。
- **月次**: 成果集計シート（B/A分析）の更新。

## 3. 研修フォローアップ・マニュアル
- オンライン研修（13時間）の進捗を、管理画面から毎週チェックする。
- 脱落者が出ないよう、2週間に1回「励まし・疑問解消」の個別メッセージを送る。
- 研修修了者には、ライモBiz Toolsの「ミニアプリ開発」から着手させる（最も成果が実感しやすいため）。

## 4. トラブル対応
- **AIの精度不足**: 業務知識のプロンプト（RAG的アプローチ）への組み込みを支援。
- **現場の反発**: 「AIは仕事を奪うものではなく、残業を減らし付加価値を上げるもの」という文脈で、経営層から再度発信してもらう。
