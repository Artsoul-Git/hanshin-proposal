1 Claude Codeって何？

Claude Code（クロード コード）は、Anthropic（アンソロピック）という会社が作ったAIツールです。

普通のAIチャット（例：ChatGPTやClaude.aiのウェブ版）とのいちばんの違いは、あなたのパソコン上のファイルを直接読んだり書いたりできることです。

  • 文章の作成・修正・翻訳
  • ファイルの整理・一括変換
  • 表やデータの加工
  • プログラムの作成（知識不要）
  • 調べ物・まとめ・提案書の作成
チャットとの違いをひとことで言うと ウェブのAIチャット＝「話し相手」　Claude Code＝「実際に手を動かしてくれる同僚」

2 始める前に確認すること

以下の3つが揃っているか確認してください。

  • Claude.ai のアカウント（Proプラン以上）
    Claude Code を使うには有料プラン（月額約3,000円〜）が必要です。claude.ai でサインアップできます。
  • Windows 10/11 または Mac（OSX 10.15以上）のパソコン
    スマートフォンやタブレットでは動きません。
  • インターネット接続
    Claude Code はAIと通信しながら動くため、常時接続が必要です。

3 Node.js のインストール

Claude Code を動かすには「Node.js（ノードジェイエス）」というソフトが必要です。これはClaude Code の「土台」のようなものです。

すでに入っているか確認する

「ターミナル」（Windowsなら PowerShell、Macならターミナル）を開いて、以下を入力してEnterを押してください：

node --version

v18.0.0 以上の数字が表示されればOKです。次のセクションに進んでください。
「コマンドが見つかりません」などのエラーが出た場合は、以下でインストールします。

ターミナル（黒い画面）の開き方 Windows：キーボードの「Windows キー」を押して「powershell」と検索 → 「Windows PowerShell」をクリック
Mac：「アプリケーション」→「ユーティリティ」→「ターミナル」をダブルクリック

Node.js のインストール手順

1 nodejs.org/ja をブラウザで開く
2 「LTS」と書かれたボタン（推奨版）をクリックしてダウンロード
3 ダウンロードしたファイルを開き、「次へ」を押し続けてインストール完了
4 PCを一度再起動する
5 ターミナルを開いて node --version と打ち、数字が表示されれば成功

4 Claude Code のインストール

Node.js が入ったら、Claude Code をインストールします。ターミナルに以下をそのままコピー＆ペーストしてEnterを押してください：

npm install -g @anthropic-ai/claude-code

「Successfully installed」のような表示が出ればインストール完了です。

エラーが出た場合（Windowsのみ） PowerShell を「管理者として実行」してから同じコマンドを試してください。
スタートメニューで「powershell」を右クリック →「管理者として実行」を選択。

インストールできたか確認する

claude --version

バージョン番号が表示されればOKです。

5 作業フォルダを準備する

Claude Code は「フォルダ」を単位として動きます。AIと一緒に仕事をするための専用フォルダを用意しましょう。

おすすめの保存場所

Dropbox や OneDrive などのクラウド同期フォルダの中に作ることをおすすめします。理由：

  • パソコンが壊れても自動でバックアップされている
  • 別のPCからも作業できる
  • 速度が安定している
1 Dropbox（または OneDrive / Googleドライブ）フォルダを開く
2 新しいフォルダを作る（例：「AI作業フォルダ」「マイAIワークスペース」など好きな名前でOK）
3 そのフォルダのパス（場所）をメモしておく
例（Windows）：C:\Users\あなたの名前\Dropbox\AI作業フォルダ
例（Mac）：/Users/あなたの名前/Dropbox/AI作業フォルダ

6 データを守る仕組みを作る（Git）

「Git（ギット）」は、ファイルの変更履歴を自動的に記録してくれるツールです。ゲームの「セーブデータ」と同じ仕組みで、AIが誤ってファイルを変えてしまっても一瞬で元に戻せます。

なぜ必要か AIは一度に大量のファイルを変更できます。Gitがあれば「元に戻して」の一言で完全に復元できます。必ず設定しておきましょう。

① Git をインストールする

ターミナルで確認：

git --version

数字が表示されれば入っています。表示されなかった場合：

インストール方法 Windows：git-for-windows.github.io からダウンロードし、全て「Next」でインストール
Mac：ターミナルで xcode-select --install と打つと自動でインストールされます

② 名前とメールを登録する（最初の1回だけ）

以下を1行ずつ実行してください。名前とメールは自分のものに変えてください：

git config --global user.name "あなたの名前"
git config --global user.email "あなたのメール@example.com"

③ 作業フォルダをGit管理下に置く

作業フォルダの中でターミナルを開き、以下を順番に実行します：

git init
git add .
git commit -m "はじめてのセーブ"
フォルダの中でターミナルを開く方法（Windows） エクスプローラーで作業フォルダを開く → アドレスバーに powershell と入力 → Enter
何かおかしくなったときの復元コマンド（覚えておいてください） git restore . と打つと、最後にセーブした時点に全ファイルが戻ります。

7 Claude Code を起動して確認する

ターミナルで作業フォルダに移動してから、Claude Code を起動します：

作業フォルダに移動する

cd "C:\Users\あなたの名前\Dropbox\AI作業フォルダ"

（Macの場合は /Users/あなたの名前/Dropbox/AI作業フォルダ のように入力）

Claude Code を起動する

claude

初回起動時はログイン画面が表示されます。Claude.ai のアカウントでログインしてください。

起動成功のサイン 「>」や「Kai>」のような入力欄が表示されれば成功です！ここにメッセージを入力するとAIが返答します。

試しに以下と入力してみましょう：

こんにちは！何ができるか教えてください。

セットアップ完了！

ここからが本番です。あなただけのAIパートナーを作りましょう。

8 あなただけのAIパートナーを作る

Claude Code は「設定ファイル」を用意することで、AIの話し方や行動ルールをカスタマイズできます。この設定ファイルのことを CLAUDE.md（クロード エムディー）と呼びます。

CLAUDE.md って何？ 作業フォルダの中に置くテキストファイルです。Claude Code はこのファイルを毎回自動で読み込むため、「このAIは常にこう振る舞う」という設定が固定されます。
いわばAIへの「お仕事の説明書」です。

パートナーの名前を決めましょう

AIパートナーにはどんな名前でも付けられます。仕事のパートナーらしい名前でも、親しみやすいニックネームでも構いません。

好きな名前を自由に決めてください

例：「ソラ」「ハナ」「アシスト」「Nova」「Sora」「Leo」など、なんでもOK

名前が決まったら、以下のどちらかの方法で設定します。

方法A（おすすめ）— Claude Code に作ってもらう

Claude Code を起動した状態で、以下のメッセージを送るだけでパートナー設定ファイルが自動で作られます。[　] の部分を自分の名前・パートナーの名前に変えてからコピーしてください。

今日から私のAIパートナーとして一緒に働いてもらいます。
まず、この作業フォルダに「CLAUDE.md」というファイルを作ってください。

設定内容：
- パートナーの名前：[パートナーの名前をここに入力]
- 私の名前：[あなたの名前をここに入力]
- 話し方：むずかしい専門用語は使わず、親しみやすくわかりやすく話す
- ルール①：ファイルの削除・大きな変更をする前は「〜してもよいですか？」と必ず確認する
- ルール②：指示の意味がわからないときは勝手に進めず質問する
- ルール③：作業が終わったら「〜が完了しました」と必ず報告する
- 会話の始め方：毎回「こんにちは、[あなたの名前]さん！[パートナーの名前]です。今日は何をお手伝いしますか？」と挨拶する

ファイルを作ったら内容を見せてください。

Claude Code がファイルを作成したら、ターミナルを一度閉じて再起動してください。次回から設定が有効になります。

方法B — 自分でファイルを作る（より細かくカスタマイズしたい方向け）

以下のテンプレートをコピーして、[　] 内を書き換えてから「CLAUDE.md」という名前で作業フォルダに保存します。

# AIパートナー設定

## 基本情報
- パートナーの名前：[パートナーの名前を入力]
- あなたの名前：[あなたの名前を入力]

---

## パートナーの役割

あなたは [あなたの名前] さんをサポートするAIパートナー「[パートナーの名前]」です。
文章の作成・修正、アイデア整理、調べ物など、どんな依頼にも前向きに取り組みます。

## 話し方のルール

- むずかしい専門用語は使わず、やさしい言葉で話す
- 正直に、親しみやすく接する
- わからないことは「わかりません」「確認が必要です」とはっきり伝える
- 返答は長くなりすぎず、大切なことを先に伝える

## 仕事の進め方

- ファイルの削除・大きな変更をする前は「〜してもよいですか？」と必ず確認する
- 指示の意味がわからないときは勝手に進めず質問する
- 作業が終わったら「〜が完了しました」と必ず報告する

## 会話の始め方

新しい会話が始まったら、必ずこのように挨拶してください：
「こんにちは、[あなたの名前]さん！[パートナーの名前]です。今日は何をお手伝いしますか？」
「CLAUDE.md」として保存する方法（Windows） メモ帳（Notepad）を開く → 内容を貼り付ける → 「名前を付けて保存」→ ファイル名を CLAUDE.md と入力 → 「ファイルの種類」を「すべてのファイル」に変更 → 保存

はじめてのパートナーとの会話

CLAUDE.md を設定して Claude Code を再起動したら、以下のメッセージを送って関係をスタートさせましょう：

はじめまして！これから一緒に働きましょう。
まず自己紹介をしてください。
それから私のことをもっと知るために、次の2つを聞いてください：
1. 主にどんな仕事や作業でサポートを使いたいか
2. AIに特に得意になってほしいことは何か
パートナーがうまく機能しているサイン 毎回の会話が「こんにちは、〇〇さん！△△です。」という挨拶から始まるようになれば、設定が正しく読み込まれています。

パートナーへの上手な頼み方

  • 具体的に伝える：「文章を直して」より「この文章を小学生でも読めるくらいやさしくして」
  • 背景を伝える：「これはお客さんに送るメールです」のように用途を教えると精度が上がります
  • 「〇〇してから進めて」：大きな作業の前に「保存してから作業して」と一言添えると安全です
  • 迷ったら聞いてと言う：「やり方が複数ある場合は先に相談して」と伝えると勝手に進みません

9 毎日の使い方とコツ

毎日の起動手順

1 ターミナルを開く
2 作業フォルダに移動する：cd "作業フォルダのパス"
3 Claude Code を起動：claude
4 パートナーが挨拶してくれたら作業開始！

大きな作業の前のひと手間（習慣にしてください）

AIに大量のファイルを変更させる前に、必ずGitでセーブしておきましょう：

git add .
git commit -m "作業前バックアップ"

または、パートナーに「作業前にGitでセーブしてから進めて」と一言添えるだけでもOKです。

何かおかしくなったとき

git restore .

このコマンド1行で、最後にセーブした状態に全ファイルが戻ります。

10 よくある質問

Q. パートナーの名前は後から変更できますか？
はい。CLAUDE.md ファイルの名前の部分を書き換えるだけで変更できます。パートナーに「名前を〇〇に変更して」と頼むこともできます。
Q. Claude Code を閉じてもパートナーの設定は消えませんか？
CLAUDE.md ファイルとして保存されているので、次回起動時にも同じ設定で動きます。
Q. 無料で使えますか？
Claude Code の本体ソフトは無料でインストールできますが、使用にはClaude.ai の有料プラン（Proプラン）またはAPIキーが必要です。
Q. パートナーに言ってはいけないことはありますか？
パスワード、クレジットカード番号、個人情報などは入力しないようにしましょう。AIとの会話はAnthropicのサーバーを通じて処理されます。
Q. Gitのコマンドが怖くて使えません
パートナーに「Gitで今の状態を保存して」と日本語でお願いすれば、代わりにコマンドを実行してくれます。
Q. CLAUDE.md を作ったのに挨拶してくれません
Claude Code を一度完全に終了して、ターミナルも閉じてから再起動してみてください。再起動後に設定が読み込まれます。
