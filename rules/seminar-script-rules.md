# セミナー台本作成ルール
**適用範囲:** `/seminar-dna`・`/seminar-slide`・`/talk-script` すべてのセミナー関連スキル

> トンマナ（文体・語調・一人称）は案件ごとに別途指定する。このファイルはスタイルに依存しない「台本の構造的ルール」を定義する。

---

## 1. セミナー台本の目的と最終ゴール

台本の役割は「何を話すか」を決めることではなく、**「聴衆が何を感じ、何を考え、何をするか」を設計すること**。

```
目的導線:
気づき（わかった）→ 納得（そうだな）→ 動機（やりたい）→ 行動（やってみよう）

この4ステップを台本全体で一方向に進める。逆流させない。
```

---

## 2. 必須セクション構成

### 全セミナー共通の必須要素

どのスタイル・どの時間でも以下は必ず含める：

| 要素 | 目的 | 位置 |
|------|------|------|
| オープニングフック | 最初の30〜60秒で「聞く気」を作る | 冒頭 |
| 場のほぐし | 緊張を取り、聴衆との距離を縮める | 序盤 |
| ゴール宣言 | 「今日終わったら何が得られるか」を先に示す | 序盤 |
| 課題・共感パート | 「これは自分のことだ」と思わせる | 本編前半 |
| 解決・提案パート | 「それなら自分にもできる」と思わせる | 本編後半 |
| 具体的行動設計 | 「今日からすぐ試せる1つ」に落とす | クロージング前 |
| CTA（1つだけ） | 次のステップへ背中を押す | 最後 |

### 時間別の推奨セクション数

| セミナー時間 | セクション数 | 1セクションの目安 |
|-------------|------------|----------------|
| 30分以内 | 3〜4 | 6〜8分 |
| 60分 | 4〜6 | 8〜12分 |
| 90分 | 5〜7 | 10〜15分 |
| 120分以上 | 6〜9 | 12〜18分（休憩を挟む） |

---

## 3. オープニング設計の原則

### 最初の60秒で決まること

最初の60秒で聴衆は「この時間に価値があるか」を判断する。

**3ステップ構造（必須）:**
```
① 観察（5〜10秒）
   聴衆が「あるある」と思う場面・問いかけ・現象から入る。
   登壇者の話ではなく、聴衆の現実から始める。

② 一歩深い気づき（20〜30秒）
   ①で提示した場面の「本当の問題」「意外な側面」を示す。
   「実はこれって〇〇なんですよね」

③ 安心・期待（15〜20秒）
   「今日でその問題が解決する」「難しくない」という安心感を渡す。
```

### 自己紹介のタイミング

- **早すぎない:** 開口一番の自己紹介は禁止。まず聴衆の関心を引いてから
- **推奨:** フック → 場ほぐし → ゴール宣言 → 自己紹介（3〜5分後）
- **自己紹介の目的:** 「この人の話を聞く価値がある」と思わせることのみ。経歴の羅列は不要

## 4. 各セクションの設計原則

### 4-1. 1セクション = 1つの主張

1つのセクションに複数の主張を詰めない。
```
良い例: 「AIツール選定の前に業務フローを見直す必要がある」
悪い例: 「AIツール選定と業務フロー見直しとコスト試算をする必要がある」
```

### 4-2. 1主張の構造（結論サンドイッチ）

```
① 主張（断言）
   「〜です」「〜なんです」で始める。中立な言い方にしない。

② 説明（以下から2〜3個選ぶ）
   - Why（なぜそうなのか）
   - What（根拠・データ・メカニズム）
   - How（やり方・手順）
   - 事例・比喩（「例えば〜」「ある〇〇の場合は〜」）

③ 主張の再提示
   「つまり〇〇です」で締める
```

### 4-3. セクション間の接続

セクションとセクションの間には必ず「橋渡し」を入れる。

```
橋渡しの3パターン:
① 要約接続: 「つまり〇〇でした。次は△△を見ていきます。」
② 問いかけ接続: 「では、その〇〇を実際にどうすればいいのか。」
③ 予告接続: 「ここからが本題です。〇〇についてお話しします。」
```

## 5. エンゲージメント設計の原則

### 聴衆参加の頻度目安

| セミナー時間 | 参加仕掛け（最低数） | 推奨タイミング |
|-------------|-------------------|--------------|
| 30分 | 2回 | 10分・25分 |
| 60分 | 3〜4回 | 10分・25分・45分 |
| 90分 | 4〜6回 | 15分ごとに1回 |
| 120分 | 6〜8回 | 15分ごとに1回 |

### 参加仕掛けの種類と使い分け

| 種類 | 効果 | 使いどころ |
|------|------|----------|
| レトリカルクエスチョン | 自分ごと化 | どこでも使える・最も手軽 |
| 挙手確認 | 会場の空気把握・共感形成 | 課題共感パートの冒頭 |
| ペアワーク・対話 | 深い理解・定着 | 中盤のノウハウ提供後 |
| ワーク（成果物作成） | 即使える体験・信頼形成 | 後半・まとめ前 |
| チャット・アンケート（オンライン） | 参加実感・データ収集 | 随時 |

### 感情カーブの設計

セミナー全体を通じて感情が一方向に高まるように設計する。

```
推奨感情カーブ（例）:
共感（最初に引き込む）→ 不安・危機感（問題を認識させる）→
希望（解決の可能性を示す）→ 確信（根拠・事例で固める）→
意欲・行動（CTAへ向かう）
```

**テンション管理の原則:**
- 高いテンションを長時間維持しない（聴衆が疲れる）
- 高→低→高のリズムを意図的に作る
- 「笑い・驚き・沈黙」を意図的に使って感情をリセットする

## 6. クロージング設計の原則

### CTA設計（必須ルール）

```
CTAは1つだけに絞る（複数提示は行動を分散させ結果ゼロになる）

良い例: 「今日帰ったら、まずこれを1つ試してください」
悪い例: 「①〜を実践し、②〜に申し込み、③〜もご検討ください」
```

### 「今動く理由」の作り方

聴衆が「今日じゃなくていい」と思わないように設計する。

```
3点セット:
① 期限・希少性（「今月中に〜」「今日参加の方限定で〜」）
② 特典・価値（「今日だけ〜を差し上げます」）
③ ハードルを下げる（「まず1つだけ試してください」「5分でできます」）
```

### 余韻の設計

CTAの後に余韻を作る。聴衆が「考える時間」を設けることで定着率が上がる。

```
余韻の設計パターン:
- 短い沈黙（5秒）+ まとめの一言
- 「最後に一つだけお伝えします」で締める
- 最初のフックに戻る（ブックエンド構造）
```

## 7. 台本のフォーマット規則

### 基本フォーマット

```markdown
---
# [セクション名]（目安: ○分）

## このセクションの目的
<聴衆に何を感じてほしいか>

## 台本

「[話し言葉で書く。一文を短く。]

（少し間）

[続き]」

## エンゲージメント仕掛け
- [この中で行う参加仕掛けの内容]

## 次セクションへの橋渡し
「[接続のセリフ]」
---
```

### 話し言葉の記法

| 記号 | 意味 |
|------|------|
| `（少し間）` | 一拍置く（強調の前後） |
| `（ゆっくり）` | トーンを落とす・重要な内容 |
| `（やや強く）` | エネルギーを上げる |
| `（笑いを取りに行く）` | 軽い話題・場ほぐし |
| `（締めに向かう）` | CTA・まとめ直前 |

### スライドとの対応（`/seminar-slide` 連携時）

スライドがある場合は各台本ブロックにスライド番号を紐づける。

```markdown
## 台本（Slide 07 対応）
「[台本テキスト]」
```

## 8. 禁則事項

### 構造上の禁則
- **複数CTAの禁止:** 最後に行動を求めるのは1つだけ
- **自己紹介ファースト禁止:** 開口一番の自己紹介は禁止
- **結論後回し禁止:** 各セクションは主張から始める（結論サンドイッチ）
- **同じ仕掛けの連続禁止:** 同じ種類の参加仕掛けを連続して使わない

### 言葉上の禁則
- **陳腐なAI表現禁止:** 「AIの時代が来ました」「革新的な」「パラダイムシフト」「ゲームチェンジャー」
- **テンプレ比喩禁止:** 「羅針盤」「エンジン」「地図」などの使い古された比喩
- **過剰な断言禁止:** 「必ず〜できます」「絶対に変わります」
- **冗長禁止:** 同じ文型の連続、体言止めの多用
- **根拠のない固有名詞禁止:** 根拠のない企業名・数値・人名を入れない

### 感情設計上の禁則
- **恐怖訴求の多用禁止:** 危機感は1〜2回まで。恐怖で動かす設計は信頼を損なう
- **感情の逆流禁止:** 一度上がったテンションを理由なく下げない
- **強制感のあるCTA禁止:** 「〜しなければなりません」「〜は必須です」等の圧迫表現

## 9. 品質ゲート（台本完成前に確認）

### 構造チェック
- [ ] 7つの必須要素（オープニングフック〜CTA）がすべて含まれているか
- [ ] CTAが最後の1つだけに絞られているか
- [ ] 各セクションが「主張→説明→主張の再提示」の構造を持っているか
- [ ] セクション間に橋渡しが入っているか

### エンゲージメントチェック
- [ ] 参加仕掛けが推奨頻度を満たしているか
- [ ] 感情カーブが設計されているか（共感→不安→希望→確信→行動）
- [ ] 「今動く理由」の3点セットが入っているか

### 言葉チェック
- [ ] 禁則事項の言葉が入っていないか
- [ ] 話し言葉（口語）で書かれているか（書き言葉・論文調になっていないか）
- [ ] 一文が長すぎないか（目安: 読み上げ5秒以内）
