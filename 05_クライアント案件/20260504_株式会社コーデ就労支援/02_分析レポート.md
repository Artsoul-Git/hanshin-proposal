```

         → 記録義務あり・抜けると監査リスク

  2位：日々の記録の三重転記（毎日・全職員・大量）
         → 日報 / 作業報告確認表 / 相談支援記録の3書類に同一内容を手書き転記
         → 職員1人95分/日 × 10人 × 22日 = 月間172時間ロス
         → 「3枚に関しては利用者さんがお勤めの日には全て動く」（管理者ヒアリングより）

  3位：個別支援計画・モニタリング評価の全手打ち（管理者集中・半年サイクル）
         → 55名を年2回、サビ管が単独で担当
         → 計画案→計画→モニタリングの3段階すべてをコピペ＋手修正
         → 土日作業が常態化

【根本原因】
  →「記録→集計→転記」の三重構造：日報・確認表・相談記録の内容が重複しているのに別書類
  → フェイスシートとアセスメントシートが実質同一なのに2書類として維持
  → 国保連簡易入力V2とExcel内部帳票の二重運用で入力コスト倍増
  → 通所・施設外就労・在宅作業の3ルートを同じ書式で管理しようとする無理な統一

【最優先クイックウィン（最初の2週間）】
  → カンファレンス録音 → AI文字起こし → 議事録下書き自動生成
    期待効果：議事録作業 60分 → 20分以内（40分削減/件）
    コスト：スマートフォン＋無料アプリのみ。即日開始可能

【6ヶ月後の目標状態】
  総削減時間：月190〜210時間（記録172h + 議事録5h + 個別支援計画18h）
  月間コスト改善：475,000〜525,000円（時給換算2,500円ベース）
  ROI：6ヶ月投資額 650,000円 → 約1.5ヶ月で回収完了
```

## ■ 付記：現場で確認された追加課題（ヒアリングより）

1. **利用者の工賃計算の境界ルール**：1日1秒でも来れば固定額を支給。外就・在宅は別計算。107万円の壁を超える利用者は所得税処理が必要
2. **カンファレンスの突発性**：通常半年サイクルの他に、利用者の状況変化で臨時カンファレンスが週1〜2回発生することがある
3. **様式の出所が不明**：現在使用している作業日報・確認表は前任管理者作成で、様式17以外はローカルルールが混在。様式整理が必要
4. **3枚の記録書類の書き分けルール**：エピソードの深度で使い分けている（日報=簡易、確認表=中程度、相談支援記録=詳細）。この分岐をデジタルでも再現する必要がある
