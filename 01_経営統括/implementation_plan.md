# AI Core Transformation (ACT) モデル：実装計画書

本モデルは、ライモBiz（ラーニング＋ツールズ）をプラットフォームとし、経営課題の解決から現場の定着までを一気通貫で支援する、一人運営特化型の高収益コンサルティングモデルです。

## 1. 事業コンセプト
「AI研修で終わらせない。現場を変え、利益を創出する組織へ」
AIを「ツール」から「組織のインフラ」へと昇華させ、3ヶ月で劇的な業務改善（Before/After）を実現します。

## 2. ターゲットセグメント（ACTモデル推奨業界）
1.  **士業・専門サービス**: 行政書士、弁理士等（書類作成自動化）
2.  **不動産管理・仲介**: 物件紹介・顧客対応自動化
3.  **建設・工務店**: 現場事務・マニュアル自動化
4.  **介護・福祉**: 記録・報告書作成の効率化
5.  **製造業**: 技能承継・日報・Q&Aボット化

## 3. 収益・価格構造
| サービス項目 | 価格（税別） | 内容 |
| :--- | :--- | :--- |
| **ACT 導入研修** | **20万円/名** | ライモBizラーニング（オンライン13時間）＋管理者枠活用 |
| **Phase 1: 集中実装** | **30万円/月** | 1〜3ヶ月目：現地訪問1回、週1Web会議、環境構築、ミニアプリ開発 |
| **Phase 2: 定着加速** | **15万円/月** | 4〜6ヶ月目：オンラインのみ、月2回面談、横展開支援 |
| **Phase 3: 継続顧問** | **5万円/月** | 7ヶ月目〜（1年契約）：チャット相談、最新情報提供 |

## 4. ACTモデル 3つの柱（差別化要因）
1.  **AIマネージャー育成（組織化）**: 管理職2名＋実務者1名の3名体制を構築し、外部に依存しない自走組織を作る。
2.  **定量的B/A分析**: 導入前後の工数・コスト・品質を数値化し、経営層に投資対効果（ROI）を可視化する。
3.  **ライモBiz Toolsのフル活用**: ノーコードでのアプリ開発、動画マニュアル、パンフレット内製化により、外部発注コストを劇的に削減する。

## 5. ロードマップ
- **1ヶ月目**: 現状分析、AIマネージャー選定、導入研修開始、最優先課題（Low Hanging Fruit）の特定。
- **2ヶ月目**: ミニアプリ開発・実装、業務フローへの組み込み、第一次B/A評価。
- **3ヶ月目**: 社内浸透ワークショップ、動画マニュアル作成、成果報告会（経営層向け）。
- **4ヶ月目以降**: 他部署への横展開、Phase 2（オンライン支援）への移行。
