## ■ 競合カテゴリの整理

AS株式会社が戦う市場には、以下3種類の競合が存在する。

```
【直接競合】同じターゲット（小規模事業者）に同じ価値（AI導入支援）を提供
【間接競合】同じターゲットに別の価値（IT全般・業務改善・経営コンサル）を提供
【代替手段】顧客が自己解決する手段（YouTube・書籍・無料AI活用など）
```

## ■ 間接競合 一覧

| # | カテゴリ | 代表例 | 顧客が流れる理由 | 対抗策 |
|---|---------|--------|---------------|--------|
| I-001 | ITコンサル | PCサポート会社、IT顧問 | 「AI専門でなくてもITは任せてる」 | AI導入の専門性と成果の可視化 |
| I-002 | 経営コンサル | 中小企業診断士、商工会議所 | 「経営全般を見てもらってる」 | AI×業務改善の具体的ROI提示 |
| I-003 | 助成金コンサル | 認定支援機関、行政書士 | 「補助金がほしい」 | 補助金活用を絡めた提案 |
| I-004 | 人材紹介・派遣 | 人材会社 | 「人を増やせばいい」 | AI社員の方が安くて速いという比較提示 |

## ■ 代替手段（顧客の自己解決策）

| 手段 | 顧客が選ぶ理由 | 対抗策 |
|------|-------------|--------|
| YouTube・Udemy等で独学 | 無料・低コスト | 「学んでも実装に詰まる」段階でのフォロー設計 |
| ChatGPT等を自分で試す | すぐ使える | 「プロンプト設計」「業務フロー組み込み」の壁を可視化 |
| 社内のIT担当者に任せる | 外注不要 | IT担当がいない・属人化リスクを訴求 |

## ■ ポジショニングマップ

```
        【高価格】
             ↑
             │  ②全国系DXコンサル
             │  （大企業向け・高単価）
             │
低い ─────────┼───────── 高い
専門性        │              専門性
（AI特化度）  │  ① AS株式会社（目指すポジション）
             │  ・小規模特化
             │  ・AI×業務改善の掛け合わせ
             │  ・岡山発・地域密着
             │
③フリーランス│
AI講師        │
（低価格・    │
 浅い支援）   ↓
        【低価格】
```

**弊社の勝ち筋**：
- 「全国系には高すぎて頼めない」
- 「フリーランスには深いコンサルが期待できない」
- この2つの間の**「ちょうどいい専門家」**ポジションを占める

## ■ 差別化ポイント 整理

| 比較軸 | 弊社 | 全国系DXコンサル | フリーランスAI講師 |
|--------|------|----------------|----------------|
| 価格帯 | 中価格（研修20万〜） | 高価格（数百万〜） | 低価格（数万〜） |
| 対象規模 | 1〜10名の小規模事業者 | 中堅〜大企業 | 規模問わず |
| 専門深度 | AI＋業務改善＋現場伴走 | DX全般 | AI操作スキル中心 |
| 継続支援 | Phase制で段階的伴走 | プロジェクト完了型 | 単発研修が多い |
| 地域密着 | 岡山・訪問対応あり | 出張費高い | 基本オンラインのみ |
| ROI可視化 | 成果レポートで定量化 | 大きめの数字 | 測定なし |

## ■ 競合モニタリング 月次チェックリスト

```
【毎月1回・舞が実施】
□ 主要競合のHP・SNSに新サービス・価格変更がないか確認
□ 「AI導入支援 岡山」等のキーワードで検索順位・新規参入を確認
□ 商工会議所・業界団体のセミナー情報をチェック（競合が登壇していないか）
□ 顧客からの「他でも似たのを聞いた」発言を記録
□ 変化があった場合はケイに即報告、必要に応じて本シートを更新
```
