# Proposal Outline Generator（提案骨子生成）

## Purpose

ヒアリング結果から提案骨子（1〜2ページ）を自動生成し、営業→受注のボトルネックを解消する。

## Workflow

```
[入力]
  hearing-sheet.xlsx / 文字起こし.txt / メモ
      ↓
[Step 1] 入力ソース判定・課題抽出
      ↓
[Step 2] 提案タイプ判定（AI/DX or 汎用IT）
      ↓
[Step 3] 価値訴求ポイント生成
      ↓
[Step 4] アウトライン構成
      ↓
[Step 5] Word出力
      ↓
[出力]
  提案骨子_{クライアント名}_{日付}.docx
```

## hearing-sheet連携（自動抽出）

### 概要

`hearing-sheet-generator`で生成されたExcelファイルから、以下を自動抽出：

| 抽出項目 | 抽出元シート | セル/範囲 |
|---------|-------------|-----------|
| クライアント名 | 基本情報 | B3 |
| 従業員数 | 基本情報 | D5 |
| 業種 | シート名から推測 | - |
| 課題（優先順位） | 優先度・ゴール整理 | B3-B5 |
| 理想の状態 | 優先度・ゴール整理 | B8 |
| 予算感 | 優先度・ゴール整理 | B11 |
| 困っていること | 部門別シート | チェック済み項目 |
| エピソード | 部門別シート | B25 |

### 使用方法

```bash
# hearing-sheetから自動生成（クライアント名も自動取得）
python scripts/create_proposal_outline.py \
  --input "ヒアリングシート_株式会社サンプル.xlsx"

# クライアント名を上書きする場合
python scripts/create_proposal_outline.py \
  --input "ヒアリングシート_株式会社サンプル.xlsx" \
  --client "株式会社サンプル（別名）"
```

### 抽出ロジック

`scripts/hearing_sheet_extractor.py`で実装：

```python
from hearing_sheet_extractor import extract_from_hearing_sheet, generate_proposal_data

# ヒアリングシートからデータ抽出
hearing_data = extract_from_hearing_sheet("hearing_sheet.xlsx")

# 提案骨子用データに変換
proposal_data = generate_proposal_data(hearing_data)

# proposal_dataの内容:
# - client_name: クライアント名
# - issues: 課題リスト
# - proposal_type: AI/DX or IT導入
# - approach: 提案アプローチ文
# - reasons: 理由リスト
# - effects: 期待効果リスト
# - next_steps: 次のステップリスト
```

## Input Requirements

**優先度順**:
1. **hearing-sheet（.xlsx）** - 最優先。`/mnt/user-data/uploads/`から取得
2. **文字起こしテキスト（.txt）** - 音声メモからの変換
3. **手書きメモ（直接貼り付け）** - 最低限：会社名、業種、主要課題

**必須情報**（どの入力でも必要）:
- クライアント名
- 業種
- 主要課題（最低1つ）

## 課題抽出ロジック

### hearing-sheetからの抽出

```python
# 抽出対象シート・セル
EXTRACTION_MAP = {
    "基本情報": ["会社名", "業種", "従業員数"],
    "優先度・ゴール整理": ["課題の優先順位", "理想の状態", "予算感"],
    "部門別": ["困っていること（チェック済み項目）", "具体的なエピソード"]
}
```

### 文字起こし/メモからの抽出

以下のパターンを検出:
- 「困っている」「課題」「問題」→ 課題として抽出
- 「したい」「欲しい」「必要」→ 要望として抽出
- 数値表現（○時間、○人、○円）→ 定量データとして抽出

## 提案タイプ判定

| 検出キーワード | 提案タイプ |
|---------------|-----------|
| AI、生成AI、ChatGPT、自動化、効率化 | AI/DXアドバイザリー |
| DX、デジタル化、ペーパーレス | AI/DXアドバイザリー |
| システム導入、ツール導入、クラウド | 汎用IT導入 |
| Excel脱却、手作業削減 | 両方検討 |

**デフォルト**: AI/DXアドバイザリー（けんけん主力サービス）

- **メイン**: #000000（タイトル）、#333333（本文）

- **余白**: 上下左右 25mm

## Constraints & Boundaries

### DO（すること）
- ヒアリング結果からの課題構造化
- 顧客向け言語での価値訴求生成
- AI/DX提案と汎用IT提案の両方に対応
- 1〜2ページのシンプルなアウトライン生成

### DO NOT（しないこと）
- 詳細な実装計画の記載
- 見積金額の算出（billing-documentsで対応）
- 5ページ以上の詳細提案書
- 技術仕様の詳細記述
- 競合比較の詳細分析

## Examples

### Example 1: hearing-sheetからの生成

**入力**: 製造業・経理部門のヒアリングシート
- 課題: 請求書の手入力が多い、月次決算に時間がかかる
- 理想: 経理業務の自動化

**出力**: 
- 提案タイプ: AI/DXアドバイザリー
- 提案方向性: 「生成AIを活用した請求書処理自動化」
- 期待効果: 工数60%削減、月次決算3日短縮

### Example 2: 文字起こしからの生成

**入力**: 
```
「うちは社員5人の会社なんですけど、経理が1人で
請求書を毎月100枚くらい手入力してるんですよ。
それで残業が月20時間くらいあって...」
```

**出力**:
- 課題抽出: 請求書手入力100枚/月、残業20時間/月
- 提案タイプ: AI/DXアドバイザリー
- 期待効果: 残業時間80%削減（20時間→4時間）
