# eval-monthly — 月次総括レポート

## このスキルのルール

1. **承認不要で出力** — 分析結果を提示するだけ（削除・変更なし）
2. **Kai がセッション内で分析** — 追加API費用なし
3. **ロードマップの見直し提案を必ず含める**（翌月の指標設定）
4. **月次データはストックされ、翌月以降の比較に使われる**

---

## 実行手順

### Step 1: 月次データ集計

```bash
# 今月を集計
python 08_アプリ開発事業部/outputs/kai-review/kai-review.py monthly

# 先月を集計
python 08_アプリ開発事業部/outputs/kai-review/kai-review.py monthly --last
```

- git commit で記録

---

## 月次の役割

月次レポートは「事業評価の鏡」として機能する:

```
日次: 作業ログ → スコア化（記録）
週次: パターン検出 → Stop/Scale 判定（意思決定）
月次: トレンド分析 → ゴール再設定（戦略）
```

月次レポートを見て「このまま続けるか、方向を変えるか」を判断する場として使う。
